# 数据模型管理页 - 页面设计规范

> 页面路径: `/governance/data-model`
> 覆盖 MASTER 规范: 需要ER图可视化

## 页面目标

管理数据模型，定义事实表维度表，支持物理建表，稽核模型一致性。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据模型管理    │
│ 过滤栏: [搜索] [分类] [状态]       │
│ [新增模型] [导入] [导出]           │
├──────────────┬────────────────────┤
│ 模型目录树  │ 模型列表            │
│             │                    │
│             │                    │
│             │                    │
└──────────────┴────────────────────┘
```

## 左侧元模型目录

- 树形分类目录
- 逐层浏览
- 支持增删改分类节点
- 点击筛选右侧列表

## 右侧模型列表表格

| 列       | 说明                        |
| -------- | --------------------------- |
| 模型名称 | 链接到详情                  |
| 模型类型 | 标签: 事实表/维度表         |
| 分类     |                             |
| 版本     |                             |
| 状态     | 未提交/待审批/已上线/已下线 |
| 创建人   |                             |
| 更新时间 |                             |
| 操作     | 详情 / 稽核 / 上线 / 下线   |

## 模型详情页 (Tabs)

### Tab 1: 基本信息

| 字段       | 说明                     |
| ---------- | ------------------------ |
| 模型名称   |                          |
| 模型描述   |                          |
| 父模型     | 可选，继承属性           |
| 模型类型   | 事实表 / 维度表          |
| 目标数据源 | 选择数据源，用于物理建表 |

### Tab 2: 属性定义

- **技术元数据属性** 表格
- **业务元数据属性** 表格
- **管理元数据属性** 表格
- 支持添加/编辑/删除属性
- 每个属性: 名称、类型、是否必填、描述

### Tab 3: 关系定义 (ER图)

- 图形化展示当前模型与其他模型的关系
- 支持拖拽编辑关系
- 主键 ← 外键 关系箭头

### Tab 4: 版本历史

- 列表展示所有版本
- 支持版本比对
- 支持基于当前版本生成新版本
- 审批通过后不允许修改，只能新版本升级

## 操作功能

| 功能     | 说明                                   |
| -------- | -------------------------------------- |
| 模型审批 | 创建后需要审批才能上线                 |
| 模型上线 | 审批通过后上线使用                     |
| 模型下线 | 下线后无法使用                         |
| 物理建表 | 根据模型定义在目标数据源自动生成物理表 |
| 稽核任务 | 检测异常/僵尸/孤立模型                 |

## 稽核功能

- 手动触发或定时执行
- 检测:
  - 孤立模型: 没有任何数据来源
  - 僵尸模型: 已上线但长期未使用
  - 不一致: 属性定义与物理表不一致
- 生成稽核报告
- 支持查看每次稽核历史结果
- 支持开启/禁用稽核任务

## 交互规范

- 导入导出支持Excel模板
- 版本升级保留历史版本
- 物理建表前预览SQL脚本确认
- 稽核结果异常高亮展示

## 权限

- 模型创建需要审批
- 只有审批通过才能上线
- 上线后不能直接修改，需要版本升级
