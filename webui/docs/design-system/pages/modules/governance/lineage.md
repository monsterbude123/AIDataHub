# 数据血缘分析页 - 页面设计规范

> 页面路径: `/governance/lineage`
> 覆盖 MASTER 规范: 全屏图形展示，需要足够空间

## 页面目标

图形化展示数据血缘关系，分析影响范围。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据血缘        │
│ 搜索: [输入表名]  [定位]          │
│ 层级: ↑加号放大 ↓减号缩小  重置视图 │
├──────────────┬────────────────────┤
│              │                    │
│ 左侧树       │ 血缘图画布          │
│              │                    │
│              │                    │
│              │  (全屏可拖拽缩放)  │
│              │                    │
├──────────────┼────────────────────┤
│              │ 节点属性面板       │
│              │                    │
└──────────────┴────────────────────┘
```

## 左侧表树

- 树形展示数据源 -> 数据库 -> 表
- 支持搜索快速定位表
- 点击表名称在右侧画布展示血缘

## 中间血缘画布

- 使用 React-Flow 渲染
- 支持鼠标拖拽移动节点
- 支持滚轮缩放
- 支持框选多个节点
- 点击节点选中，右侧显示属性
- 箭头表示数据流向: 上游 → 当前节点 → 下游

### 颜色编码

| 节点类型  | 颜色 |
| --------- | ---- |
| 数据源表  | 蓝色 |
| ETL任务   | 橙色 |
| 数据服务  | 绿色 |
| 报表/指标 | 紫色 |

### 支持层级

- **表级血缘**: 展示表与表之间关系
- **字段级血缘**: 展示字段到字段的关系
- 可切换显示级别

## 右侧属性面板

选中节点后展示:

- **基本信息**: 名称、类型、描述
- **元数据信息**: 数据量、更新时间
- **ETL任务信息**: 调度周期、最近执行状态
- **操作**: 查看详情 / 刷新血缘 / 导出影响范围

## 影响分析功能

修改元数据前，自动分析下游影响:

- 图形高亮展示所有下游节点
- 分类统计: 影响多少个表、多少个数据服务、多少个报表
- 支持导出影响分析结果CSV
- 帮助评估修改风险

## 采集机制

- 自动从ETL任务、SQL开发、数据服务采集血缘关系
- 血缘自动更新，保持和实际一致
- 支持手动调整血缘关系

## 交互规范

- 双击节点可跳转到对应元数据详情页
- 滚轮缩放以鼠标位置为中心
- 双击背景重置视图到合适大小
- 支持导出血缘图为PNG图片

## 可访问性说明

- 复杂图形需要同时提供文字汇总表
- 表格列出所有上游节点和下游节点
- 屏幕阅读器可读取表格

### 键盘导航规范

血缘图支持完整的键盘导航，确保无法使用鼠标的用户也能操作：

| 按键            | 功能                           |
| --------------- | ------------------------------ |
| `Tab`           | 在左侧树和画布之间切换焦点     |
| `↑` `↓` `←` `→` | 在节点之间移动焦点             |
| `Enter`         | 选中当前焦点节点，显示属性面板 |
| `Escape`        | 取消选中，关闭属性面板         |
| `+` / `-`       | 放大/缩小画布                  |
| `0`             | 重置视图到合适大小             |
| `Ctrl + F`      | 聚焦到搜索框                   |
| `?`             | 显示键盘快捷键帮助面板         |

**焦点样式**:

- 焦点节点显示明显的虚线边框 (2px, #2563EB)
- 焦点顺序: 搜索框 → 左侧树 → 画布节点(按拓扑顺序) → 属性面板

### 屏幕阅读器支持

#### 节点 ARIA 标签

每个节点需要提供完整的 ARIA 标签：

```html
<div
  role="button"
  aria-label="数据表: orders, 类型: 数据源表, 上游节点 2 个, 下游节点 3 个"
  aria-describedby="node-orders-description"
>
  <span id="node-orders-description" class="sr-only">
    双击查看详情，使用方向键导航到相邻节点
  </span>
</div>
```

#### 图形区域 ARIA 标签

```html
<div
  role="region"
  aria-label="数据血缘图"
  aria-describedby="lineage-instructions"
>
  <span id="lineage-instructions" class="sr-only">
    使用方向键在节点之间导航，Enter 选中节点，Escape 取消选中
  </span>
</div>
```

### 文字汇总表

为屏幕阅读器和键盘用户提供文字形式的血缘汇总：

```
┌─────────────────────────────────────────────────────────────┐
│ 血缘汇总视图  [切换到图形视图]                                 │
├─────────────────────────────────────────────────────────────┤
│ 当前节点: dws_user_summary                                   │
│ 类型: 数据仓库表                                              │
│                                                             │
│ 上游节点 (2 个)                                              │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 节点名称         │ 类型       │ 关联方式    │ 操作       │ │
│ │ ods_user_table   │ 数据源表   │ ETL任务     │ [查看详情] │ │
│ │ dwd_user_detail  │ 中间表     │ Spark SQL   │ [查看详情] │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ 下游节点 (3 个)                                              │
│ ┌─────────────────────────────────────────────────────────┐ │
│ │ 节点名称         │ 类型       │ 关联方式    │ 操作       │ │
│ │ ads_user_report  │ 报表       │ 定时同步     │ [查看详情] │ │
│ │ api_user_service │ 数据服务   │ 实时查询     │ [查看详情] │ │
│ │ bi_user_dashboard│ BI报表     │ 数据抽取     │ [查看详情] │ │
│ └─────────────────────────────────────────────────────────┘ │
│                                                             │
│ 影响范围: 下游 3 个节点，涉及 2 个服务，1 个报表              │
└─────────────────────────────────────────────────────────────┘
```

**汇总表特性**:

- 默认显示当前选中节点的上下游
- 支持展开查看完整血缘链路
- 表格可通过 Tab 键导航
- 每行提供"查看详情"链接

### 颜色备用指示

颜色不是唯一的信息指示方式，需提供备用指示：

| 信息类型 | 颜色指示 | 备用指示                    |
| -------- | -------- | --------------------------- |
| 节点类型 | 不同颜色 | 节点图标 + 类型文字标签     |
| 数据流向 | 箭头颜色 | 箭头方向 + "上游/下游" 文字 |
| 状态正常 | 绿色     | ✓ 勾选图标                  |
| 状态警告 | 黄色     | ⚠ 警告图标                  |
| 状态异常 | 红色     | ✗ 错误图标                  |

**节点图标示例**:

```
┌────────────────────────┐
│ 📊 orders              │  ← 数据源表: 柱状图图标
│ 数据源表               │  ← 类型文字标签
└────────────────────────┘

┌────────────────────────┐
│ ⚙️ etl_user_sync       │  ← ETL任务: 齿轮图标
│ ETL任务                │  ← 类型文字标签
└────────────────────────┘

┌────────────────────────┐
│ 🔌 api_user_service    │  ← 数据服务: 插头图标
│ 数据服务               │  ← 类型文字标签
└────────────────────────┘
```

### 高对比度模式

支持高对比度模式，确保视觉障碍用户可辨识：

| 元素     | 普通模式     | 高对比度模式        |
| -------- | ------------ | ------------------- |
| 节点边框 | 1px, #E2E8F0 | 2px, #000000        |
| 连线     | 1px, #94A3B8 | 2px, #000000        |
| 箭头     | 填充色       | 黑色填充 + 白色描边 |
| 焦点指示 | 虚线边框     | 3px 实线边框        |
| 文字     | #1E293B      | #000000             |

### 减少动画模式

尊重 `prefers-reduced-motion` 用户偏好：

```css
@media (prefers-reduced-motion: reduce) {
  .lineage-node {
    transition: none;
  }
  .lineage-edge {
    animation: none;
  }
}
```

### 可访问性检查清单

- [ ] 所有节点可通过键盘访问

- [ ] 提供文字汇总表作为图形替代

## 性能考虑

- 超过100个节点提示用户缩小范围
- 展示TOP N 主要路径，隐藏不重要分支
- 使用Canvas渲染大图减少DOM节点数

## 移动端适配

### 移动端限制

由于血缘图需要复杂的拖拽、缩放、连线交互，移动端采用简化方案：

| 功能       | 桌面端     | 移动端         |
| ---------- | ---------- | -------------- |
| 图形拖拽   | ✓ 完全支持 | ✗ 不支持       |
| 滚轮缩放   | ✓ 完全支持 | ✗ 不支持       |
| 节点选择   | ✓ 点击选中 | ✓ 点击选中     |
| 属性面板   | ✓ 右侧面板 | ✓ 底部抽屉     |
| 血缘图查看 | ✓ 完整交互 | ✓ 静态图片预览 |

### 移动端布局

```
┌─────────────────────────────┐
│ 搜索: [输入表名]            │
├─────────────────────────────┤
│                             │
│   血缘图静态预览图          │
│   (点击查看大图)            │
│                             │
├─────────────────────────────┤
│ 上游节点列表                │
│ ┌─────────────────────────┐ │
│ │ ods_user_table          │ │
│ │ dwd_user_detail         │ │
│ └─────────────────────────┘ │
├─────────────────────────────┤
│ 当前节点                    │
│ ┌─────────────────────────┐ │
│ │ dws_user_summary        │ │
│ │ 类型: 数据仓库表         │ │

│ └─────────────────────────┘ │
├─────────────────────────────┤
```

### 移动端切换

移动端提供「图形视图」和「列表视图」切换：

- **图形视图**: 显示静态血缘图预览，点击可查看大图
- **列表视图**: 以文字列表形式展示上游/当前/下游节点

在移动端显示提示信息：
