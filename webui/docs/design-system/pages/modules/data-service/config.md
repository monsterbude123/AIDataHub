# 数据服务配置页 - 页面设计规范

> 页面路径: `/data-service/config`
> 覆盖 MASTER 规范: 无

## 页面目标

新增/编辑数据服务，配置查询条件、响应字段、发布服务。

## 布局结构 (分步表单)

```
┌───────────────────────────────────┐
│ 步骤条: 基本信息 > 查询条件 > 响应字段 │
├───────────────────────────────────┤
│                                   │
│         当前步骤内容               │
│                                   │
├───────────────────────────────────┤
│             按钮区                 │
└───────────────────────────────────┘
```

## 步骤 1: 基本信息

| 字段     | 说明                             |
| -------- | -------------------------------- |
| 服务名称 | 必填                             |
| 服务描述 | 文本域                           |
| 服务类型 | 单选: 查询检索 / 数据下载 / 比对 |
| 基于资源 | 选择: 已有的数据资源 / 自定义SQL |

**数据下载类型额外配置**:

- 输出格式: 默认 CSV
- 压缩: 是否压缩 (可选)
- 加密: 是否加密 (可选)
- 分片大小: MB，分片写入
- 支持断点续传: 开关默认开启

## 步骤 2: 查询条件配置

表格形式配置查询参数:

| 序号 | 参数名 | 显示名称 | 类型 | 必填 | 默认值 | 操作 |
| ---- | ------ | -------- | ---- | ---- | ------ | ---- |
| 1    |        |          |      |      |        |      |

**添加参数** 按钮新增行，上移下移调整顺序。

## 步骤 3: 响应字段配置

表格形式配置返回字段:

| 序号 | 字段名 | 显示名称 | 字典翻译 | 操作 |
| ---- | ------ | -------- | -------- | ---- |

选择字典后，自动翻译字典编码为字典文本。

## 底部按钮

- **测试服务**: 配置完后可点击测试，弹出测试模态框
- **保存草稿**: 保存不发布
- **发布**: 保存并发布服务，发布后可被调用

## 测试模态框

- 自动生成输入框对应每个查询参数
- 用户填入参数值
- 点击「执行测试」
- 底部展示JSON响应结果或错误信息
- 数据下载类型测试提供下载链接

## 特殊设计

- **自定义SQL**: 提供SQL编辑器，可预览字段
- **基于数据资源**: 树形选择资源，勾选字段
- 支持批量导入导出服务配置
- 发布后生成唯一服务URL和访问密钥

## 权限

- 仅服务发布权限用户可操作
