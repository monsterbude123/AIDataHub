# 数据服务授权页 - 页面设计规范

> 页面路径: `/data-service/authorization`
> 覆盖 MASTER 规范: 无

## 页面目标

在保障数据安全的前提下，为服务使用方授予访问权限。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据服务 > 服务授权         │
│ 过滤栏: [搜索] [分类筛选]         │
│ [新增授权]                         │
├──────────────┬────────────────────┤
│ 分类树      │ 授权列表            │
│             │                    │
│             │                    │
│             │                    │
└──────────────┴────────────────────┘
```

## 左侧分类树

- 按行业 / 单位 / 系统分类
- 支持增删改节点
- 支持检索
- 点击节点筛选右侧列表

## 右侧授权列表

表格列:

| 列           | 说明                   |
| ------------ | ---------------------- |
| 申请标题     | 链接到详情             |
| 服务名称     |                        |
| 申请方单位   |                        |
| 联系人       |                        |
| 访问频率限制 | 次/分钟                |
| 单日访问限制 | 次/日                  |
| 到期时间     | 颜色提醒: 即将过期标黄 |
| 状态         | 生效 / 失效            |
| 操作         | 编辑 / 删除            |

## 新增/编辑授权弹窗

表单:

| 字段                   | 说明               |
| ---------------------- | ------------------ |
| 关联服务               | 下拉选择已发布服务 |
| 申请联系单编号         | 输入外部编号       |
| 申请方单位             | 选择               |
| 联系人姓名             |                    |
| 联系人电话             |                    |
| 访问频率限制 (次/分钟) | 数字，0表示不限制  |
| 单日访问限制 (次/日)   | 数字，0表示不限制  |
| 授权到期时间           | 日期选择           |
| 状态                   | 生效 / 失效        |

## 交互规范

- 支持按申请标题、用户账号、用户名检索
- 修改授权信息实时保存
- 删除需要二次确认
- 到期前自动发送提醒通知

## 安全考虑

- 所有授权访问都有日志记录
- 超频率自动拒绝并记录
- 到期后自动失效
