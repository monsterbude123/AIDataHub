# 数据服务管理模块 - 页面索引

> 模块路由前缀: `/service`
> 菜单位置: 一级菜单「数据服务」

## 模块说明

将数据资源以服务接口方式对外暴露，提供发布、授权、监控能力。

## 功能页面

### 一级菜单页面

| 页面     | 类型  | 菜单名称 | 路由                  | 文档                             |
| -------- | ----- | -------- | --------------------- | -------------------------------- |
| 服务目录 | `[M]` | 服务目录 | `/service/catalog`    | [catalog.md](./catalog.md)       |
| 服务监控 | `[M]` | 服务监控 | `/service/monitoring` | [monitoring.md](./monitoring.md) |

### 非菜单页面（从列表/按钮进入）

| 页面     | 类型  | 路由                          | 入口方式                 | 文档                                   |
| -------- | ----- | ----------------------------- | ------------------------ | -------------------------------------- |
| 服务配置 | `[C]` | `/service/config`             | 服务目录「新建服务」按钮 | [config.md](./config.md)               |
| 服务配置 | `[C]` | `/service/config/[id]`        | 服务目录「编辑」按钮     | [config.md](./config.md)               |
| 服务授权 | `[D]` | `/service/authorization/[id]` | 服务目录「授权管理」按钮 | [authorization.md](./authorization.md) |

**页面类型说明**：

- `[M]` 菜单页面 - 出现在侧边导航菜单
- `[D]` 详情页面 - 从列表点击进入，不在菜单
- `[C]` 配置页面 - 新增/编辑配置，不在菜单

## 核心功能

- 支持查询检索类、数据下载类、比对类三种服务类型
- 数据下载支持后台离线分片输出、压缩加密、断点续传
- 授权控制访问频率、单日次数、到期时间
- 完整调用日志统计可视化
