# 数据标准化配置页 - 页面设计规范

> 页面路径: `/data-integration/standardization`
> 覆盖 MASTER 规范: 无

## 页面目标

配置原始表到标准表的字段映射，执行标准化处理。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据集成 > 数据标准化        │
├───────────────────────────────────┤
│ 顶部: 基本信息 (任务名称、描述)     │
├──────────┬──────────┬────────────┤
│ 原始表   │ 映射控制 │ 标准表     │
│ 字段列表 │          │ 字段列表   │
│          │  >>     │            │
│          │  <<     │            │
│          │ 自动匹配│            │
├───────────────────────────────────┤
│ 过滤条件配置区                      │
├───────────────────────────────────┤
│ 底部: 保存 / 预览 / 执行           │
└───────────────────────────────────┘
```

## 左右分栏映射设计

- **左侧**: 原始表字段列表 (可勾选)
  - 显示: 字段名、原始类型、描述
  - 支持搜索过滤
- **中间**: 操作按钮
  - `>>` 全部右移
  - `>` 选中右移
  - `<` 选中左移
  - `<<` 全部左移
  - **自动匹配**: 根据字段名称模糊匹配
- **右侧**: 标准表字段列表
  - 显示: 字段名、标准类型、是否已映射
  - 拖拽调整顺序

## 清洗筛选配置

- **前缀筛选**: 配置 WHERE 条件筛选数据
- **质量过滤**: 勾选是否过滤空值数据
- **函数预处理**: 可为每个字段配置预处理函数
  - 下拉选择已注册函数
  - 显示函数参数配置

## 历史视图

标签页切换:

- **按来源层**: 展示来源表 -> 标准表映射
- **按标准层**: 展示标准表 <- 来源表映射

## 任务管理区域

- 展示已配置的标准化任务列表
- 列: 名称、创建时间、状态、最后执行、数据量
- 操作: 查看报错、重新执行、编辑、删除

## 交互规范

- 自动匹配后用户可手动调整映射关系
- 保存为草稿可后续编辑
- 预览映射结果展示样本数据
- 执行后跳转到任务监控查看进度

## 职责说明

> 本页面负责**执行**数据标准化，数据标准的**定义**在数据治理模块
