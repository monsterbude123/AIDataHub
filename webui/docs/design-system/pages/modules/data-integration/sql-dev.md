# Spark SQL 开发页 - 页面设计规范

> 页面路径: `/data-integration/sql-dev`
> 覆盖 MASTER 规范: 无

## 页面目标

提供基于Spark的大数据自助SQL开发能力。

## 布局结构

```
┌──────────────┬───────────────────────────┐
│ 表资源树     │ 顶部: 模型信息编辑         │
│              ├───────────────────────────┤
│              │ SQL 编辑器                │
│              ├───────────────────────────┤
│              │ 执行控制栏 ▶测试 ▶执行     │
│              ├───────────────────────────┤
│              │ 结果预览 / 执行日志       │
└──────────────┴───────────────────────────┘
```

## 左侧表资源树

- 树形展示所有可访问数据源和表
- 拖拽表到编辑器自动插入 `SELECT * FROM table`
- 支持搜索表名称
- 点击表节点可预览前10行数据

## 顶部模型信息

| 字段       | 说明                  |
| ---------- | --------------------- |
| 模型名称   | 输入保存名称          |
| 模型分类   | 选择分类              |
| 执行器内存 | 下拉选择: 1G/2G/4G/8G |
| 执行器核数 | 数字输入              |
| 执行器个数 | 数字输入              |

## SQL 编辑器

- 基于 Monaco Editor / CodeMirror
- 语法高亮
- 表名字段自动补全
- 支持多行编辑

## 执行控制栏

- **测试执行**: 采样少量数据 (默认 1000 行) 执行，快速验证SQL正确性
- **完全执行**: 使用Spark全量执行
- **保存模型**: 保存SQL和配置
- **执行配置**: 展开显示高级配置

## 结果区域

标签页切换:

1. **结果预览**
   - 表格展示执行结果
   - 支持下载 CSV

2. **执行日志**
   - 流式展示Spark执行日志
   - 错误信息红色高亮
   - 支持搜索过滤日志

3. **历史执行**
   - 列表展示历史执行记录
   - 可查看任意历史执行的结果

## 高级特性

- **临时视图**: 支持 `CREATE TEMP VIEW`，执行结束自动删除
- **自定义UDF**: 可选择已注册的自定义函数
- **输出配置**:
  - 输出方式: 全量 / 增量
  - 写入模式: 插入 / 更新 / 覆盖

## 性能考虑

- 编辑器代码分隔不频繁重渲染
- 结果大表格虚拟滚动
- 日志增量更新不重渲染整个列表
