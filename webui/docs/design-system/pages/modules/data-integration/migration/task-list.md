# 迁移任务列表页 - 页面设计规范

> 页面路径: `/integration/migration`
> 所属模块: 数据集成管理模块
> 覆盖 MASTER 规范: 高密度表格，多筛选条件

## 页面目标

浏览和管理所有数据迁移任务，提供任务筛选、状态监控和快速操作入口。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│ 面包屑: 数据集成 > 数据迁移                                    │

│ 操作栏: [新建迁移任务] [刷新] [导出]                           │
├─────────────────────────────────────────────────────────────┤
│ 统计卡片                                                     │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐ │
│ │ 任务总数  │ │ 执行中   │ │ 成功     │ │ 失败     │ │ 待执行   │ │
│ │   25     │ │    3     │ │   18     │ │    2     │ │    2     │ │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘ └──────────┘ │
├─────────────────────────────────────────────────────────────┤

│                                                             │

│                                                             │

```

## 统计卡片区域

| 卡片     | 说明                   | 颜色                 |
| -------- | ---------------------- | -------------------- |
| 任务总数 | 所有迁移任务数量       | Primary (#2563EB)    |
| 执行中   | 当前正在执行的迁移任务 | Processing (#3B82F6) |
| 成功     | 最近成功完成的迁移任务 | Success (#10B981)    |
| 失败     | 执行失败的迁移任务     | Error (#EF4444)      |
| 待执行   | 已配置但未启动的任务   | Pending (#6B7280)    |

**卡片样式**:

- 宽度: 140px
- 高度: 60px
- 数字: H3 (20px) 加粗
- 标签: Body Small (14px)

## 过滤栏组件

| 过滤项     | 类型       | 说明                                |
| ---------- | ---------- | ----------------------------------- |
| 搜索       | Input      | 按任务名称搜索，支持模糊匹配        |
| 状态       | Select     | 全部/待执行/执行中/成功/失败/已取消 |
| 迁移类型   | Select     | 全部/同构迁移/异构迁移              |
| 源数据源   | Select     | 选择源数据源筛选                    |
| 目标数据源 | Select     | 选择目标数据源筛选                  |
| 时间范围   | DatePicker | 创建时间范围筛选                    |

**过滤栏样式**:

- 高度: 48px
- 每个过滤项间距: 12px
- 支持清空所有过滤条件

## 任务列表表格

| 列         | 说明                     | 宽度  |
| ---------- | ------------------------ | ----- |
| 任务名称   | 链接到任务详情页         | 200px |
| 源数据源   | 数据源名称 + 类型图标    | 150px |
| 目标数据源 | 数据源名称 + 类型图标    | 150px |
| 迁移范围   | 单表/多表/单库/多库      | 100px |
| 迁移模式   | 全量/增量/全量+增量      | 120px |
| 数据量     | 已迁移数据量（行数）     | 120px |
| 进度       | 进度条显示完成百分比     | 150px |
| 状态       | 任务执行状态             | 100px |
| 创建人     | 用户名 + 头像            | 120px |
| 创建时间   | YYYY-MM-DD HH:mm         | 140px |
| 操作       | 详情/执行/编辑/删除/日志 | 180px |

### 状态标签样式

| 状态   | 颜色    | 标签样式                |
| ------ | ------- | ----------------------- |
| 待执行 | #6B7280 | 灰色实心标签            |
| 执行中 | #3B82F6 | 蓝色实心标签 + 动态图标 |
| 成功   | #10B981 | 绿色实心标签            |
| 失败   | #EF4444 | 红色实心标签            |
| 已取消 | #9CA3AF | 灰色空心标签            |
| 已暂停 | #F59E0B | 黄色实心标签            |

### 进度条样式

- 高度: 8px
- 背景色: #E2E8F0
- 完成色: #2563EB（成功时为 #10B981）
- 显示百分比文字（如 "75%"）
- 执行中时进度条带动画效果

### 迁移范围图标

| 范围 | 图标         | 说明           |
| ---- | ------------ | -------------- |
| 单表 | 单个表格图标 | 迁移单个表     |
| 多表 | 多表格图标   | 迁移多个表     |
| 单库 | 数据库图标   | 迁移整个数据库 |
| 多库 | 多数据库图标 | 迁移多个数据库 |

## 操作功能

### 单任务操作

| 操作     | 说明               | 条件              |
| -------- | ------------------ | ----------------- |
| 查看详情 | 跳转到任务详情页   | 所有状态          |
| 执行任务 | 手动启动执行任务   | 待执行/已暂停状态 |
| 暂停任务 | 暂停正在执行的任务 | 执行中状态        |
| 继续执行 | 从断点继续执行     | 已暂停状态        |
| 查看日志 | 跳转到日志中心页   | 所有状态          |
| 编辑任务 | 编辑任务配置       | 待执行状态        |
| 复制任务 | 复制配置创建新任务 | 所有状态          |
| 删除任务 | 删除任务配置       | 待执行/已取消状态 |

### 批量操作

- 批量执行: 勾选多个待执行任务批量启动
- 批量暂停: 勾选多个执行中任务批量暂停
- 批量删除: 勾选多个待执行任务批量删除

**批量操作样式**:

- 表格首列复选框
- 选中后在顶部显示批量操作按钮栏
- 危险操作（删除）需二次确认

## 任务状态流转

```
待执行 → 执行中 → 成功
         ↓        ↑
       已暂停 → 继续执行
         ↓
       失败 → 重试 → 执行中
         ↓
       已取消
```

## 创建任务入口

点击"新建迁移任务"按钮进入配置页，支持两种创建模式：

| 模式     | 说明                      |
| -------- | ------------------------- |
| 快速创建 | 单表迁移，简单配置        |
| 高级配置 | 多表/库迁移，完整配置选项 |

**按钮样式**:

- 主按钮，Primary 色 (#2563EB)
- 图标: Plus 图标
- 位置: 页面顶部操作栏右侧

## 刷新机制

- 手动刷新: 点击刷新按钮
- 自动刷新: 可配置自动刷新间隔（30s/60s/5min）
- 执行中任务自动更新进度

## 导出功能

支持导出任务列表报表:

- Excel 格式
- 包含任务基本信息、状态、进度统计
- 可选择导出当前筛选结果或全部任务

## 权限控制

| 操作          | 管理员 | 数据工程师 | 数据分析师 | 只读者 |
| ------------- | ------ | ---------- | ---------- | ------ |
| 查看任务列表  | ✓      | ✓          | ✓          | ✓      |
| 新建迁移任务  | ✓      | ✓          | ✗          | ✗      |
| 执行任务      | ✓      | ✓          | ✗          | ✗      |
| 暂停/继续任务 | ✓      | ✓          | ✗          | ✗      |
| 编辑任务      | ✓      | ✓          | ✗          | ✗      |
| 删除任务      | ✓      | ✗          | ✗          | ✗      |
| 导出报表      | ✓      | ✓          | ✗          | ✗      |

## 交互规范

- **点击任务名称**: 跳转到任务详情页
- **点击数据源名称**: 跳转到数据源配置页
- **自动刷新**: 执行中任务状态自动更新
- **异常行高亮**: 失败任务行背景浅红色 (#FEE2E2)
- **进度条动画**: 执行中任务进度条带渐变动画
- **状态提示**: 状态变更时 Toast 提示

## 性能考虑

- 分页加载，默认每页 20 条
- 统计卡片数据缓存 5 分钟
- 表格支持虚拟滚动（大量数据时）
- 执行中任务进度定时轮询更新

## 错误提示

| 场景           | 提示方式                      |
| -------------- | ----------------------------- |
| 数据源连接失败 | 红色 Toast 提示               |
| 任务执行失败   | 表格行高亮 + Tooltip 显示原因 |
| 删除失败       | Modal 弹窗显示详细错误        |
| 权限不足       | Toast 提示 "无权限执行此操作" |
