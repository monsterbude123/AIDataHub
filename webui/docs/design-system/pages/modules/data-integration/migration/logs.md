# 迁移日志中心页 - 页面设计规范

> 页面路径: `/integration/migration/[taskId]/logs`
> 所属模块: 数据集成管理模块
> 覆盖 MASTER 规范: 流式日志展示，搜索过滤，实时跟踪

## 页面目标

统一收集展示迁移任务执行日志，支持实时跟踪、历史查询和问题排查。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│ 面包屑: 数据集成 > 数据迁移 > [任务名称] > 日志               │
│ 任务信息卡片: 名称 + 状态 + 当前执行进度                      │
├─────────────────────────────────────────────────────────────┤
│ 过滤栏: [表选择] [执行ID] [时间范围] [级别] [关键词]           │
│ 操作栏: [自动刷新开关] [下载日志] [清空展示]                  │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ 日志流式展示区域                                             │
│                                                             │
│ 加载更多 / 实时追加                                          │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

## 任务信息卡片

在日志页顶部显示任务上下文：

```
┌─────────────────────────────────────────────────────────────┐
│ 任务: 订单数据迁移                          状态: ⟳ 执行中    │
│ 执行ID: exec-001234                        进度: 65%        │
│ 当前表: orders                             已迁移: 1.25M 行  │
└─────────────────────────────────────────────────────────────┘
```

| 元素     | 说明             |
| -------- | ---------------- |
| 任务名称 | 链接到任务详情页 |
| 状态     | 当前执行状态标签 |
| 执行ID   | 当前执行唯一标识 |
| 进度     | 进度百分比       |
| 当前表   | 正在处理的表名   |
| 已迁移   | 已迁移数据量     |

**卡片样式**:

- 高度: 48px
- 背景: #F8FAFC
- 信息项间距: 24px

## 过滤栏组件

| 过滤项   | 类型        | 说明                     |
| -------- | ----------- | ------------------------ |
| 表选择   | Select      | 选择特定表查看日志       |
| 执行ID   | Select      | 选择历史执行记录         |
| 时间范围 | DatePicker  | 日志时间范围筛选         |
| 日志级别 | MultiSelect | DEBUG/INFO/WARN/ERROR    |
| 关键词   | Input       | 搜索关键词，支持模糊匹配 |

**级联筛选**:

- 选择执行ID后，时间范围自动调整
- 选择表后，仅显示该表相关日志

**过滤栏样式**:

- 高度: 48px
- 过滤项间距: 12px
- 清空过滤按钮

## 实时跟踪功能

### 自动刷新

- 开关控制自动刷新
- 默认开启，每 10 秒刷新
- 执行中状态强制开启
- 新日志追加到顶部
- 新日志提示条显示数量

**新日志提示样式**:

```
┌─────────────────────────────────────────────────────────────┐
│ 有 15 条新日志                               [立即查看]       │
└─────────────────────────────────────────────────────────────┘
```

### 实时进度指示器

正在执行时显示：

```
┌─────────────────────────────────────────────────────────────┐
│ ⟳ 正在执行: orders 表，批次 125/200                         │
│ 当前速率: 5,000 行/秒                                       │

```

## 执行阶段日志

按迁移执行阶段组织日志：

| 阶段      | 说明                 |
| --------- | -------------------- |
| 初始化    | 任务启动，连接数据源 |
| 数据读取  | 从源数据源读取数据   |
| 数据转换  | 字段映射和类型转换   |
| 数据写入  | 写入目标数据源       |
| 数据校验  | 一致性校验           |
| 完成/失败 | 执行结束             |

**阶段分隔线样式**:

- 背景: #F1F5F9
- 阶段名称居中显示
- 时间戳标注

## 操作功能

### 下载日志

| 格式 | 说明                 |
| ---- | -------------------- |
| TXT  | 纯文本格式           |
| JSON | 结构化格式，含元数据 |
| CSV  | 表格格式，便于分析   |

**下载范围**:

- 当前筛选条件下的所有日志
- 单次执行的完整日志
- 单表的执行日志

### 日志操作

| 操作     | 说明                   |
| -------- | ---------------------- |
| 复制日志 | 点击日志行复制完整内容 |
| 搜索高亮 | 关键词在日志中黄色高亮 |
| 清空展示 | 清空当前展示，重新加载 |
| 跳转详情 | 点击表名跳转到表详情   |

### 错误日志处理

对于错误日志提供快捷操作：

| 操作         | 说明                   |
| ------------ | ---------------------- |
| 查看该行数据 | 展示出问题的数据行     |
| 跳转字段映射 | 跳转配置页修改映射     |
| 忽略继续     | 标记忽略该错误继续执行 |
| 标记处理     | 标记该错误已处理       |

## 性能考虑

- 流式加载，不一次性加载所有日志
- 搜索在服务端完成，分页返回
- 最多显示 10,000 条日志，超出需导出
- 虚拟滚动优化大量日志渲染
- 日志分页加载，每页 200 条

## 与任务详情的联动

- 从任务详情页点击"查看日志"跳转到此页
- 自动带上任务上下文信息
- 日志中点击表名可跳转到任务详情的表详情 Tab
- 日志中点击错误详情可跳转到字段映射配置

## 错误诊断辅助

### 错误类型识别

自动识别常见错误类型并提供建议：

| 错误类型     | 诊断建议                     |
| ------------ | ---------------------------- |
| 连接超时     | 检查数据源网络连通性         |
| 类型不匹配   | 修改字段映射或添加类型转换   |
| 字段不存在   | 检查源表结构或修改映射       |
| 主键冲突     | 清理目标表或设置冲突处理策略 |
| 数据校验失败 | 检查数据一致性，重新执行     |

## 日志归档

历史日志归档策略：

- 执行完成后日志归档存储
- 归档日志可随时查看
- 归档日志保留 30 天（可配置）
- 重要错误日志永久保留
