# 数据迁移子模块 - 页面索引

> 所属模块: 数据集成管理模块 (`data-integration`)
> 模块路径: `/integration/migration`

## 模块说明

数据迁移是数据集成的核心子模块，负责同/异构数据源之间的数据迁移任务管理与运维监控。支持单表、多表、单库、多库等多种迁移场景，提供可视化的迁移配置、实时进度监控和统一日志管理。

## 功能页面

| 页面         | 文件                           | 路由                                   | 说明                         |
| ------------ | ------------------------------ | -------------------------------------- | ---------------------------- |

| 迁移日志中心 | [logs.md](./logs.md)           | `/integration/migration/[taskId]/logs` | 迁移任务执行日志查看         |

## 核心特性

- **多源多目标支持**: 支持 MySQL、PostgreSQL、Oracle、SQL Server、MongoDB 等主流数据源
- **灵活迁移范围**: 单表、多表、单库、多库、全量/增量迁移
- **同构/异构迁移**: 支持同类型数据源迁移和跨类型异构迁移
- **断点续传**: 任务中断后支持从断点继续执行
- **数据校验**: 迁移完成后自动进行数据一致性校验
- **实时监控**: 迁移进度实时展示，支持执行状态追踪
- **失败重试**: 支持失败自动重试和手动重试机制
- **统一日志**: 迁移过程日志统一收集，便于问题排查

## 迁移场景支持

### 按迁移范围

| 场景     | 说明                             |
| -------- | -------------------------------- |
| 单表迁移 | 选择源表迁移到目标表             |
| 多表迁移 | 批量选择多个源表迁移到对应目标表 |
| 单库迁移 | 整个数据库所有表迁移             |
| 多库迁移 | 多个数据库批量迁移               |

### 按数据源类型

| 场景     | 说明                                       |
| -------- | ------------------------------------------ |
| 同构迁移 | 同类型数据源迁移（如 MySQL → MySQL）       |
| 异构迁移 | 跨类型数据源迁移（如 Oracle → PostgreSQL） |

### 按迁移模式

| 模式      | 说明                            |
| --------- | ------------------------------- |
| 全量迁移  | 全部数据一次性迁移              |
| 增量迁移  | 基于时间戳/增量标识迁移新增数据 |
| 全量+增量 | 先全量迁移，后续持续增量同步    |

## 与其他模块的关联

| 关联模块   | 关联方式                   |
| ---------- | -------------------------- |
| 数据源管理 | 迁移任务使用已配置的数据源 |

## 技术实现要点

- **迁移引擎**: 基于 Apache SeaTunnel / DataX 实现
- **状态管理**: Redis 缓存迁移状态和进度
- **日志收集**: Elasticsearch 存储迁移日志
- **任务队列**: 支持优先级调度和资源分配
- **断点续传**: 记录已迁移数据位置，支持恢复
