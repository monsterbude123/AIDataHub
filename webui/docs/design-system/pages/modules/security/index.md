# 数据安全管理模块 - 页面索引

> 模块路由前缀: `/security`
> 菜单位置: 一级菜单「数据安全」

## 模块说明

提供数据脱敏、分级分类、数据水印、数据加密能力，保障数据安全。

## 功能页面

### 一级菜单页面

| 页面         | 类型  | 菜单名称 | 路由                        | 文档                                       |
| ------------ | ----- | -------- | --------------------------- | ------------------------------------------ |
| 脱敏规则配置 | `[M]` | 数据脱敏 | `/security/desensitization` | [desensitization.md](./desensitization.md) |
| 分级分类管理 | `[M]` | 分级分类 | `/security/classification`  | [classification.md](./classification.md)   |
| 数据水印     | `[M]` | 数据水印 | `/security/watermark`       | [watermark.md](./watermark.md)             |

**页面类型说明**：

- `[M]` 菜单页面 - 出现在侧边导航菜单

## 核心特性

- 多种预置脱敏算法（Hash、遮蔽、出生日期等），支持自定义算法
- 分级分类控制访问权限，用户只能访问低于自身级别数据
- 支持行级数据权限基于用户属性动态过滤
- 多种水印方式，支持部分数据泄露溯源
- 支持静态脱敏和动态脱敏
