# 里程碑管理页 - 页面设计规范

> 页面路径: `/project/[id]/milestones`
> 覆盖 MASTER 规范: 时间线组件

## 页面目标

管理项目各阶段的里程碑节点，跟踪关键节点完成情况，关联交付物文档。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] > 里程碑管理     │
│ 操作栏: [新建里程碑]                                     │
├─────────────────────────────────────────────────────────┤
│ 阶段筛选: [全部] [立项] [规划] [执行] [验收] [结项]       │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 里程碑时间线视图                                         │
│                                                         │
│  ●───────●───────○───────○                              │
│  │       │       │       │                              │
│  M1      M2      M3      M4                             │
│  已完成   已完成   进行中   待开始                        │
│                                                         │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 里程碑列表表格                                           │
│                                                         │
│ 分页                                                     │
└─────────────────────────────────────────────────────────┘
```

## 阶段筛选组件

| 筛选项 | 说明                 |
| ------ | -------------------- |
| 全部   | 显示所有里程碑       |
| 立项   | 仅显示立项阶段里程碑 |
| 规划   | 仅显示规划阶段里程碑 |
| 执行   | 仅显示执行阶段里程碑 |
| 验收   | 仅显示验收阶段里程碑 |
| 结项   | 仅显示结项阶段里程碑 |

**样式**: Tab 筛选样式，选中高亮

## 里程碑时间线视图

**时间线布局**:

```
横向时间线:
  ●───────●───────○───────○
  │       │       │       │
  M1      M2      M3      M4
  已完成   已完成   进行中   待开始
  01-15   02-20   03-30   04-15
```

**节点样式**:

| 状态   | 节点样式                       | 连线样式          |
| ------ | ------------------------------ | ----------------- |
| 已完成 | 实心圆 + Success 色            | 实线 + Success 色 |
| 进行中 | 实心圆 + Warning 色 + 脉冲动画 | 实线 + Pending 色 |
| 待开始 | 空心圆 + Pending 色            | 虚线 + Pending 色 |
| 已延期 | 实心圆 + Error 色              | 实线 + Error 色   |

**节点信息**:

- 里程碑名称
- 状态标签
- 计划完成日期

**交互**:

- 点击节点显示详情弹窗
- 悬浮显示进度摘要

## 里程碑列表表格

| 列           | 说明                              | 宽度  |
| ------------ | --------------------------------- | ----- |
| 里程碑名称   |                                   | 200px |
| 所属阶段     | 标签：立项/规划/执行/验收/结项    | 100px |
| 计划时间     | YYYY-MM-DD                        | 120px |
| 实际完成时间 | YYYY-MM-DD，未完成显示「待完成」  | 120px |
| 状态         | 标签：待开始/进行中/已完成/已延期 | 100px |
| 负责人       | 用户名 + 头像                     | 120px |
| 交付物       | 关联文档链接，可点击跳转          | 150px |
| 操作         | 编辑/删除/标记完成                | 120px |

**状态标签样式**:

| 状态   | 颜色                 |
| ------ | -------------------- |
| 待开始 | #6B7280 (Pending)    |
| 进行中 | #3B82F6 (Processing) |
| 已完成 | #10B981 (Success)    |
| 已延期 | #EF4444 (Error)      |

## 新建里程碑弹窗

**表单字段**:

| 字段         | 类型       | 必填 | 说明                     |
| ------------ | ---------- | ---- | ------------------------ |
| 里程碑名称   | Input      | 是   | 最大 100 字符            |
| 所属阶段     | Select     | 是   | 立项/规划/执行/验收/结项 |
| 计划完成时间 | DatePicker | 是   |                          |
| 负责人       | Select     | 是   | 从项目成员中选择         |
| 交付物说明   | TextArea   | 否   | 最大 500 字符            |
| 关联文档     | Select     | 否   | 从项目文档中选择         |

**表单布局**:

- 两列布局
- 左侧：基本信息
- 右侧：交付物信息

## 编辑里程碑弹窗

同新建弹窗，额外显示：

- 当前状态（只读）
- 实际完成时间（只读，已完成时显示）

## 标记完成操作

点击「标记完成」：

- 二次确认弹窗
- 确认后：
  - 状态变更为「已完成」
  - 自动记录实际完成时间（当前时间）
  - 发送通知给项目负责人

点击时间线节点或表格行展开：

```
│                                      │
│ 所属阶段: 立项阶段                    │
│ 计划时间: 2024-01-15                  │
│ 实际完成: 2024-01-14                  │
│ 负责人: 张三                          │
│                                      │

│ 状态: ✓ 已完成                        │
│                                      │

```

## 交互规范

- **新建**: 点击「新建里程碑」按钮，弹窗打开表单
- **编辑**: 表格操作菜单 → 编辑，打开编辑弹窗
- **删除**: 表格操作菜单 → 删除，二次确认
- **标记完成**: 表格操作菜单 → 标记完成，二次确认
- **查看详情**: 点击时间线节点或表格行展开详情
- **阶段筛选**: 点击阶段 Tab 快速筛选

## 自动提醒

- 里程碑临近计划时间（提前 3 天）：发送提醒通知给负责人
- 里程碑超期未完成：自动标记为「已延期」，发送告警通知
- 里程碑完成：发送通知给项目负责人
