# 项目详情页 - 页面设计规范

> 页面路径: `/project/[id]`
> 覆盖 MASTER 规范: Tab 布局，阶段进度组件

## 页面目标

展示项目基本信息、阶段进度、成员管理，作为项目子页面的入口枢纽。

## 布局结构

``
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] │
├─────────────────────────────────────────────────────────┤
│ 项目头部 │
│ ┌─────────────────────────────────────────────────────┐ │
│ │ 项目名称 状态: 进行中 [编辑] [删除] │ │
│ │ 项目编号: PRJ-2024-001 负责人: 张三 │ │
│ │ 当前阶段: 执行阶段 进度: ████░░ 65% │ │
│ └─────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────┤
│ 阶段进度条 │
│ │
│ ●─────────●─────────●─────────○─────────○ │
│ 立项 规划 执行 验收 结项 │
│ ✓完成 ✓完成 进行中 待开始 待开始 │
│ │
│ [推进阶段] [回退阶段] │
├─────────────────────────────────────────────────────────┤
│ Tab 切换: [概览] [任务管理] [里程碑] [文档] [统计] [成员] │
├─────────────────────────────────────────────────────────┤
│ │
│ Tab 内容区域 │
│ │
└─────────────────────────────────────────────────────────┘

```

## 项目头部区域

**头部信息卡片**:

| 信息项 | 显示方式 | 说明 |
|--------|----------|------|
| 项目名称 | H1 (28px) | 可点击编辑 |
| 状态标签 | Tag | 进行中(蓝)/已完成(绿)/已归档(灰) |
| 项目编号 | Body Small | 自动生成 |
| 负责人 | 用户头像 + 名称 | 可点击切换 |
| 当前阶段 | Tag | 显示阶段名称 |
| 进度 | 进度条 + 百分比 | 0-100% |

**操作按钮**:
- 编辑: 仅项目经理可见
- 删除: 仅项目经理可见，二次确认

## 阶段进度组件

**阶段节点显示**:

```

●─────────●─────────●─────────○─────────○
立项 规划 执行 验收 结项
✓完成 ✓完成 进行中 待开始 待开始

```

**节点样式**:
- 已完成: 实心圆点 + Success 色 (#10B981)
- 进行中: 实心圆点 + Warning 色 (#F59E0B) + 呼吸动画
- 待开始: 空心圆点 + Pending 色 (#6B7280)

**阶段操作**:

| 操作 | 条件 | 确认 |
|------|------|------|
| 推进阶段 | 当前阶段未完成 | 二次确认弹窗 |
| 回退阶段 | 已完成阶段可回退 | 填写原因弹窗 |

**阶段变更弹窗**:

推进弹窗:
- 显示: 当前阶段 → 目标阶段
- 确认按钮: 「确认推进」

回退弹窗:
- 显示: 当前阶段 → 目标阶段
- 必填: 回退原因 (TextArea)
- 确认按钮: 「确认回退」

## Tab 切换

| Tab | 路由 | 说明 |
|-----|------|------|
| 概览 | `/project/[id]` (默认) | 项目基本信息、关键指标、动态 |
| 任务管理 | `/project/[id]/tasks` | 跳转到任务管理页 |
| 里程碑 | `/project/[id]/milestones` | 跳转到里程碑管理页 |
| 文档 | `/project/[id]/docs` | 跳转到文档管理页 |
| 统计 | `/project/[id]/stats` | 跳转到项目统计页 |
| 成员 | 本页 Tab | 成员列表管理 |

## 概览 Tab 内容

### 基本信息卡片

| 信息项 | 说明 |
|--------|------|
| 项目描述 | 项目目标说明 |
| 开始时间 | YYYY-MM-DD |
| 预计完成时间 | YYYY-MM-DD |
| 实际完成时间 | 未完成显示「待完成」 |
| 创建时间 | YYYY-MM-DD |

### 关键指标卡片

```

┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ 任务总数 │ │ 里程碑 │ │ 文档数 │ │ 成员数 │
│ 45 │ │ 10 │ │ 28 │ │ 6 │
│ 完成: 28 │ │ 完成: 6 │ │ │ │ │
└──────────┘ └──────────┘ └──────────┘ └──────────┘

```

### 最近动态时间线

显示最近 10 条项目动态:
- 阶段变更
- 任务关联/取消
- 里程碑完成
- 文档上传
- 成员变更

**时间线样式**:
- 左侧: 时间点 + 动态图标
- 右侧: 动态描述 + 操作人 + 时间

## 成员 Tab 内容

### 成员列表表格

| 列 | 说明 |
|----|------|
| 用户头像 + 名称 | |
| 角色 | 项目经理/成员/只读者 |
| 加入时间 | YYYY-MM-DD |
| 操作 | 移除（仅项目经理可操作） |

### 添加成员弹窗

| 字段 | 类型 | 说明 |
|------|------|------|
| 选择用户 | MultiSelect | 从系统用户中选择 |
| 角色 | Select | 项目经理/成员/只读者 |

### 角色变更

- 点击角色下拉直接变更
- 仅项目经理可变更他人角色
- 项目经理角色变更需二次确认（防止无经理情况）

## 交互规范

- **编辑项目**: 点击编辑按钮，弹窗修改基本信息
- **阶段推进**: 点击推进按钮，确认后进入下一阶段
- **阶段回退**: 点击回退按钮，填写原因后回退
- **添加成员**: 点击添加按钮，选择用户和角色
- **移除成员**: 操作菜单 → 移除，二次确认
- **角色变更**: 点击角色下拉选择新角色

## 权限控制

| 操作 | 项目经理 | 成员 | 只读者 |
|------|----------|------|--------|
| 编辑项目信息 | ✓ | ✗ | ✗ |
| 删除项目 | ✓ | ✗ | ✗ |
| 推进/回退阶段 | ✓ | ✗ | ✗ |
| 添加/移除成员 | ✓ | ✗ | ✗ |
| 变更成员角色 | ✓ | ✗ | ✗ |
| 查看项目信息 | ✓ | ✓ | ✓ |
```
