# 统一日志中心页 - 页面设计规范

> 页面路径: `/project/[id]/scheduler/logs`
> 所属项目: 数据项目管理模块
> 覆盖 MASTER 规范: 流式日志展示，搜索过滤

## 页面目标

统一收集查看项目内所有任务运行日志，支持实时跟踪和历史查询。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] > 任务调度 > 日志中心 │
│ 项目信息: 当前阶段 [执行阶段]  进度 65%                   │
├─────────────────────────────────────────────────────────┤
│ 过滤栏: [DAG选择] [任务选择] [执行ID] [时间范围] [级别] [关键词] │
│ 自动刷新: [开关]  [下载日志]                             │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 日志列表流式展示                                         │
│                                                         │
│ 加载更多                                                 │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

## 项目信息头部

在日志中心顶部显示项目上下文：

- 项目名称
- 当前阶段
- 项目进度

## 过滤栏组件

| 过滤项   | 类型        | 说明                       |
| -------- | ----------- | -------------------------- |
| DAG选择  | Select      | 选择项目内特定DAG          |
| 任务选择 | Select      | 选择DAG内特定任务          |
| 执行ID   | Input       | 输入某次执行ID查看完整日志 |
| 时间范围 | DatePicker  | 开始结束时间范围           |
| 日志级别 | MultiSelect | DEBUG/INFO/WARN/ERROR      |
| 关键词   | Input       | 搜索关键词，支持模糊匹配   |

**级联筛选**:

- 选择 DAG 后，任务选择下拉仅显示该 DAG 内的任务
- 未选择 DAG 时，任务选择显示项目内所有任务

## 日志展示

每条日志展示:

```
┌──────────────────────────────────────────────────────────┐
│ 2024-01-15 10:00:15  [INFO]  任务: 数据接入-订单表         │
│ 开始执行数据接入任务，源表: mysql_orders                  │
│                                                         │
│ 2024-01-15 10:00:20  [INFO]  任务: 数据接入-订单表         │
│ 连接数据源成功                                           │
│                                                         │
│ 2024-01-15 10:01:30  [WARN]  任务: 数据接入-订单表         │
│ 数据量较大，预计耗时5分钟                                 │
│                                                         │
│ 2024-01-15 10:05:00  [ERROR]  任务: 数据接入-订单表        │
│ 执行失败: 连接超时                                       │
│ 详细错误: Connection timeout after 30000ms               │
└──────────────────────────────────────────────────────────┘
```

**日志格式**:

- **时间戳**: YYYY-MM-DD HH:mm:ss，灰色 (#6B7280)，左侧
- **日志级别**: 带颜色标签
- **任务名称**: 显示来源任务，可点击跳转
- **日志内容**: 自动换行，超长可折叠

**日志级别样式**:

| 级别  | 颜色    | 标签样式              |
| ----- | ------- | --------------------- |
| DEBUG | #6B7280 | 灰色标签              |
| INFO  | #3B82F6 | 蓝色标签              |
| WARN  | #F59E0B | 黄色标签              |
| ERROR | #EF4444 | 级色标签 + 红色背景行 |

## 交互规范

### 自动刷新

- 开启后每10秒刷新追加新日志
- 支持暂停/继续
- 新日志滚动到视图顶部时有提示

### 日志操作

| 操作       | 说明                           |
| ---------- | ------------------------------ |
| 加载更多   | 滚动到底部加载更多历史日志     |
| 关键词高亮 | 搜索关键词在日志内容中黄色高亮 |
| 下载日志   | 下载当前筛选条件的完整日志文件 |
| 清空展示   | 清空当前展示的日志             |
| 复制日志   | 点击日志行复制完整内容         |

### 任务跳转

- 点击日志中的任务名称跳转到任务运维页
- 点击 DAG 名称跳转到 DAG 编排页

## 特殊设计

### 错误日志突出

- ERROR 级别日志行红色背景 (#FEE2E2)
- 错误堆栈信息折叠显示，点击展开
- 失败任务日志自动置顶

### 实时执行跟踪

- 正在执行的任务日志实时追加
- 显示执行进度指示器
- 支持中途取消执行（仅项目经理和成员）

### 项目级过滤

- 默认只显示当前项目内任务日志
- 支持跨项目日志查询（需系统级权限）

## 性能考虑

- 流式加载，不一次性加载所有日志
- 搜索在服务端完成，分页返回
- 高亮不重渲染整个列表，只高亮当前页
- 最多显示10000条日志，超出需导出查看

## 日志下载

支持下载格式:

- TXT: 纯文本格式
- JSON: 结构化格式，含元数据

下载范围:

- 当前筛选条件下的所有日志
- 单次执行的完整日志

## 权限控制

| 操作     | 项目经理 | 成员 | 只读者 |
| -------- | -------- | ---- | ------ |
| 查看日志 | ✓        | ✓    | ✓      |
| 搜索过滤 | ✓        | ✓    | ✓      |
| 下载日志 | ✓        | ✓    | ✗      |
| 实时跟踪 | ✓        | ✓    | ✓      |
| 取消执行 | ✓        | ✓    | ✗      |

## 与任务运维的联动

- 从任务运维页点击"查看日志"跳转到此页，自动带上任务筛选条件
- 日志中点击任务名称可跳转回任务运维页
- 两页面共享项目上下文信息
