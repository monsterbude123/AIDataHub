# 任务调度子模块 - 页面索引

> 所属模块: 数据开发项目管理模块 (`data-development-project`)
> 模块路径: `/project/[id]/scheduler`

## 模块说明

任务调度是数据项目的核心子模块，负责项目内任务的 DAG 可视化编排、调度执行与运维监控。所有调度任务都与项目关联，实现项目级任务统一管理。

## 与项目模块的关系

- **项目级任务管理**: 所有 DAG 任务归属于特定项目
- **权限继承**: 任务调度权限继承项目角色权限
- **任务关联**: 项目任务管理页关联的是调度模块的 DAG 任务
- **统一运维**: 项目内所有任务统一监控和日志管理

| 统一日志中心 | [log-center.md](./log-center.md) | `/project/[id]/scheduler/logs`  | 项目任务日志查看  |

## 核心特性

- **项目级 DAG 编排**: 可视化配置项目内任务依赖关系
- **多触发策略**: 定时调度、事件触发、依赖触发
- **任务队列优先级**: 任务优先级调度，资源负载均衡
- **失败重试机制**: 支持失败重试、超时告警、多渠道通知
- **数据对账检查**: 来源表和目的表数据一致性校验
- **统一日志管理**: 项目内所有任务日志统一收集查看

## 权限继承

任务调度模块权限继承项目角色权限：

| 操作          | 项目经理 | 成员 | 只读者 |
| ------------- | -------- | ---- | ------ |
| 创建/编辑 DAG | ✓        | ✓    | ✗      |
| 删除 DAG      | ✓        | ✗    | ✗      |
| 执行/停止任务 | ✓        | ✓    | ✗      |
| 查看任务状态  | ✓        | ✓    | ✓      |
| 查看日志      | ✓        | ✓    | ✓      |
| 配置告警      | ✓        | ✓    | ✗      |
