# 数据开发项目管理模块 - 页面索引

> 模块路由前缀: `/project`
> 菜单位置: 一级菜单「数据项目」

## 模块说明

数据开发项目全生命周期管理模块，支持项目立项、规划、执行、验收、结项五个阶段，阶段可回退。项目作为容器关联各模块任务，实现跨模块任务协同与进度追踪。

## 核心特性

- **全生命周期管理**: 立项 → 规划 → 执行 → 验收 → 结项
- **阶段可回退**: 验收不通过可回到执行阶段，规划调整可回到立项阶段
- **项目为容器**: 关联数据集成、治理、调度、分析等模块的具体任务
- **项目级权限**: 项目成员角色（项目经理、成员、只读者），项目内所有资源继承权限

详见 [scheduler 模块文档](./scheduler/index.md)。

## 阶段流转

```
立项 → 规划 → 执行 → 验收 → 结项
  ↑______|      |      |
  |_____________|______|
```

阶段回退规则：

- 验收不通过 → 回退到执行阶段
- 规划调整 → 回退到立项阶段
- 所有回退操作需填写原因并记录

## 项目角色权限

| 角色     | 权限                                               |
| -------- | -------------------------------------------------- |
| 项目经理 | 项目全部操作权限，包括删除项目、管理成员、阶段变更 |
| 成员     | 查看项目、关联任务、上传文档、编辑里程碑           |
| 只读者   | 仅查看项目信息，不可编辑                           |
