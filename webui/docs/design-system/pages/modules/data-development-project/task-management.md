# 任务管理页 - 页面设计规范

> 页面路径: `/project/[id]/tasks`
> 覆盖 MASTER 规范: 关联任务弹窗

## 页面目标

展示项目关联的所有任务，支持关联现有模块任务、取消关联、批量操作。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] > 任务管理       │
│ 操作栏: [关联任务] [批量取消关联]                        │
├─────────────────────────────────────────────────────────┤
│ 过滤栏: [搜索] [任务类型] [状态] [负责人]                │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 任务列表表格                                             │
│                                                         │
│ 分页                                                     │
└─────────────────────────────────────────────────────────┘
```

## 过滤栏组件

| 过滤项   | 类型   | 说明                                |
| -------- | ------ | ----------------------------------- |
| 搜索     | Input  | 按任务名称搜索                      |
| 任务类型 | Select | 数据集成/数据治理/任务调度/数据分析 |
| 状态     | Select | 待执行/执行中/已完成/失败           |
| 负责人   | Select | 用户下拉选择                        |

## 关联任务弹窗

**步骤 1: 选择任务类型**

```
┌──────────────────────────────────────┐
│ 选择要关联的任务类型                  │
│                                      │
│ ┌────────────┐ ┌────────────┐       │
│ │ 数据集成    │ │ 数据治理    │       │
│ │ Database   │ │ Shield     │       │
│ └────────────┘ └────────────┘       │
│ ┌────────────┐ ┌────────────┐       │
│ │ 任务调度    │ │ 数据分析    │       │
│ │ Clock      │ │ Chart      │       │
│ └────────────┘ └────────────┘       │
│                                      │
│              [下一步]                 │
└──────────────────────────────────────┘
```

**步骤 2: 选择具体任务**

根据选择的类型，显示对应模块的任务列表:

| 任务类型 | 数据来源         | 选择方式 |
| -------- | ---------------- | -------- |
| 数据集成 | 数据集成模块任务 | 表格勾选 |
| 数据治理 | 数据治理工单     | 表格勾选 |
| 任务调度 | DAG 任务列表     | 表格勾选 |
| 数据分析 | 分析任务列表     | 表格勾选 |

弹窗显示该类型下的可用任务:

- 支持搜索筛选
- 支持多选
- 显示任务基本信息

**步骤 3: 设置关联信息**

| 字段         | 类型       | 必填 | 说明             |
| ------------ | ---------- | ---- | ---------------- |
| 计划开始时间 | DatePicker | 否   |                  |
| 计划结束时间 | DatePicker | 否   |                  |
| 负责人       | Select     | 否   | 从项目成员中选择 |

**完成关联**:

- 点击「确认关联」保存
- 关联成功后刷新任务列表

## 批量操作

### 批量选择

- 表格首列复选框
- 全选/取消全选按钮

### 批量取消关联

- 选中任务后点击「批量取消关联」
- 二次确认弹窗
- 确认后批量取消关联

## 任务详情跳转

点击任务名称，跳转到对应模块的任务详情页:

- 数据集成任务 → `/data-integration/sources/[id]`
- 数据治理工单 → `/governance/data-quality/[id]`
- DAG 任务 → `/project/[id]/scheduler/dag`（项目内调度模块）
- 分析任务 → `/analytics/[id]`

**任务调度说明**: 选择「任务调度」类型时，跳转到项目内的 DAG 编排页创建或选择 DAG 任务。

## 交互规范

- **关联任务**: 点击「关联任务」按钮，打开分步弹窗
- **取消关联**: 操作菜单 → 取消关联，二次确认
- **批量取消**: 选中多个任务 → 批量取消关联 → 二次确认
- **查看详情**: 点击任务名称跳转到原模块
- **刷新状态**: 定时轮询任务状态（每 30 秒）
