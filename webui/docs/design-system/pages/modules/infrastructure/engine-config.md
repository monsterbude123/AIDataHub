# 计算引擎配置页 - 页面设计规范

> 页面路径: `/infrastructure/engine`
> 所属模块: 基础设施管理模块
> 覆盖 MASTER 规范: 分类展示，参数配置表格

## 页面目标

管理数据中台的计算引擎配置（Spark、Flink、DataX等），提供引擎参数模板管理、版本管理和参数继承机制，为数据迁移、数据探查、数据治理等模块提供统一的引擎配置引用。

## 新建引擎配置流程

### 步骤 1: 基本信息

| 配置项   | 类型        | 必填       | 说明                             |
| -------- | ----------- | ---------- | -------------------------------- |
| 配置名称 | Input       | ✓          | 配置唯一标识，如 spark-tenant-a  |
| 引擎类型 | Select      | ✓          | Spark/Flink/DataX/Python/Shell   |
| 引擎版本 | Select      | ✓          | 选择引擎版本                     |
| 配置层级 | Select      | ✓          | 系统级/租户级/项目级             |
| 所属租户 | Select      | 租户级必填 | 租户级配置选择租户               |
| 所属项目 | Select      | 项目级必填 | 项目级配置选择项目               |
| 描述     | TextArea    | ✗          | 配置描述                         |
| 标签     | MultiSelect | ✗          | 配置标签（如 default/high-perf） |

### 步骤 2: 继承设置

| 配置项       | 类型     | 说明                 |
| ------------ | -------- | -------------------- |
| 是否继承上级 | Checkbox | 是否继承上级配置     |
| 继承源配置   | Select   | 选择要继承的上级配置 |

**继承规则**:

- 系统级配置不继承
- 租户级配置继承系统级配置
- 项目级配置继承租户级或系统级配置

### 步骤 3: 参数配置

根据引擎类型显示参数配置表格：

- Spark: 资源配置、执行配置、序列化配置等
- Flink: TM配置、JM配置、状态后端配置等
- DataX: 核心配置、任务配置、插件配置等

**参数配置方式**:

- 填写默认值（新建参数）
- 覆盖继承值（继承配置）
- 新增自定义参数

### 步骤 4: 配置预览

展示合并后的完整配置，确认后保存。

## 引擎配置引用方式

### 任务引用引擎配置

任务创建时通过**引擎引用**指定使用的引擎配置：

```
{
  "taskId": "migration-001",
  "engine": {
    "type": "Spark",
    "configRef": "spark-tenant-a-high",    // 引用引擎配置ID
    "override": {                           // 任务级参数覆盖
      "spark.executor.memory": "16g",
      "spark.executor.instances": "8"
    }
  }
}
```

### 配置引用优先级

任务执行时按以下优先级合并配置：

1. **任务级覆盖参数**（最高优先级）
2. **项目级配置**
3. **租户级配置**
4. **系统级默认配置**（最低优先级）

### 各模块引擎引用示例

**数据迁移模块**:

```
{
  "migrationTask": {
    "engine": {
      "type": "DataX",
      "configRef": "datax-default",
      "override": {
        "channel": 8,
        "batchSize": 10000
      }
    }
  }
}
```

**数据探查模块**:

```
{
  "profilingTask": {
    "engine": {
      "type": "Spark",
      "configRef": "spark-3.x-default"
    }
  }
}
```

**DAG任务节点**:

```
{
  "dagNode": {
    "nodeType": "spark-sql",
    "engineRef": "spark-project-x"
  }
}
```

## 技术实现要点

- **配置存储**: 数据库存储配置参数
- **版本管理**: 配置变更记录版本号和变更内容
- **参数校验**: 配置保存时校验参数有效性
- **引用计数**: 记录配置被引用次数
- **配置缓存**: Redis 缓存活跃配置
- **配置合并**: 执行时按层级合并参数
