# 租户管理页 - 页面设计规范

> 页面路径: `/infrastructure/tenant`
> 所属模块: 基础设施管理模块
> 覆盖 MASTER 规范: 高密度表格，多筛选条件，配置级联

## 页面目标

管理数据中台的多租户配置，包括租户基本信息、资源配额分配、默认队列和引擎配置，为租户下的项目和任务提供配置继承基础。

**配额校验**:

- 配额不能超过系统总配额
- 配额调整后不能低于已分配量
- 配额变更需审批（可配置审批流程）

### 队列绑定操作

| 操作           | 说明                         |
| -------------- | ---------------------------- |
| 绑定新队列     | 从系统队列列表选择绑定到租户 |
| 解绑队列       | 解除队列与租户的绑定关系     |
| 设置默认队列   | 设置租户默认使用的队列       |
| 设置优先级队列 | 按任务优先级分配不同队列     |

**队列绑定规则**:

- 租户只能绑定已创建的系统队列
- 队列可被多个租户共享（配额按比例分配）
- 租户必须至少绑定一个默认队列

### 参数覆盖机制

- 租户级参数**覆盖**系统级同名参数
- 未覆盖参数继承系统级配置
- 支持添加租户专属参数（系统级不存在）

**参数覆盖表格样式**:

- 参数名: 左对齐，灰色背景
- 覆盖值: 输入框，可编辑
- 操作: 删除按钮，红色图标
- 添加参数: 底部添加按钮

## 租户配置继承机制

### 配置继承链

```
系统级默认配置
    ↓ 继承（租户级可覆盖）
租户级配置
    ↓ 继承（项目级可覆盖）
项目级配置
    ↓ 继承（任务级可覆盖）
任务级配置
```

### 租户级覆盖规则

| 规则     | 说明                       |
| -------- | -------------------------- |
| 队列限制 | 租户只能使用绑定的队列     |
| 配额限制 | 租户资源使用不能超过配额   |
| 参数覆盖 | 租户参数覆盖系统级同名参数 |
| 引擎选择 | 租户可选择使用的引擎版本   |

### 配置生效时机

- **新任务创建**: 使用当前租户配置
- **租户配置变更**: 新任务使用新配置，旧任务不受影响
- **配额调整**: 立即生效，超额任务暂停

## 交互规范

- **点击租户名称**: 跳转到租户详情页
- **配额超限提示**: Toast 提示 + 配额调整建议
- **队列解绑确认**: Modal 二次确认，提示影响范围
- **配置变更通知**: 配置变更后通知租户管理员

## 技术实现要点

- **配额计算**: 实时统计租户资源使用量
- **队列隔离**: YARN 队列标签或 K8s Namespace
- **配置缓存**: Redis 缓存租户配置，任务执行时读取
- **配额审计**: 记录配额变更历史和审批记录
