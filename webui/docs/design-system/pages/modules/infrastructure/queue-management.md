# 资源队列管理页 - 页面设计规范

> 页面路径: `/infrastructure/queue`
> 所属模块: 基础设施管理模块
> 覆盖 MASTER 规范: 高密度表格，资源监控图表

## 页面目标

管理 YARN 和 Kubernetes 资源队列配置，为数据迁移、数据治理、任务调度等模块提供任务执行队列资源池。

## 新建队列流程

### 步骤 1: 基本信息

| 配置项   | 类型     | 必填 | 说明             |
| -------- | -------- | ---- | ---------------- |
| 队列名称 | Input    | ✓    | 队queu名称，唯一 |
| 队列类型 | Select   | ✓    | YARN / K8s       |
| 所属集群 | Select   | ✓    | 选择目标集群     |
| 描述     | TextArea | ✗    | 队列描述         |

### 步骤 2: 资源配额

**YARN 队列**:

| 配置项     | 类型       | 说明               |
| ---------- | ---------- | ------------------ |
| 最小内存   | Input (GB) | 队queu最小内存保证 |
| 最大内存   | Input (GB) | 队queu最大内存上限 |
| 最小 vCore | Input      | 队queu最小CPU保证  |
| 最大 vCore | Input      | 队queu最大CPU上限  |
| 资源权重   | Input      | 相对权重，默认 1.0 |

**K8s Namespace**:

| 配置项          | 类型         | 说明          |
| --------------- | ------------ | ------------- |
| CPU Requests    | Input (mCPU) | CPU 请求配额  |
| CPU Limits      | Input (mCPU) | CPU 限制配额  |
| Memory Requests | Input (GB)   | 内存请求配额  |
| Memory Limits   | Input (GB)   | 内存限制配额  |
| Pod 上限        | Input        | 最大 Pod 数量 |

### 步骤 3: 调度策略

| 配置项     | 类型     | 说明                     |
| ---------- | -------- | ------------------------ |
| 调度策略   | Select   | Capacity/Fair/FIFO       |
| 启用优先级 | Checkbox | 是否支持优先级调度       |
| 队列优先级 | Input    | 默认优先级 1-10          |
| 启用抢占   | Checkbox | 是否允许抢占低优先级资源 |

### 步骤 4: 租户绑定

| 配置项   | 类型             | 说明           |
| -------- | ---------------- | -------------- |
| 绑定模式 | Select           | 独占/共享      |
| 绑定租户 | MultiSelect      | 选择绑定的租户 |
| 配额分配 | Input (共享模式) | 各租户配额比例 |

## 队queu与任务调度模块的关联

### 任务执行队列选择

任务创建时通过**队列引用**指定执行队列：

```
{
  "taskId": "migration-001",
  "queue": {
    "ref": "queue-tenant-a-high",    // 引用队列 ID
    "override": {                     // 可选覆盖参数
      "priority": 8                   // 任务优先级覆盖
    }
  }
}
```

### 队列选择策略

| 场景         | 队列选择              |
| ------------ | --------------------- |
| 默认执行     | 使用租户/项目默认队列 |
| 高优先级任务 | 使用高优先级队列      |
| 低优先级任务 | 使用低优先级队列      |
| 大数据量任务 | 使用大配额队列        |
| 测试任务     | 使用测试队列          |

### 任务排队机制

```
任务提交 → 队queu选择 → 资源检查 → 排队等待 → 资源分配 → 执行
                    ↓
               资源不足 → 排队等待 → 抢占(可选) → 执行
```

## 交互规范

- **点击队列名称**: 跳转到队列详情页
- **同步集群状态**: 从集群拉取最新队列状态
- **资源超限提示**: 超过配额时 Toast 提示
- **队列异常告警**: 队列状态异常时显示告警条

## 技术实现要点

- **YARN 队列管理**: 通过 YARN REST API 配置队列
- **K8s Namespace 管理**: 通过 K8s API 创建/更新 ResourceQuota
- **状态同步**: 定时从集群同步队列状态
- **资源监控**: 从 YARN/K8s 获取实时资源使用数据
- **任务调度**: 与任务调度模块集成，提交任务到指定队列
