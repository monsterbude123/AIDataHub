# 资源目录浏览页 - 页面设计规范

> 页面路径: `/data-organization/{type}`，type = business / raw / resource / theme
> 覆盖 MASTER 规范: 无

## 页面目标

按分层浏览数据资源目录，支持增删改维护。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据组织 > [分层] > 目录... │
│ [新增目录] [采集数据] [刷新]        │
├──────────────┬────────────────────┤
│ 目录树       │ 资源卡片列表        │
│              │                    │
│              │                    │
│              │                    │
│              │                    │
└──────────────┴────────────────────┘
```

## 左侧目录树

- 逐层递进展示分类目录
- 支持右键菜单:
  - 新增子节点
  - 新增同级节点
  - 重命名
  - 删除 (确认)
- 支持搜索快速定位节点
- 当前节点高亮
- 点击节点刷新右侧列表

## 右侧资源卡片列表

每张卡片:

- 资源名称
- 资源类型标签
- 数据量 (行数 / 文件数)
- 更新时间
- 操作菜单: 编辑 / 探查 / 入库 / 删除

## 分层说明

页面根据URL type参数展示不同分层:

| Type       | 分层   | 说明                       |
| ---------- | ------ | -------------------------- |
| `business` | 业务库 | 各业务领域原始业务数据库   |
| `raw`      | 原始库 | 保留原始数据，反映原始场景 |
| `resource` | 资源库 | 公共数据集合               |
| `theme`    | 主题库 | 按主题对象整合数据         |

## 交互规范

- 点击卡片进入详情/元数据维护
- 支持拖拽调整目录节点顺序
- 选中节点后右侧展示该节点下所有资源
- 新增数据资源可直接采集到当前目录

## 权限

- 按目录层级配置权限
- 用户只能看到有权限的节点
