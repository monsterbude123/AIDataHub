# 数据组织管理模块 - 页面索引

> 模块路由前缀: `/organization`
> 菜单位置: 一级菜单「数据组织」

## 模块说明

按照方式和规则对数据进行归并存储，实现从生产库到服务库的合理分布存储。分为四个分层：业务库、原始库、资源库、主题库。

## 功能页面

### 一级菜单页面

| 页面         | 类型  | 菜单名称 | 路由                    | 文档                       |
| ------------ | ----- | -------- | ----------------------- | -------------------------- |
| 资源目录浏览 | `[M]` | 资源目录 | `/organization/catalog` | [catalog.md](./catalog.md) |
| 数据入库映射 | `[M]` | 入库映射 | `/organization/mapping` | [mapping.md](./mapping.md) |

**页面类型说明**：

- `[M]` 菜单页面 - 出现在侧边导航菜单

## 分层说明

| 分层       | 说明                               |
| ---------- | ---------------------------------- |
| **业务库** | 各专业领域业务数据库，支撑业务数据 |
| **原始库** | 保留原始数据，反映原始业务场景     |
| **资源库** | 综合各类数据资源建立公共数据集合   |
| **主题库** | 围绕主题对象整合各类数据           |
