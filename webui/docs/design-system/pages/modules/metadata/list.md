# 元数据列表页 - 页面设计规范

> 页面路径: `/metadata/list`
> 覆盖 MASTER 规范: 无

## 页面目标

浏览、搜索、管理所有元数据，支持版本管理和变更订阅。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 元数据管理 > 元数据列表     │
│ 过滤栏: [搜索] [类型] [版本]        │
│ [新增] [导入] [导出]               │
├──────────────┬────────────────────┤
│ 分类树      │ 元数据列表表格      │
│             │                    │
│             │                    │
│             │                    │
└──────────────┴────────────────────┘
```

## 左侧分类树

- 按元模型分类展示
- 支持折叠展开
- 支持搜索定位节点

## 右侧列表表格

列:

| 列       | 说明                   |
| -------- | ---------------------- |
| 名称     | 链接到详情             |
| 类型     | 标签展示               |
| 数据源   |                        |
| 当前版本 |                        |
| 更新时间 |                        |
| 更新人   |                        |
| 变更订阅 | 是否已订阅开关         |
| 操作     | 编辑 / 版本历史 / 删除 |

## 顶部操作栏

- **新增**: 新增元数据
- **导入**: 按模板导入元数据 (文件上传)
- **导出**: 导出选中或全部元数据

## 交互规范

- 搜索支持按元数据名称全文搜索
- 点击名称进入详情页编辑
- 支持勾选批量导出
- 版本号格式: `v{major}.{minor}.{patch}`

## 特殊设计

- 支持三种采集方式: 自动采集 / 订阅采集 / 手动导入
- 元数据同步定时比对，发现差异提示更新
- 用户可订阅感兴趣的元数据变更，变更时邮件通知
