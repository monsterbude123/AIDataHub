# 元数据详情页 - 页面设计规范

> 页面路径: `/metadata/detail/{id}`
> 覆盖 MASTER 规范: 无

## 页面目标

查看和编辑元数据详细信息，管理版本历史。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包屑: 元数据管理 > 元数据列表 > 详情 │
│ [编辑] [版本对比] [订阅]            │
├──────────┬─────────────────────────┤
│  Tabs:  │                         │
│  ▶基本  │                         │
│  技术  │       内容区域            │
│  业务  │                         │
│  管理  │                         │
│  版本  │                         │
└──────────┴─────────────────────────┘
```

## Tab 1: 基本信息

| 字段       | 说明     |
| ---------- | -------- |
| 元数据名称 | 可编辑   |
| 元数据类型 | 选择     |
| 所属分类   | 树形选择 |
| 描述       | 文本域   |
| 数据源     | 关联选择 |
| 绑定元模型 | 选择     |

## Tab 2: 技术元数据

表格展示字段信息:

| 字段名 | 数据类型 | 精度 | 可空 | 描述 | 操作 |
| ------ | -------- | ---- | ---- | ---- | ---- |

支持添加/编辑/删除字段。

## Tab 3: 业务元数据

| 字段           | 说明     |
| -------------- | -------- |
| 业务定义       | 文本域   |
| 业务责任人     | 用户选择 |
| 关联标准数据元 | 多选选择 |
| 关联字典       | 选择     |
| 分级分类       | 选择     |

## Tab 4: 管理元数据

| 字段         | 说明                |
| ------------ | ------------------- |
| 创建人       | 只读                |
| 创建时间     | 只读                |
| 当前版本     | 只读                |
| 最后更新人   | 只读                |
| 最后更新时间 | 只读                |
| 存储位置     | HDFS路径 / 数据库表 |

## Tab 5: 版本历史

表格展示版本历史:

| 版本号 | 更新人 | 更新时间 | 更新说明 | 操作 |
| ------ | ------ | -------- | -------- | ---- |

操作: 查看详情 / 回滚到此版本

## 版本对比弹窗

选择两个版本，对比差异:

- 左侧: 版本A
- 右侧: 版本B
- 差异行高亮显示
- 支持下载差异报告

## 交互规范

- 编辑模式 / 查看模式切换
- 所有修改需要保存
- 保存后版本号自动递增
- 支持版本说明填写
- 订阅/取消订阅变更推送

## 权限

- 仅管理员可编辑
- 普通用户只读
