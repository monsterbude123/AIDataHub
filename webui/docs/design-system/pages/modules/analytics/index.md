# 用户自助数据分析模块 - 页面索引

> 模块路由前缀: `/analytics`
> 菜单位置: 一级菜单「自助分析」

## 模块说明

支持用户自助可视化生成查询，结果可视化展示，无需开发人员参与。

## 功能页面

### 一级菜单页面

| 页面       | 类型  | 菜单名称   | 路由                       | 文档                                                 |
| ---------- | ----- | ---------- | -------------------------- | ---------------------------------------------------- |
| 即席查询   | `[M]` | 即席查询   | `/analytics/query`         | [ad-hoc-query.md](./ad-hoc-query.md)                 |
| 可视化分析 | `[M]` | 可视化分析 | `/analytics/visualization` | [ad-hoc-visualization.md](./ad-hoc-visualization.md) |

**页面类型说明**：

- `[M]` 菜单页面 - 出现在侧边导航菜单

## 核心特性

- 可视化查询构建，无需手写SQL
- 支持多种图表类型：柱状图、折线图、饼图、地图等
- 支持查询结果导出Excel/CSV
- 支持保存查询和分享查询
- 支持抽样数据探索
