# 共享交换事项任务页 - 页面设计规范

> 页面路径: `/sharing/tasks`
> 覆盖 MASTER 规范: 无

## 页面目标

处理待办事项任务，提供审批功能。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包crumb: 共享交换 > 事项任务    │
│ Tabs: 我的待办 ▶ 我的已办         │
└───────────────────────────────────┘
```

---

## Tab 1: 待办任务列表

表格:

| 列       | 说明              |
| -------- | ----------------- |
| 资源信息 | 资源名称          |
| 申请方   | 申请单位 / 申请人 |
| 提供方   | 提供单位          |
| 申请时间 |                   |
| 操作     | 审批按钮          |

支持搜索排序。

## 审批详情页

从上到下:

1. **基本信息**:
   - 事项类型
   - 资源信息
   - 申请方信息
   - 提供方信息
   - 申请信息

2. **申请内容**
   - 不同服务类型不同表单:
     - 文件下载: 用途说明
     - 库表交换: 选择字段、配置查询条件
     - 数据查询: 配置参数

3. **审批历史**
   - 列表展示审批节点、审批人、时间、结果、意见

4. **审批表单**
   - 审批结果: 通过 / 拒绝
   - 审批意见: 文本域

## 交互

- **催办**: 申请人可发送催办消息，提醒审批人
- **提交审批**: 提交后进入下一节点或完成
- 审批通过自动生成访问密钥（如需）

---

## Tab 2: 我的已办

展示已审批完成的任务:

| 列           | 说明        |
| ------------ | ----------- |
| 资源信息     |             |
| 申请方       |             |
| 我的审批结果 | 通过 / 拒绝 |
| 审批时间     |             |
| 最终状态     |             |
| 操作         | 查看详情    |

## 权限

- 待办页面只显示当前用户需要审批的任务
- 已办显示当前用户已经审批过的任务
- 管理员可看到所有待办
