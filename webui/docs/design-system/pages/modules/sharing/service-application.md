# 服务申请管理页 - 页面设计规范

> 页面路径: `/sharing/applications`
> 覆盖 MASTER 规范: 无

## 页面目标

用户申请共享服务，管理申请记录，审批处理。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包crumb: 共享交换 > 服务申请    │
│ Tabs: 我的申请 ▶ 待我审批 ▶ 已共享 │
└───────────────────────────────────┘
```

---

## Tab 1: 我的申请

用户查看自己提交的申请:

| 列       | 说明                            |
| -------- | ------------------------------- |
| 服务名称 |                                 |
| 服务类型 | 文件/库表/接口/查询             |
| 申请状态 | 暂存 / 待审批 / 审批通过 / 拒绝 |
| 申请时间 |                                 |
| 操作     | 查看详情 / 继续编辑 / 撤销      |

**新增申请**:

- 用户只能申请有权限目录下的服务
- 不同服务类型不同申请表单:
  - **文件下载**: 填写用途说明 → 提交审批 → 通过后下载
  - **库表交换**: 选择查询条件，设置调度周期 → 审批通过创建调度任务
  - **数据查询**: 配置查询参数 → 审批通过获得API访问权限
  - **比对服务**: 配置比对双方 → 审批通过获得调用权限

- 支持暂存不提交，后续继续编辑

## 使用功能

**文件服务**:

- 预览文件
- 下载文件

**库表交换服务**:

- 查看执行记录
- 手动触发执行
- 下载结果

**数据查询服务**:

- 在线测试查询
- 查看API文档
- 下载查询结果

## 审批流程

- **无条件共享**: 自动通过，不需要审批
- **有条件共享**: 需要提供方审批
- 审批通过自动生成访问密钥
- 权限校验: 平台校验授权、有效期、调用频率，记录日志

## 交互规范

- 暂存申请可继续编辑
- 提交后不能编辑只能撤销
- 申请人可发送催办提醒审批人
- 提供方可以查看自己提供的资源被申请情况
- 支持搜索申请

## 权限

- 用户只能申请访问有权限的目录
- 审批人只能审批自己权限范围内的申请
- 只有审批通过才能使用服务
