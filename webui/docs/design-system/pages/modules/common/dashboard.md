# 系统首页仪表盘 - 页面设计规范

> 页面路径: `/`
> 所属模块: 公共页面
> 覆盖 MASTER 规范: 多模块数据聚合展示

## 页面目标

系统全局首页，展示跨模块关键指标、待办事项、系统状态，为用户提供一站式工作入口。

与 `/sharing` 数据共享首页的区别：

- `/` 系统首页：跨模块全局视角，面向所有用户
- `/sharing` 共享首页：数据共享模块专属，面向共享业务用户

## 欢迎区域

| 元素     | 规格                                   |
| -------- | -------------------------------------- |
| 欢迎文案 | H2 (24px), "欢迎回来，[用户名]"        |
| 待办统计 | Body (16px), Primary色数字             |
| 查看全部 | 文字链接，跳转 `/system/approval/todo` |

## 核心指标卡片

| 卡片       | 数据来源     | 点击跳转                             |
| ---------- | ------------ | ------------------------------------ |
| 数据源总数 | 数据集成模块 | `/integration/sources`               |
| 迁移任务   | 数据迁移模块 | `/integration/migration`             |
| 数据服务   | 数据服务模块 | `/service/catalog`                   |
| 质量问题   | 数据治理模块 | `/governance/data-quality` (工单Tab) |
| 待审批     | 系统管理模块 | `/system/approval/todo`              |

### 卡片样式

- 宽度: 200px
- 高度: 80px
- 数字: H2 (24px), Primary色
- 副文案: Body Small (14px), 灰色
- 趋势箭头: ↑绿色 / ↓红色

## 今日待办事项

数据来源: 系统审批模块 + 数据治理工单 + 项目任务

### 待办类型

| 类型     | 图标              | 来源     | 点击跳转                             |
| -------- | ----------------- | -------- | ------------------------------------ |
| 审批待办 | `clipboard-check` | 系统审批 | `/system/approval/todo`              |
| 质量工单 | `alert-triangle`  | 数据治理 | `/governance/data-quality` (工单Tab) |
| 项目任务 | `folder`          | 数据项目 | `/project/[projectId]`               |

### 待办列表样式

- 最多显示 5 条
- 每条高度 60px
- 显示图标 + 标题 + 关键信息 + 操作按钮
- 超出显示 "查看更多" 链接

## 系统资源状态

数据来源: 基础设施模块

### 资源队列使用率

| 元素       | 规格                   |
| ---------- | ---------------------- |
| 进度条     | 高度 8px, 宽度 100%    |
| 使用率文字 | Body Small (14px)      |
| 队列名称   | 下拉可切换查看不同队列 |

### Worker节点状态

| 状态 | 图标           | 颜色    |
| ---- | -------------- | ------- |
| 正常 | `check-circle` | #10B981 |
| 离线 | `x-circle`     | #EF4444 |
| 警告 | `alert-circle` | #F59E0B |

点击跳转: `/infrastructure/worker`

## 快捷入口

常用功能快捷访问入口，根据用户角色动态显示。

### 快捷入口配置

| 入口       | 图标          | 跳转路由                        | 权限要求   |
| ---------- | ------------- | ------------------------------- | ---------- |
| 数据源管理 | `database`    | `/integration/sources`          | 所有用户   |
| 新建迁移   | `plus-circle` | `/integration/migration/create` | 数据工程师 |
| 服务目录   | `layers`      | `/service/catalog`              | 所有用户   |
| 数据血缘   | `git-branch`  | `/governance/lineage`           | 所有用户   |
| 即席查询   | `search`      | `/analytics/query`              | 数据分析师 |
| 项目列表   | `folder-open` | `/project`                      | 所有用户   |

### 快捷入口样式

- 卡片宽度: 180px
- 图标: 32px, Primary色
- 文字: Body (16px)
- 悬浮: 背景变色 + 显示"进入"/"创建"按钮

## 近期活动

系统活动日志，展示最近 10 条操作记录。

### 活动类型

| 类型     | 图标          | 颜色    |
| -------- | ------------- | ------- |
| 任务完成 | `check`       | #10B981 |
| 任务创建 | `plus`        | #3B82F6 |
| 任务失败 | `x`           | #EF4444 |
| 申请提交 | `file-plus`   | #F59E0B |
| 审批通过 | `thumbs-up`   | #10B981 |
| 审批拒绝 | `thumbs-down` | #EF4444 |

### 活动列表样式

- 时间线左侧对齐
- 时间点: 8px 圆点，类型对应颜色
- 时间文字: Caption (12px), #94A3B8
- 内容文字: Body Small (14px)
- 用户名可点击跳转用户详情

## 刷新机制

| 区域     | 刷新方式                 |
| -------- | ------------------------ |
| 核心指标 | 手动刷新 + 5分钟自动刷新 |
| 今日待办 | 实时推送更新             |
| 系统资源 | 30秒自动刷新             |
| 近期活动 | 手动刷新                 |

## 权限控制

| 角色       | 可见内容                          |
| ---------- | --------------------------------- |
| 系统管理员 | 全部内容                          |
| 租户管理员 | 本租户数据 + 系统资源状态         |
| 数据工程师 | 数据相关指标 + 待办 + 快捷入口    |
| 数据分析师 | 服务目录 + 即席查询 + 数据血缘    |
| 只读者     | 核心指标(只读) + 快捷入口(只进入) |

## 空状态

| 场景       | 空状态设计                                                |
| ---------- | --------------------------------------------------------- |
| 无待办事项 | 图标 `check-circle`, "暂无待办事项", "您已处理完所有待办" |
| 无近期活动 | 图标 `history`, "暂无近期活动"                            |
| 首次登录   | 显示引导卡片 "开始使用数据中台" + 快速入门链接            |

## 加载状态

| 区域     | 加载方式        |
| -------- | --------------- |
| 核心指标 | Skeleton 卡片   |
| 待办列表 | Skeleton 列表   |
| 系统资源 | Spinner         |
| 近期活动 | Skeleton 时间线 |

## 响应式设计

| 断点    | 布局调整                    |
| ------- | --------------------------- |
| Mobile  | 单列堆叠，快捷入口 2x2 网格 |
| Tablet  | 双列，待办和系统资源并排    |
| Desktop | 三列，完整布局              |

## 与其他首页的区别

| 首页         | 路由            | 目标用户     | 内容范围       |
| ------------ | --------------- | ------------ | -------------- |
| 系统首页     | `/`             | 所有用户     | 跨模块全局视角 |
| 数据共享首页 | `/sharing`      | 共享业务用户 | 共享模块专属   |
| 项目详情     | `/project/[id]` | 项目成员     | 项目内视角     |
