# 个人中心页 - 页面设计规范

> 页面路径: `/profile`
> 覆盖 MASTER 规范: Tabs 标签页布局

## 页面目标

用户管理个人信息、安全设置、偏好配置。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 个人中心                   │
├───────────────────────────────────┤
│                                   │
│  ┌─────────────────────────────┐  │
│  │  头像    用户名             │  │
│  │         部门/角色           │  │
│  └─────────────────────────────┘  │
│                                   │
│  Tabs: 基本信息 ▶ 安全设置 ▶ 偏好设置 │
│  ┌─────────────────────────────┐  │
│  │                             │  │
│  │     Tab 内容区域            │  │
│  │                             │  │
│  └─────────────────────────────┘  │
│                                   │
└───────────────────────────────────┘
```

## 用户信息卡片

顶部展示当前用户基本信息:

| 元素   | 说明              |
| ------ | ----------------- |
| 头像   | 80x80，可点击更换 |
| 用户名 | 显示姓名          |
| 账号   | 显示登录账号      |
| 部门   | 所属组织机构      |
| 角色   | 主要角色列表      |

---

## Tab 1: 基本信息

### 表单字段

| 字段     | 说明                   | 可编辑 |
| -------- | ---------------------- | ------ |
| 头像     | 点击上传新头像         | ✓      |
| 姓名     | 必填                   | ✓      |
| 性别     | 单选：男/女            | ✓      |
| 手机号   | 格式校验               | ✓      |
| 邮箱     | 格式校验               | ✓      |
| 所属机构 | 显示，不可编辑         | ✗      |
| 数据分级 | 显示用户最大可访问级别 | ✗      |
| 创建时间 | 显示                   | ✗      |

### 操作

- **保存**: 保存修改的基本信息
- **重置**: 恢复未保存的状态

---

## Tab 2: 安全设置

### 修改密码

| 字段     | 说明               |
| -------- | ------------------ |
| 当前密码 | 必填，验证身份     |
| 新密码   | 必填，密码强度校验 |
| 确认密码 | 必填，与新密码一致 |

**密码规则:**

- 至少 8 位字符
- 必须包含大小写字母和数字
- 可包含特殊字符

### 绑定信息

| 项目       | 说明                                       |
| ---------- | ------------------------------------------ |
| 手机绑定   | 显示已绑定手机号，支持更换                 |
| 邮箱绑定   | 显示已绑定邮箱，支持更换                   |
| OAuth 绑定 | 显示已绑定的第三方账号（企业微信、钉钉等） |

### 登录历史

展示最近 10 条登录记录:

| 列       | 说明            |
| -------- | --------------- |
| 登录时间 |                 |
| 登录 IP  |                 |
| 登录设备 | 浏览器/操作系统 |
| 登录方式 | 密码/OAuth/LDAP |

---

## Tab 3: 偏好设置

### 界面设置

| 设置项     | 说明               |
| ---------- | ------------------ |
| 主题模式   | 浅色/深色/跟随系统 |
| 语言       | 中文/English       |
| 侧边栏折叠 | 默认展开/折叠      |

### 通知设置

| 设置项            | 说明      |
| ----------------- | --------- |
| 系统通知          | 开启/关闭 |
| 邮件通知          | 开启/关闭 |
| 钉钉/企业微信通知 | 开启/关闭 |

### 数据偏好

| 设置项       | 说明                 |
| ------------ | -------------------- |
| 默认数据分级 | 创建数据时的默认分级 |
| 默认数据源   | 工作台默认数据源     |
| 表格每页条数 | 10/20/50/100         |

---

## 交互规范

- 头像上传支持裁剪，限制 2MB 以内
- 密码修改后需要重新登录
- 手机/邮箱更换需要验证码确认
- 偏好设置实时保存

## 权限控制

- 普通用户只能修改自己的信息
- 部分字段（机构、数据分级）由管理员设置，用户不可修改
