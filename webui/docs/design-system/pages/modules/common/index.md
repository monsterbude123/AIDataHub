# 公共页面 - 页面索引

> 不归属业务模块的公共页面

## 模块说明

不归属业务模块的公共页面，如系统首页、登录、个人中心、错误页等。

## 功能页面

### 菜单页面

| 页面           | 类型  | 路由 | 菜单位置       | 文档                           |
| -------------- | ----- | ---- | -------------- | ------------------------------ |
| 系统首页仪表盘 | `[M]` | `/`  | 导航栏「首页」 | [dashboard.md](./dashboard.md) |

**注意**: 系统首页 `/` 与数据共享首页 `/sharing` 是不同的页面：

- `/` - 系统全局首页，展示跨模块关键指标
- `/sharing` - 数据共享模块首页，展示共享业务内容

### 非菜单页面

| 页面      | 类型  | 路由       | 入口方式         | 文档                       |
| --------- | ----- | ---------- | ---------------- | -------------------------- |
| 登录页    | `[C]` | `/login`   | 未登录自动跳转   | [login.md](./login.md)     |
| 个人中心  | `[D]` | `/profile` | 用户头像下拉菜单 | [profile.md](./profile.md) |
| 404错误页 | `[C]` | `/404`     | 路由不存在时显示 | -                          |
| 403错误页 | `[C]` | `/403`     | 无权限时显示     | -                          |
| 500错误页 | `[C]` | `/500`     | 服务器错误时显示 | -                          |

**页面类型说明**：

- `[M]` 菜单页面 - 出现在顶部导航栏
- `[C]` 配置页面 - 系统级页面，不在侧边菜单
- `[D]` 详情页面 - 从用户菜单进入，不在侧边菜单栏

## 导航结构

```
公共页面
├── 系统首页仪表盘 [M] (/) - 顶部导航栏「首页」
├── 登录页 [C] (/login) - 未登录自动跳转
├── 个人中心 [D] (/profile) - 用户头像下拉进入
├── 404错误页 [C] (/404)
├── 403错误页 [C] (/403)
└── 500错误页 [C] (/500)
```

## 系统首页功能

系统首页仪表盘提供：

- 跨模块核心指标展示
- 今日待办事项（审批、工单、任务）
- 系统资源状态监控
- 快捷入口（常用功能）
- 近期活动记录

详见 [dashboard.md](./dashboard.md)
