# 队列监控总览页 - 页面设计规范

> 页面路径: `/task-queue/monitor`
> 覆盖 MASTER 规范: 高密度数据展示，实时状态更新

## 页面目标

实时监控系统中所有任务队列的运行情况，支持队列级别操作管理。

```

├─────────────────────────────────────────────────────────┤
```

## 队列概览卡片

| 卡片         | 数据                         | 说明                             |
| ------------ | ---------------------------- | -------------------------------- |
| 总队列数     | 当前配置的队列数量           | 包含所有队列（运行中/暂停/异常） |
| 运行中队列   | 正常处理任务的队列数         | 绿色标识健康状态                 |
| 等待任务数   | 所有队列中等待处理的任务总数 | 黄色超过阈值告警                 |
| 平均处理速率 | 系统整体任务处理吞吐量       | 任务/秒                          |

## 队列列表表格

| 列           | 说明                                    |
| ------------ | --------------------------------------- |
| 队列名称     | 队列标识名称，可点击查看详情            |
| 队列类型     | 数据同步/数据清洗/特征工程/质量检测等   |
| 当前状态     | 运行中/暂停/异常/空队列（状态圆点标识） |

| 处理中任务   | 正在执行的任务数量                      |
| 处理速率     | 最近1分钟平均处理速率（任务/秒）        |
| 平均等待时间 | 任务从入队到开始处理的平均等待时间      |
| 峰值容量     | 队列配置的最大容量                      |
| 堆积告警     | 是否触发堆积告警阈值                    |
| 操作         | 查看详情/暂停/恢复/清空                 |

## 队列状态定义

| 状态    | 颜色         | 说明                         |
| ------- | ------------ | ---------------------------- |
| running | #10B981 (绿) | 正常运行，持续处理任务       |
| paused  | #F59E0B (黄) | 队列已暂停，停止接收新任务   |
| error   | #EF4444 (红) | 队列异常，处理失败或连接中断 |
| empty   | #6B7280 (灰) | 队列空闲，无待处理任务       |

## 操作功能

### 队列级别操作

- **暂停队列**: 暂停后停止处理任务，保留队列中现有任务
- **恢复队列**: 恢复暂停的队列，继续处理任务
- **清空队列**: 清空队列中所有等待任务（需确认，仅清空等待任务，不影响执行中任务）
- **查看详情**: 跳转队列详情页，查看队列中任务列表

### 全局操作

- **暂停所有**: 暂停所有运行中的队列（需确认）
- **恢复所有**: 恢复所有暂停的队列
- **刷新**: 手动刷新队列状态数据
- **自动刷新**: 开启后每30秒自动刷新

## 操作按钮状态规则

| 队列状态 | 查看详情 | 暂停   | 恢复   | 清空   |
| -------- | -------- | ------ | ------ | ------ |
| running  | ✓ 可用   | ✓ 可用 | ✗ 禁用 | ✓ 可用 |
| paused   | ✓ 可用   | ✗ 禁用 | ✓ 可用 | ✓ 可用 |
| error    | ✓ 可用   | ✗ 禁用 | ✓ 可用 | ✓ 可用 |
| empty    | ✓ 可用   | ✓ 可用 | ✗ 禁用 | ✗ 禁用 |

**交互细节**:

- 禁用按钮：灰色、悬浮提示禁用原因
- 清空操作：二次确认弹窗，防止误操作
- 操作完成后：自动刷新列表，状态更新
- 异常队列：行背景浅黄色提醒

## 告警配置

队列可配置告警阈值:

- **堆积告警**: 队列长度超过阈值时告警（默认 100）
- **等待时间告警**: 平均等待时间超过阈值时告警（默认 5分钟）
- **处理速率下降告警**: 处理速率下降超过 50% 时告警
- **告警通知渠道**: 邮件 / 短信 / 钉钉

## 容量趋势图表

支持查看单个队列的容量趋势:

- 时间范围：最近 1小时 / 6小时 / 24小时
- 图表类型：折线图
- 展示指标：队列长度、处理速率、等待时间
- 支持导出图表数据

## 交互规范

- 自动刷新间隔 30秒（可配置）
- 队列状态实时更新，状态变化时有视觉提示
- 异常队列行高亮显示
- 堆积告警状态用红色数字标识
- 分页支持每页 10/20/50/100 条

## 报表导出

支持导出队列监控报表:

- 导出格式：Excel / CSV
- 包含数据：队列状态快照、容量统计、处理速率
- 时间戳：导出时间自动添加到文件名

## 类型定义参考

```typescript
// 队列状态
type QueueStatus = 'running' | 'paused' | 'error' | 'empty';

// 队列信息
interface QueueInfo {
  id: string;
  name: string;
  type: QueueType;
  status: QueueStatus;
  queueLength: number; // 队列长度
  processingCount: number; // 处理中任务数
  processingRate: number; // 处理速率（任务/秒）
  avgWaitTime: number; // 平均等待时间（秒）
  maxCapacity: number; // 峰值容量
  alertThreshold: number; // 堆积告警阈值
  hasAlert: boolean; // 是否触发告警
  createdAt: string;
  updatedAt: string;
}

// 队列类型
type QueueType =
  | 'data_sync' // 数据同步
  | 'data_clean' // 数据清洗
  | 'feature_engine' // 特征工程
  | 'quality_check' // 质量检测
  | 'report_gen' // 报表生成
  | 'data_import'; // 数据导入
```
