## 一、设计系统概览

### 产品分析

| 维度         | 说明                                                 |
| ------------ | ---------------------------------------------------- |
| **产品类型** | 企业级SaaS数据中台 / 大数据平台                      |
| **目标用户** | 数据管理员、数据分析师、开发工程师、运维人员         |
| **行业**     | 政务/企业大数据                                      |
| **核心需求** | 高密度数据展示、多模块导航、数据血缘可视化、任务监控 |
| **设计风格** | Data-Dense Enterprise Dashboard                      |

### 设计模式选择

**Pattern: Real-Time / Operations Dashboard**

- 适合运维监控、数据运营类产品
- 顶部关键指标展示，下方多图表数据面板
- 主CTA放在导航栏，次要CTA在数据区块后

**Style: Data-Dense Dashboard**

- 多图表/多数据表格布局
- KPI卡片网格排列
- 最小化padding，空间高效利用
- 最大数据可见性
- 性能评级: ⚡ Excellent
- 可访问性: ✓ WCAG AA

**关键词**: `enterprise`, `dashboard`, `data-platform`, `big-data`, `data-dense`

### 避免的反模式

- ❌ 华丽装饰性设计 - 数据平台以功能优先
- ❌ 缺少筛选能力 - 用户需要多维度组合筛选数据
- ❌ 大z-index值随意使用 - 需要系统化z-index管理
- ❌ 一次性加载所有内容 - 需要懒加载

## 四、布局与交互规范

### 整体布局结构

数据中台采用经典的**侧边导航 + 顶部面包屑 + 主内容区**布局：

```
┌─────────────────────────────────────────┐
│  Logo [Search]                      User │ ← 顶部导航栏 (高度: 64px)
├──────────┬──────────────────────────────┤
│          │                              │
│  侧边    │         主内容区              │
│  导航    │                              │
│  (240px) │  • 面包屑                    │
│          │  • 页面标题                  │
│          │  • 过滤栏                    │
│          │  • 内容区域                  │
│          │                              │
└──────────┴──────────────────────────────┘
```

### 响应式断点

| 断点        | 宽度范围        | 布局调整                      |
| ----------- | --------------- | ----------------------------- |
| **Mobile**  | < 768px         | 侧边导航折叠为抽屉，单列布局  |
| **Tablet**  | 768px - 1024px  | 侧边导航图标折叠，双列布局    |
| **Desktop** | 1024px - 1440px | 完整侧边导航，三列布局        |
| **Large**   | > 1440px        | 固定最大宽度 1400px，居中展示 |

### Z-Index 尺度系统

必须使用系统化z-index，禁止随意使用大数值：

| 层级           | z-index | 使用场景         |
| -------------- | ------- | ---------------- |
| Dropdown       | 10      | 下拉菜单         |
| Sticky Header  | 20      | 吸顶表头         |
| Modal Backdrop | 30      | 模态框背景       |
| Modal Content  | 40      | 模态框内容       |
| Toast/Popup    | 50      | 消息提示、弹出框 |

> **原则**: 理解堆叠上下文，新堆叠上下文会隔离z-index

### 间距尺度

使用 4px 基础单位：

| 单位 | px   | 使用场景     |
| ---- | ---- | ------------ |
| 1    | 4px  | 极小间距     |
| 2    | 8px  | 元素内间距   |
| 3    | 12px | 紧凑间距     |
| 4    | 16px | 标准间距     |
| 6    | 24px | 区块间距     |
| 8    | 32px | 页面段落间距 |
| 12   | 48px | 章节间距     |

### 交互规范

#### 触摸/点击目标

- **最小点击目标**: 44x44px
- **表格行点击**: 整行可点击，不只是文字
- **图标按钮**: 需要包裹在足够大的点击区域内

#### 状态反馈

| 状态         | 视觉反馈                          |
| ------------ | --------------------------------- |
| **Normal**   | 默认样式                          |
| **Hover**    | 背景色变化 + `cursor-pointer`     |
| **Focus**    | 可见焦点环 (键盘导航)             |
| **Active**   | 颜色加深                          |
| **Disabled** | 透明度 50% + `cursor-not-allowed` |
| **Loading**  | 按钮禁用 + spinner 加载动画       |

#### 动画时长

- **微交互**: 150-300ms
- **页面过渡**: 300ms
- **避免**: 超过 500ms 的动画

#### 性能优化

- 使用 `transform` 和 `opacity` 做动画，避免动画 `width`/`height`/`top`/`left`
- 支持 `prefers-reduced-motion`，尊重用户动画偏好
- 懒加载折叠区域和视口以下的图片内容
- 为异步内容预留空间，避免加载时内容跳动

## 六、数据可视化推荐

根据不同数据类型，推荐合适的图表类型：

### 6.1 KPI概览区域

**多个KPI并排**: Bullet Chart 网格布局

- 空间高效，可同时展示 3-10 个KPI
- 支持目标值对比
- 颜色编码区分好/中/差区间

**单个重点KPI**: Gauge Chart

- 突出展示单个核心指标
- 渐变颜色表示性能区间

### 6.2 任务运行统计

**任务状态分布**: 饼图 / 环形图

- 展示成功/失败/等待占比

**任务趋势**: 折线图

- 展示时间序列趋势
- 多条折线对比不同类型任务

### 6.3 数据质量统计

**质量问题分布**: 柱状图

- 按规则类型统计问题数量

**质量趋势**: 面积图

- 展示问题数量随时间变化趋势

### 6.4 数据血缘

**表级/字段级血缘**: 有向无环图 (DAG)

- 使用 React-Flow 或 Cytoscape.js 渲染
- 快乐路径: 绿色粗线
- 异常路径: 黄色细线
- 瓶颈节点: 红色填充
- **可访问性**: 同时提供路径文字汇总表

### 6.5 服务调用统计

**热门服务TOP 10**: 横向条形图

- 适合排名展示

**调用趋势**: 折线图

- 展示每日调用次数变化

### 6.6 存储成本统计

**存储占比按项目**: treemap 矩形树图

- 层级展示存储占用

**成本趋势**: 面积图

- 展示随时间变化

### 推荐图表库

| 场景       | 推荐库       | 理由                 |
| ---------- | ------------ | -------------------- |
| 基础图表   | Recharts     | React 原生，轻量     |
| 血缘图/DAG | React-Flow   | 易用的交互式流程图   |
| 复杂网络图 | Cytoscape.js | 强大的网络图布局能力 |
| 高级可视化 | D3.js        | 完全自定义能力       |
| 商务图表   | ApexCharts   | 美观的响应式图表     |

### 可访问性指南

1. **所有图表必须提供文字回退**: 图表下方提供数据表格展示原始数据
2. **不只用颜色传递信息**: 使用纹理、形状、文字标签辅助区分
3. **实时更新使用ARIA live region**: 让屏幕阅读器知晓数据更新
4. **所有数值必须以文字形式可见**: 不依赖hover才能看到数值

## 七、无障碍设计 (优先级: CRITICAL)

### 必须满足的检查项

| 检查项     | 要求                                    | 状态        |
| ---------- | --------------------------------------- | ----------- |
| 颜色对比度 | 正常文本 ≥ 4.5:1，大文本 ≥ 3:1          | ✅ 必须满足 |
| 焦点状态   | 所有可交互元素必须有可见焦点环          | ✅ 必须满足 |
| Alt文本    | 所有有意义图片必须有描述性alt文本       | ✅ 必须满足 |
| ARIA标签   | 纯图标按钮必须有aria-label              | ✅ 必须满足 |
| 键盘导航   | Tab顺序匹配视觉顺序，所有操作可键盘完成 | ✅ 必须满足 |
| 表单标签   | 所有输入框必须有label的for关联          | ✅ 必须满足 |
| 触摸目标   | 所有点击目标 ≥ 44x44px                  | ✅ 必须满足 |

### 错误反馈

- 错误信息必须显示在出错字段附近
- 使用颜色 + 文字图标双重提示
- 屏幕阅读器可识别错误信息

## 八、Next.js 实现指南

### 数据获取

✅ **正确做法**: 在 Server Component 中直接fetch数据

```tsx
async function DataTablePage() {
  const data = await fetch('/api/data', { next: { revalidate: 60 } });
  const items = await data.json();
  return <DataTable data={items} />;
}
```
