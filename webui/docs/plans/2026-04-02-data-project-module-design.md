# 数据项目模块设计文档

> 创建日期: 2026-04-02
> 状态: 已确认

## 一、模块概览

### 1.1 核心定位

数据项目全生命周期管理模块，支持项目立项、规划、执行、验收、结项五个阶段，阶段可回退。

### 1.2 核心特性

- **全生命周期管理**：立项 → 规划 → 执行 → 验收 → 结项
- **阶段可回退**：验收不通过可回到执行阶段，规划调整可回到立项阶段
- **项目为容器**：项目作为容器，关联各模块（数据集成、治理、调度等）的具体任务
- **项目级权限**：项目成员角色（项目经理、成员、只读者），项目内所有资源继承权限

### 1.3 页面结构

| 页面       | 路由                       | 说明                         |
| ---------- | -------------------------- | ---------------------------- |
| 项目列表   | `/project`                 | 项目概览、筛选、创建入口     |
| 项目详情   | `/project/[id]`            | 项目基本信息、成员、阶段进度 |
| 任务管理   | `/project/[id]/tasks`      | 关联的任务/作业列表          |
| 里程碑管理 | `/project/[id]/milestones` | 阶段里程碑节点管理           |
| 文档管理   | `/project/[id]/docs`       | 项目相关文档/附件            |
| 项目统计   | `/project/[id]/stats`      | 项目报表、进度分析           |

### 1.4 阶段流转

```
立项 → 规划 → 执行 → 验收 → 结项
  ↑______|      |      |
  |_____________|______|
```

### 4.4 任务列表表格

| 列       | 说明                                |
| -------- | ----------------------------------- |


### 7.4 统计指标

| 指标         | 说明                  |
| ------------ | --------------------- |
| 任务总数     | 项目关联任务总数      |
| 完成率       | 已完成任务/总任务     |
| 里程碑       | 已完成里程碑/总里程碑 |
| 成员数       | 项目成员数量          |
| 平均任务耗时 | 任务平均执行时长      |

### 7.5 图表说明

1. **任务完成趋势**：折线图，按周/月展示任务完成数量
2. **任务类型分布**：饼图，数据集成/治理/调度/分析占比
3. **阶段进度**：横向条形图，各阶段计划与实际进度对比
4. **成员贡献**：柱状图，各成员任务完成数

### 7.6 导出功能

- 导出PDF报告
- 导出Excel数据表

## 八、权限设计

### 8.1 项目角色

| 角色     | 权限                                               |
| -------- | -------------------------------------------------- |
| 项目经理 | 项目全部操作权限，包括删除项目、管理成员、阶段变更 |
| 成员     | 查看项目、关联任务、上传文档、编辑里程碑           |
| 只读者   | 仅查看项目信息，不可编辑                           |

### 8.2 权限继承

- 项目内所有资源（任务、文档、里程碑）继承项目级权限
- 系统级权限控制模块访问，项目级权限控制项目资源

## 九、数据类型定义

```typescript
// 项目阶段
type ProjectStage =
  | 'initiation'
  | 'planning'
  | 'execution'
  | 'acceptance'
  | 'closure';

// 项目状态
type ProjectStatus = 'active' | 'completed' | 'archived';

// 项目成员角色
type ProjectRole = 'manager' | 'member' | 'viewer';

// 项目信息
interface Project {
  id: string;
  name: string;
  code: string;
  description?: string;
  stage: ProjectStage;
  status: ProjectStatus;
  progress: number;
  managerId: string;
  startDate: string;
  plannedEndDate: string;
  actualEndDate?: string;
  createdAt: string;
  updatedAt: string;
}

// 项目成员
interface ProjectMember {
  id: string;
  projectId: string;
  userId: string;
  role: ProjectRole;
  joinedAt: string;
}

// 里程碑
interface Milestone {
  id: string;
  projectId: string;
  name: string;
  stage: ProjectStage;
  plannedDate: string;
  actualDate?: string;
  status: 'pending' | 'in_progress' | 'completed' | 'overdue';
  ownerId: string;
  deliverables?: string;
  documentId?: string;
}

// 项目任务关联
interface ProjectTask {
  id: string;
  projectId: string;
  taskType: 'data_integration' | 'data_governance' | 'scheduler' | 'analytics';
  taskId: string;
  taskName: string;
  status: string;
  assigneeId?: string;
  plannedStartTime?: string;
  plannedEndTime?: string;
}

// 项目文档
interface ProjectDocument {
  id: string;
  projectId: string;
  folderId?: string;
  name: string;
  type: string;
  size: number;
  version: number;
  uploaderId: string;
  uploadedAt: string;
  filePath: string;
}

// 文档文件夹
interface DocumentFolder {
  id: string;
  projectId: string;
  parentId?: string;
  name: string;
  createdAt: string;
}
```
