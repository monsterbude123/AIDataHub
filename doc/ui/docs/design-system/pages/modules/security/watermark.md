# 数据水印配置页 - 页面设计规范

> 页面路径: `/security/watermark`
> 覆盖 MASTER 规范: 无

## 页面目标

嵌入水印信息，数据泄露后可溯源。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 数据安全 > 数据水印    │
│ 过滤栏: [搜索] [状态]            │
│ [新增水印任务]                    │
├───────────────────────────────────┤
│                                  │
│ 水印任务列表                     │
│                                  │
└───────────────────────────────────┘
```

## 水印任务列表表格

| 列       | 说明                           |
| -------- | ------------------------------ |
| 任务名称 |                                |
| 数据源   |                                |
| 水印类型 | 隐藏水印 / 伪行水印 / 伪列水印 |
| 输出目标 |                                |
| 状态     |                                |
| 操作     | 编辑 / 溯源测试 / 执行 / 删除  |

## 新增/编辑水印任务表单

| 字段       | 说明                                 |
| ---------- | ------------------------------------ |
| 任务名称   | 必填                                 |
| 数据源表   | 选择源表                             |
| 水印类型   | 单选: 隐藏水印 / 伪行水印 / 伪列水印 |
| 水印信息   | 接收单位信息，嵌入水印               |
| 水印密度   | 百分比，多少行嵌入一个水印           |
| 输出目标表 | 目标数据源 + 表名                    |

### 水印类型说明

| 类型         | 说明                                                 |
| ------------ | ---------------------------------------------------- |
| **隐藏水印** | 在原始数据中通过微小修改嵌入水印信息，不影响正常使用 |
| **伪行水印** | 插入特殊伪行携带水印信息                             |
| **伪列水印** | 添加特殊伪列携带水印信息                             |

## 水印溯源功能

支持解析水印，确认泄露来源:

- 两种方式:
  1. **上传文件**: 用户上传CSV文件解析
  2. **指定数据库表**: 直接解析数据库表

解析结果:

- 显示提取到的水印信息
- 显示置信度
- 显示原始接收单位信息

**支持部分数据泄露溯源**: 即使只有部分数据泄露，也能尝试提取水印信息

## 交互规范

- 执行水印任务异步执行
- 可查看执行日志
- 失败可重新执行
- 溯源结果显示置信度，提醒用户可能误判

## 安全考虑

- 水印嵌入不影响原始数据可用性
- 水印难以被察觉和去除
- 溯源需要管理员权限
- 记录所有溯源操作日志
