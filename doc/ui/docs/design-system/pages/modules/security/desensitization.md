# 数据脱敏配置页 - 页面设计规范

> 页面路径: `/security/desensitization`
> 覆盖 MASTER 规范: 无

## 页面目标

管理脱敏算法和脱敏规则，配置静态脱敏任务和动态脱敏。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包crumb: 数据安全 > 数据脱敏     │
│ Tabs: 算法管理 ▶ 规则管理 ▶ 任务配置 │
└───────────────────────────────────┘
```

---

## Tab 1: 脱敏算法管理

预置算法:
- Hash
- 字符串遮蔽 (保留前N后M，中间打*)
- 生日脱敏 (保留年，月日打*)
- 手机号脱敏 (保留前3后4，中间打*)
- 身份证脱敏 (保留前6后4，中间打*)
- 邮箱脱敏 (用户名前缀保留1位，域名保留)

表格:

| 算法名称 | 类型 | 描述 | 操作 |
|----------|------|------|------|
| Hash | 预置 | | 查看 |
| ... | | | |

支持**自定义算法**: 用户上传JAR包实现接口，配置使用。

---

## Tab 2: 脱敏规则管理

预置规则:
- 身份证号
- 姓名
- 地址
- 电话
- 邮箱
- 银行卡号

表格:

| 规则名称 | 算法 | 描述 | 状态 | 操作 |
|----------|------|------|------|------|

新增/编辑规则:
- 选择算法
- 配置算法参数 (比如保留前N后M)
- 测试规则效果 (输入测试数据看输出)

---

## Tab 3: 脱敏任务配置

配置脱敏任务，执行静态脱敏:

| 列 | 说明 |
|----|------|
| 任务名称 | |
| 数据源 | 选择源数据表 |
| 脱敏配置 | 选择字段 → 关联脱敏规则 |
| 输出目标 | 配置输出表 |
| 调度周期 | 定时执行 |
| 状态 | |
| 操作 | 执行 / 编辑 / 日志 / 删除 |

### 脱敏类型

- **静态脱敏**: 一次性脱敏后写入新表，用于数据分发
- **动态脱敏**: 根据访问者权限实时脱敏，不修改原数据，API访问时生效

## 交互规范

- 配置字段脱敏规则时，左侧可选字段，右侧已选，中间移动按钮
- 支持测试脱敏效果，输入测试数据立即预览结果
- 任务执行后可查看脱敏日志和统计 (多少条记录脱敏)
- 失败可查看错误信息重新执行

## 安全考虑

- 脱敏配置需要管理员权限
- 脱敏日志记录所有操作
- 敏感数据脱敏后不可逆 (Hash算法)
