# 数据安全管理模块 - 页面索引

## 模块说明

提供数据脱敏、分级分类、数据水印、数据加密能力，保障数据安全。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| 脱敏规则配置 | [desensitization.md](./desensitization.md) | 脱敏算法和规则配置 |
| 分级分类管理 | [classification.md](./classification.md) | 数据分级分类配置、行级权限 |
| 数据水印 | [watermark.md](./watermark.md) | 水印配置和溯源 |

## 核心特性

- 多种预置脱敏算法（Hash、遮蔽、出生日期等），支持自定义算法
- 分级分类控制访问权限，用户只能访问低于自身级别数据
- 支持行级数据权限基于用户属性动态过滤
- 多种水印方式，支持部分数据泄露溯源
- 支持静态脱敏和动态脱敏
