# 分级分类管理页 - 页面设计规范

> 页面路径: `/security/classification`
> 覆盖 MASTER 规范: 无

## 页面目标

按敏感程度对数据分级分类，支撑权限控制和访问策略。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包crumb: 数据安全 > 分级分类    │
│ Tabs: 分级字典 ▶ 分类字典 ▶ 分级配置 │
└───────────────────────────────────┘
```

---

## Tab 1: 分级字典维护

维护分级信息：

| 级别代码 | 级别名称 | 说明         | 访问要求     | 操作      |
| -------- | -------- | ------------ | ------------ | --------- |
| 1        | 公开     | 可公开访问   | 任何用户     | 编辑 删除 |
| 2        | 内部     | 单位内部访问 | 授权用户     |           |
| 3        | 秘密     | 需要授权     | 仅限授权人员 |           |
| 4        | 机密     | 最高敏感     | 严格授权     |           |

> 用户只能访问低于等于自身级别的数据

支持增删改分级定义。

---

## Tab 2: 分类字典维护

维护分类信息：

| 分类代码 | 分类名称 | 关联分级 | 定级依据 | 备注 | 操作 |
| -------- | -------- | -------- | -------- | ---- | ---- |

支持增删改分类定义。

---

## Tab 3: 分级分类配置

给数据集、数据列、数据行配置分级分类：

### 布局

左侧树形选择数据资源，右侧表格展示字段。

### 配置表格

| 数据对象        | 当前分级 | 当前分类 | 操作 |
| --------------- | -------- | -------- | ---- |
| 数据集 (整个表) | 下拉选择 | 下拉选择 | 编辑 |
| 字段1           |          |          |      |
| 字段2           |          |          |      |

### 行级数据权限

**支持基于用户角色配置行级过滤规则**:

- 表达式如: `org_code = current_user.org_code`
- 实现用户只能看到本组织机构的数据
- 支持复杂条件组合

## 权限控制

配置完成后，访问控制逻辑:

1. 用户有分级分类属性
2. 数据有分级分类属性
3. 用户只能访问分级 <= 用户分级的数据
4. 分类权限控制用户只能访问授权分类
5. 行级权限根据规则动态过滤数据行

## 交互规范

- 树形选择数据资源，点击加载配置
- 批量设置分级分类到多个字段
- 支持导出分级分类配置报表
- 修改需要管理员权限
- 权限变更生效需要重新登录或刷新权限缓存
