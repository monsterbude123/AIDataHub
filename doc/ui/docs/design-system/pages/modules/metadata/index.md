# 元数据管理模块 - 页面索引

## 模块说明

负责元数据的全生命周期管理，数据接入只做初始采集。支持自动/手动采集，版本管理，变更订阅。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| 元数据列表 | [list.md](./list.md) | 列表浏览搜索元数据 |
| 元数据详情 | [detail.md](./detail.md) | 详情编辑、版本管理 |

## 核心功能

- 自动/订阅/手动多种采集方式
- 支持技术/业务/管理元数据
- 版本历史管理，支持版本比对
- 元数据变更邮件订阅推送
- 扩展支持ETL、数据模型、数据服务版本管理
