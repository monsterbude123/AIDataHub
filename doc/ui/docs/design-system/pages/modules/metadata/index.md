# 元数据管理模块 - 页面索引

## 模块说明

负责元数据的全生命周期管理，数据接入只做初始采集。支持自动/手动采集，版本管理，变更订阅。元数据采集任务执行时引用基础设施配置资源。

## 功能页面

| 页面       | 文件                     | 说明               |
| ---------- | ------------------------ | ------------------ |
| 元数据列表 | [list.md](./list.md)     | 列表浏览搜索元数据 |
| 元数据详情 | [detail.md](./detail.md) | 详情编辑、版本管理 |

## 核心功能

- 自动/订阅/手动多种采集方式
- 支持技术/业务/管理元数据
- 版本历史管理，支持版本比对
- 元数据变更邮件订阅推送
- 扩展支持ETL、数据模型、数据服务版本管理

## 采集任务配置

元数据采集任务执行时引用基础设施配置：

### 采集任务类型

| 类型     | 说明               | 使用的资源       |
| -------- | ------------------ | ---------------- |
| 自动采集 | 定时自动采集元数据 | Spark引擎 + 队列 |
| 订阅采集 | 订阅数据源变更事件 | 消息队列         |
| 手动采集 | 手动触发采集       | Spark引擎 + 队列 |
| 增量采集 | 采集变更的元数据   | Spark引擎 + 队列 |

### 采集任务配置引用

```
┌─────────────────────────────────────────────────────────────┐
│ 采集任务配置                                                  │
│                                                             │
│ 数据源: MySQL-prod-orders                                   │
│ 采集类型: 全量采集                                            │
│                                                             │
│ 执行配置                                                      │
│ ┌───────────────────────────────────────────────────────┐   │
│ │ 引擎类型: Spark (轻量采集任务)                          │   │
│ │ 引擎配置: spark-metadata-collect                       │   │
│ │ 队列: queue-metadata                                   │   │
│ │ 优先级: 低                                             │   │
│ └───────────────────────────────────────────────────────┘   │
│                                                            │
│ 调度配置                                                      │
│ ┌───────────────────────────────────────────────────────┐   │
│ │ 调度方式: 定时调度                                      │   │
│ │ Cron表达式: 0 0 2 * * ? (每天凌晨2点)                   │   │
│ │ 失败重试: 3 次                                         │   │
│ └───────────────────────────────────────────────────────┘   │
│                                                            │
│ [立即执行] [保存配置]                                         │
└─────────────────────────────────────────────────────────────┘
```

### 采集任务配置项

| 配置项       | 类型   | 说明               |
| ------------ | ------ | ------------------ |
| 数据源       | Select | 选择要采集的数据源 |
| 采集类型     | Select | 全量/增量          |
| 引擎类型     | Select | Spark(推荐)        |
| 引擎配置引用 | Select | 引用引擎配置       |
| 队列选择     | Select | 选择执行队列       |
| 任务优先级   | Select | 高/中/低           |
| 调度方式     | Select | 定时/事件触发      |
| Cron表达式   | Input  | 定时调度表达式     |

## 与基础设施模块的关联

| 关联项        | 说明                      |
| ------------- | ------------------------- |
| Spark引擎配置 | 采集任务使用Spark引擎执行 |
| 资源队列      | 采集任务提交到队列执行    |
| Worker节点    | 可指定采集任务执行节点    |

## 配置继承说明

采集任务的配置继承链：

```
系统级采集配置 (spark-metadata-default)
    ↓ 继承
租户级配置 (spark-tenant-a-metadata)
    ↓ 引用
采集任务执行配置
```
