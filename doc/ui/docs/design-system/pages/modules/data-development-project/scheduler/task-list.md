# 任务运维列表页 - 页面设计规范

> 页面路径: `/project/[id]/scheduler/tasks`
> 所属项目: 数据项目管理模块
> 覆盖 MASTER 规范: 高密度表格，多筛选条件

## 页面目标

监控项目内所有 DAG 任务的执行情况，支持运维操作和任务管理。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] > 任务调度 > 任务运维 │
│ 项目信息: 当前阶段 [执行阶段]  进度 65%                   │
│ 操作栏: [刷新] [导出] [批量操作]                         │
├─────────────────────────────────────────────────────────┤
│ 统计卡片                                                 │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│ │ 任务总数  │ │ 成功     │ │ 失败     │ │ 运行中   │     │
│ │   12     │ │    8     │ │    1     │ │    3     │     │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘     │
├─────────────────────────────────────────────────────────┤
│ 过滤栏: [搜索] [状态] [类型] [DAG] [负责人] [时间范围]    │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 任务列表表格                                             │
│                                                         │
│ 分页                                                     │
└─────────────────────────────────────────────────────────┘
```

## 项目信息头部

在运维页顶部显示项目上下文：

- 项目名称
- 当前阶段
- 项目进度

## 统计卡片区域

| 卡片     | 说明                 | 颜色                 |
| -------- | -------------------- | -------------------- |
| 任务总数 | 项目内DAG任务总数    | Primary (#2563EB)    |
| 成功     | 最近执行成功的任务数 | Success (#10B981)    |
| 失败     | 最近执行失败的任务数 | Error (#EF4444)      |
| 运行中   | 当前正在执行的任务数 | Processing (#3B82F6) |

**卡片样式**:

- 宽度: 160px
- 高度: 60px
- 数字: H3 (20px)

## 过滤栏组件

| 过滤项   | 类型       | 说明                              |
| -------- | ---------- | --------------------------------- |
| 搜索     | Input      | 按任务名称/DAG名称搜索            |
| 状态     | Select     | 全部/成功/失败/运行中/待执行      |
| 类型     | Select     | 数据集成/数据治理/数据处理/控制流 |
| DAG      | Select     | 选择特定DAG筛选其下任务           |
| 负责人   | Select     | 从项目成员中选择                  |
| 时间范围 | DatePicker | 最后执行时间范围                  |

## 任务列表表格

| 列           | 说明                        | 宽度  |
| ------------ | --------------------------- | ----- |
| 任务名称     | 链接到DAG编排页该节点       | 180px |
| 所属DAG      | DAG名称，可点击跳转         | 150px |
| 任务类型     | 标签显示类型                | 100px |
| 负责人       | 项目成员名称 + 头像         | 120px |
| 调度类型     | 定时/事件/依赖              | 100px |
| 优先级       | 高(红)/中(蓝)/低(灰)        | 80px  |
| 最后执行时间 | YYYY-MM-DD HH:mm            | 140px |
| 最后执行状态 | 成功/失败/运行中 (颜色圆点) | 100px |
| 当前状态     | 在线/下线                   | 80px  |
| 操作         | 查看日志/重新执行/编辑/下线 | 150px |

**状态标签样式**:

| 状态   | 颜色    | 圆点       |
| ------ | ------- | ---------- |
| 成功   | #10B981 | 绿色实心圆 |
| 失败   | #EF4444 | 红色实心圆 |
| 运行中 | #3B82F6 | 蓝色闪烁圆 |
| 待执行 | #6B7280 | 灰色空心圆 |

## 操作功能

### 单任务操作

| 操作     | 说明                         | 条件         |
| -------- | ---------------------------- | ------------ |
| 查看日志 | 跳转到日志中心查看该任务日志 | 所有状态     |
| 重新执行 | 手动触发重新执行             | 失败或已完成 |
| 编辑     | 跳转到DAG编排页编辑任务节点  | 在线状态     |
| 下线     | 下线后无法执行，保留配置     | 在线状态     |
| 上线     | 重新上线任务                 | 下线状态     |

### 批量操作

- 批量重新执行: 勾选多个失败任务批量重试
- 批量下线: 勾选多个任务批量下线

## 告警配置

每个任务可配置告警:

| 告警类型     | 说明             |
| ------------ | ---------------- |
| 超时预警     | N分钟未完成告警  |
| 失败告警     | 执行失败立即告警 |
| 数据增量预警 | 增量低于N条告警  |
| 调度超时预警 | 到点未调度告警   |

**告警通知渠道**: 邮件 / 短信 / 钉钉 / 企业微信

**告警接收人**: 默认任务负责人，可添加其他项目成员

## 失败重试策略

可针对不同错误类型配置重试策略:

| 错误类型     | 重试策略              |
| ------------ | --------------------- |
| 网络异常     | 自动重试3次，间隔30秒 |
| 数据库迁移锁 | 等待60秒后重试        |
| 数据错误     | 不重试，立即告警      |
| 资源不足     | 等待5分钟后重试       |

## 数据对账功能

支持数据一致性检查:

| 配置项   | 说明             |
| -------- | ---------------- |
| 源表     | 数据来源表       |
| 目标表   | 数据写入表       |
| 对账字段 | 用于比对的字段   |
| 对账周期 | 定时对账周期     |
| 差异阈值 | 差异超过阈值告警 |

对账结果可在任务详情中查看。

## 交互规范

- **自动刷新**: 可配置刷新间隔（默认30秒），支持暂停
- **点击任务名称**: 展开详情弹窗
- **跳转DAG编排**: 点击所属DAG名称跳转
- **异常行高亮**: 失败任务行背景浅黄色 (#FEF3C7)
- **批量勾选**: 表格首列复选框

## 报表导出

支持导出项目任务运维报表:

- 任务执行比例统计
- 成功率统计
- 按任务类型分组统计
- 按负责人分组统计
- 导出Excel格式
