# DAG任务编排页 - 页面设计规范

> 页面路径: `/project/[id]/scheduler/dag`
> 所属项目: 数据项目管理模块
> 覆盖 MASTER 规范: 全屏画布设计，需要最大化可用空间

## 页面目标

可视化编排项目内 DAG 任务，配置任务依赖关系，管理项目级调度流程。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] > 任务调度 > DAG编排 │
│ 项目信息: 当前阶段 [执行阶段]  进度 65%                   │
│ 操作栏: [保存] [验证] [运行] [全屏]                       │
├──────────┬──────────────────────────────────────────────┤
│ 节点面板  │              DAG画布                         │
│ (节点类型)│                                              │
│          │  拖拽节点，连线配置依赖                        │
│          │                                              │
│          │                                              │
├──────────┼──────────────────────────────────────────────┤
│ 属性面板  │  选中节点显示属性配置                         │
└──────────┴──────────────────────────────────────────────┘
```

## 项目信息头部

在 DAG 编排页顶部显示项目上下文：

- 项目名称
- 当前阶段（标签显示）
- 项目进度（进度条）

**目的**: 让用户在编排 DAG 时清楚当前项目状态，确保任务编排与项目阶段匹配。

## 左侧节点面板

可拖拽节点类型（按项目关联模块分类）:

| 分类     | 节点类型                   | 关联模块     |
| -------- | -------------------------- | ------------ |
| 数据集成 | 数据接入、数据探查、标准化 | 数据集成模块 |
| 数据治理 | 质量检测、标签提取         | 数据治理模块 |
| 数据处理 | Spark SQL、Python脚本      | 数据处理服务 |
| 控制流   | 条件分支、循环             | -            |

**节点面板样式**:

- 宽度: 240px，可折叠到 48px
- 拖拽节点到画布添加节点
- 悬浮显示节点类型说明

## 中间DAG画布

- 使用 React-Flow 渲染
- 支持拖拽移动节点
- 支持拖拽节点边缘连接两个节点 (上游 → 下游)
- 支持点击节点选中，右侧显示属性
- 支持右键菜单操作
- 支持画布缩放平移
- 箭头表示依赖关系：上游完成 → 下游开始

### 节点显示

每个节点显示：

- 节点名称
- 节点类型图标
- 关联任务名称
- 当前状态（如果正在执行）

**节点样式**:

- 宽度: 160px
- 高度: 60px
- 圆角: 8px
- 状态色边框

### 连线功能

- **创建连线**: 从节点右侧拖拽连接点到另一节点左侧
- **删除连线**: 右键点击连线，选择"删除"选项
- **连线样式**: 灰色线条（#94A3B8），带箭头指示方向
- **禁止自连**: 节点不能连接自己
- **禁止重复**: 相同两个节点之间只能有一条连线

### 配置继承说明

```
项目级资源配置
    ↓ 继承
DAG默认资源配置
    ↓ 继承/覆盖
节点级资源配置
```

- DAG配置继承项目级默认配置
- 节点可继承DAG配置或独立配置
- 节点独立配置可覆盖DAG默认值

## 操作按钮

| 按钮     | 功能          | 说明                           |
| -------- | ------------- | ------------------------------ |
| 保存     | 保存DAG配置   | 必须验证通过才能保存           |
| 验证     | 验证DAG正确性 | 检查环路、孤立节点、参数完整性 |
| 立即运行 | 手动触发执行  | 启动一次DAG执行                |
| 全屏     | 全屏画布      | 扩展画布区域                   |

## 验证规则

前端验证必须通过才能保存:

1. **不能有环路**: 检测循环依赖
2. **不能有孤立节点**: 每个节点必须有入口或出口
3. **参数完整性**: 所有必需参数已配置
4. **任务有效性**: 所有节点关联有效的项目任务
5. **负责人设置**: 每个节点必须设置负责人（从项目成员中选择）

## 项目级特殊设计

### 任务关联约束

- DAG节点只能关联**项目内已关联的任务**
- 如果节点类型需要的任务未在项目中关联，需先到任务管理页关联

### 阶段匹配提示

- DAG编排时显示当前项目阶段
- 如果编排的任务超出当前阶段范围，给出提示

### 权限继承

- DAG保存/删除权限继承项目角色
- 仅项目经理和成员可编辑 DAG
- 只读者仅可查看 DAG 结构

## 交互规范

- **Ctrl+Z**: 撤销操作
- **Ctrl+Shift+Z**: 重做操作
- **Delete**: 删除选中节点
- **空格 + 拖拽**: 平移画布
- **滚轮**: 缩放画布
- **双击节点**: 编辑名称
- **右键节点**: 显示菜单
- **右键连线**: 显示删除菜单
- **左键空白**: 关闭菜单和属性面板

## 性能考虑

- 画布超过50个节点提示简化视图
- 使用虚拟滚动节点面板
- 防抖处理画布变更保存

## 与基础设施模块的关联

### 配置引用关系

DAG执行时引用基础设施配置：

| 关联项   | 引用方式       | 说明                         |
| -------- | -------------- | ---------------------------- |
| 引擎配置 | 引用引擎配置ID | 节点执行时使用的计算引擎参数 |
| 资源队列 | 引用队列ID     | 任务提交到的YARN/K8s队列     |
| Worker组 | 引用Worker组ID | 任务执行的Worker节点组       |
| 配置模板 | 可选引用       | DAG预设配置模板              |

### 执行流程

```
DAG触发执行
    ↓
读取DAG默认资源配置
    ↓
遍历节点，读取节点配置
    ↓
合并配置 (节点覆盖DAG默认)
    ↓
从基础设施模块获取完整配置
    ↓
提交任务到队列
    ↓
分配Worker执行
```

### 配置引用示例

```json
{
  "dagId": "dag-001",
  "name": "daily-etl-flow",
  "defaultConfig": {
    "engineSpark": "spark-project-default",
    "engineDataX": "datax-project-default",
    "queue": "queue-project-a",
    "workerGroup": "worker-group-project",
    "priority": "medium"
  },
  "nodes": [
    {
      "nodeId": "node-1",
      "type": "spark-sql",
      "config": {
        "inherit": true, // 继承DAG默认配置
        "engineOverride": "spark-high-mem" // 可选覆盖
      }
    },
    {
      "nodeId": "node-2",
      "type": "datax-migration",
      "config": {
        "inherit": true
      }
    }
  ]
}
```

### 资源分配机制

DAG执行时的资源分配：

1. **队列资源**: DAG整体使用队列资源配额
2. **并行限制**: 最大并行任务数控制并发
3. **内存限制**: 单任务和总内存限制防超额
4. **优先级调度**: 高优先级任务优先执行
