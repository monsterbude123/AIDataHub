# 项目列表页 - 页面设计规范

> 页面路径: `/project`
> 覆盖 MASTER 规范: 无

## 页面目标

展示所有项目概览，支持按状态、阶段、负责人筛选，提供项目创建入口和快速操作。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表                               │
│ 操作栏: [新建项目] [导入] [导出]                          │
├─────────────────────────────────────────────────────────┤
│ 统计卡片                                                 │
│ ┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐     │
│ │ 全部项目  │ │ 进行中   │ │ 已完成   │ │ 已归档   │     │
│ │   12     │ │    5     │ │    4     │ │    3     │     │
│ └──────────┘ └──────────┘ └──────────┘ └──────────┘     │
├─────────────────────────────────────────────────────────┤
│ 过滤栏: [搜索] [阶段筛选] [负责人] [时间范围] [视图切换]   │
├─────────────────────────────────────────────────────────┤
│                                                         │
│ 项目卡片列表（或表格视图）                                │
│                                                         │
│ 分页                                                     │
└─────────────────────────────────────────────────────────┘
```

## 统计卡片区域

| 卡片     | 说明                  | 点击行为   |
| -------- | --------------------- | ---------- |
| 全部项目 | 显示项目总数          | 重置筛选   |
| 进行中   | status=active 数量    | 筛选进行中 |
| 已完成   | status=completed 数量 | 筛选已完成 |
| 已归档   | status=archived 数量  | 筛选已归档 |

**卡片样式**:

- 宽度: 200px
- 高度: 80px
- 数字: H2 (24px), 粗体
- 标签: Body Small (14px)

## 过滤栏组件

| 过滤项   | 类型       | 说明                     |
| -------- | ---------- | ------------------------ |
| 搜索     | Input      | 按项目名称/编号搜索      |
| 阶段筛选 | Select     | 立项/规划/执行/验收/结项 |
| 负责人   | Select     | 用户下拉选择             |
| 时间范围 | DatePicker | 项目开始时间范围         |
| 视图切换 | Toggle     | 卡片视图 / 表格视图      |

每张卡片包含：

```

│                              │
```

**卡片规格**:

- 宽度: 320px
- 内边距: 16px

- 桌面 3 列，平板 2 列，移动端 1 列

**阶段标签样式**:
| 阶段 | 颜色 |
|------|------|
| 立项 | #6B7280 (Pending) |
| 规划 | #3B82F6 (Processing) |
| 执行 | #F59E0B (Warning) |
| 验收 | #10B981 (Success) |
| 结项 | #10B981 (Success) |

## 新建项目弹窗

**表单字段**:

| 字段         | 类型        | 必填 | 说明               |
| ------------ | ----------- | ---- | ------------------ |
| 项目名称     | Input       | 是   | 最大 100 字符      |
| 项目编号     | Input       | 否   | 自动生成，可自定义 |
| 项目描述     | TextArea    | 否   | 最大 500 字符      |
| 负责人       | Select      | 是   | 用户下拉选择       |
| 开始时间     | DatePicker  | 是   |                    |
| 预计完成时间 | DatePicker  | 是   |                    |
| 初始成员     | MultiSelect | 否   | 可添加多个成员     |

**流程**:

1. 填写基本信息
2. 选择初始成员（可选）
3. 创建成功后跳转到项目详情页

## 交互规范

- **新建**: 点击「新建项目」按钮，弹窗打开表单
- **编辑**: 卡片/表格操作菜单 → 编辑，打开编辑弹窗
- **归档**: 仅已完成项目可归档，二次确认
- **删除**: 仅项目经理可删除，二次确认
- **导入**: 导入 CSV/Excel 项目列表
- **导出**: 导出当前筛选结果到 Excel

## 权限控制

- 新建项目权限：系统级权限控制
- 编辑/删除：仅项目经理可操作
- 归档：仅已完成状态可归档
