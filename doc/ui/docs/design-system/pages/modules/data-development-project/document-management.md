# 文档管理页 - 页面设计规范

> 页面路径: `/project/[id]/docs`
> 覆盖 MASTER 规范: 文件目录树，拖拽上传

## 页面目标

管理项目相关文档、附件，支持分类管理、版本控制、在线预览。

## 布局结构

```
┌─────────────────────────────────────────────────────────┐
│ 面包屑: 数据项目 > 项目列表 > [项目名称] > 文档管理       │
│ 操作栏: [上传文档] [新建文件夹]                          │
├─────────────────────────────────────────────────────────┤
│ 左侧目录树              │  右侧文档列表                  │
│ ┌──────────────────┐    │  ┌──────────────────────────┐ │
│ │ 📁 项目文档 (根)  │    │  │ 文档名称 | 类型 | 大小... │ │
│ │   📁 需求文档     │    │  │                          │ │
│ │   📁 设计文档     │    │  │                          │ │
│ │   📁 会议纪要     │    │  │                          │ │
│ │   📁 交付文档     │    │  │                          │ │
│ │   📁 其他         │    │  │                          │ │
│ └──────────────────┘    │  └──────────────────────────┘ │
│                         │                               │
│ 目录宽度: 240px         │  文档详情/预览区域             │
│ 可折叠到 48px           │  (选中文档后显示)              │
├─────────────────────────┴───────────────────────────────┤
│ 文档详情/预览区域                                        │
└─────────────────────────────────────────────────────────┘
```

## 左侧目录树

**目录树结构**:

- 树形结构展示文件夹
- 支持折叠/展开
- 点击文件夹筛选右侧列表
- 高亮当前选中文件夹

**目录树操作**:

- 右键菜单：新建子文件夹、重命名、删除
- 拖拽调整顺序
- 拖拽文档到文件夹移动

**目录树样式**:

- 文件夹图标: Folder Icon (Lucide)
- 节点高度: 32px
- 缩进: 16px
- 悬浮高亮

**预置目录**:
| 目录名 | 说明 |
|--------|------|
| 需求文档 | 需求规格、需求变更等 |
| 设计文档 | 技术设计、方案设计等 |
| 会议纪要 | 会议记录、决策文档等 |
| 交付文档 | 验收文档、交付清单等 |
| 其他 | 其他项目文档 |

## 右侧文档列表

### 文档列表表格

| 列       | 说明                         | 宽度  |
| -------- | ---------------------------- | ----- |
| 文档名称 | 图标+名称，可点击预览        | 250px |
| 类型     | Word/Excel/PDF/PPT/图片/其他 | 100px |
| 大小     | 文件大小 (KB/MB)             | 80px  |
| 上传者   | 用户名 + 头像                | 120px |
| 上传时间 | YYYY-MM-DD HH:mm             | 150px |
| 版本     | 版本号，可点击查看历史       | 80px  |
| 操作     | 下载/预览/重命名/删除        | 150px |

**文档类型图标**:

| 类型  | 图标            | 颜色    |
| ----- | --------------- | ------- |
| Word  | FileText        | #2563EB |
| Excel | FileSpreadsheet | #10B981 |
| PDF   | FileText        | #EF4444 |
| PPT   | Presentation    | #F59E0B |
| 图片  | Image           | #3B82F6 |
| 其他  | File            | #6B7280 |

### 文档上传区域

**拖拽上传**:

- 支持拖拽文件到文档列表区域
- 拖拽时显示上传提示框
- 支持多文件批量上传

**点击上传**:

- 点击「上传文档」按钮
- 打开文件选择器
- 选择目标文件夹

**上传弹窗**:

```
┌──────────────────────────────────────┐
│ 上传文档                              │
│                                      │
│ 目标文件夹: [需求文档 ▼]              │
│                                      │
│ ┌────────────────────────────────┐  │
│ │     拖拽文件到此处              │  │
│ │     或点击选择文件              │  │
│ └────────────────────────────────┘  │
│                                      │
│ 已选择文件:                          │
│ - 需求规格说明书.docx (2.5MB)        │
│ - 需求变更记录.xlsx (1.2MB)         │
│                                      │
│              [上传] [取消]            │
└──────────────────────────────────────┘
```

**文件类型限制**:

- 允许: doc, docx, xls, xlsx, pdf, ppt, pptx, png, jpg, jpeg, zip, rar
- 单文件最大: 50MB
- 总上传最大: 200MB

```

│                                      │
│ ┌────────────────────────────────┐  │
│ │                                │  │

│ │                                │  │
│ └────────────────────────────────┘  │
│                                      │
│ 版本: v1.2                          │
│ 上传者: 张三                        │
```

## 交互规范

- **上传文档**: 点击「上传文档」或拖拽文件到列表区域
- **新建文件夹**: 点击「新建文件夹」按钮
- **预览文档**: 点击文档名称或「预览」按钮
- **下载文档**: 操作菜单 → 下载
- **重命名**: 操作菜单 → 重命名，弹窗输入新名称
- **删除**: 操作菜单 → 删除，二次确认
- **移动文档**: 拖拽文档到目标文件夹
- **查看版本**: 点击版本号查看历史版本
