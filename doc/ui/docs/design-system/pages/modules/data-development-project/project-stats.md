# 项目统计页 - 页面设计规范

> 页面路径: `/project/[id]/stats`
> 覆盖 MASTER 规范: 图表类型选择，KPI 卡片

## 页面目标

项目数据统计与可视化分析，展示项目进度、任务分布、资源投入等关键指标，支持报表导出。

## 时间范围筛选

| 筛选项 | 说明                    |
| ------ | ----------------------- |
| 本月   | 当前月份的数据          |
| 本季度 | 当前季度的数据          |
| 全年   | 当前年份的数据          |
| 全部   | 项目全周期数据          |
| 自定义 | DatePicker 选择时间范围 |

**样式**: Tab 筛选样式，选中高亮

## 概览卡片区域

### KPI 卡片规格

| 卡片     | 主指标      | 副指标     | 图标          |
| -------- | ----------- | ---------- | ------------- |
| 任务总数 | 任务总数    | 本周新增数 | ClipboardList |
| 完成率   | 完成百分比  | 较上周变化 | TrendingUp    |
| 里程碑   | 已完成/总数 | 完成数     | Flag          |
| 成员数   | 成员总数    | 活跃人数   | Users         |

**卡片样式**:

- 宽度: 200px
- 高度: 100px
- 主指标: H2 (24px), 粗体
- 副指标: Body Small (14px), 变化箭头
- 图标: 右上角，24px

**变化趋势显示**:

- 上升: ↑ + 绿色
- 下降: ↓ + 红色
- 持平: - + 灰色

## 图表区域

### 1. 任务完成趋势（折线图）

**数据维度**:

- X轴: 时间（按周/月划分）
- Y轴: 任务完成数量

**交互**:

- 鼠标悬浮显示具体数值
- 可切换按周/按月视图
- 支持缩放查看细节

**图表规格**:

- 宽度: 500px
- 高度: 300px
- 使用 Recharts LineChart

### 2. 任务类型分布（饼图）

**数据维度**:

- 数据集成任务数
- 数据治理任务数
- 任务调度任务数
- 数据分析任务数

**交互**:

- 鼠标悬浮显示具体数量和占比
- 点击扇区高亮对应类型

**图表规格**:

- 宽度: 400px
- 高度: 300px
- 使用 Recharts PieChart

**颜色方案**:
| 类型 | 颜色 |
|------|------|
| 数据集成 | #2563EB |
| 数据治理 | #10B981 |
| 任务调度 | #F59E0B |
| 数据分析 | #3B82F6 |

### 3. 阶段进度（甘特图/条形图）

**数据维度**:

- 各阶段计划进度
- 各阶段实际进度

**展示方式**:

- 横向条形图
- 左侧：阶段名称
- 右侧：计划条 + 实际条对比

**图表规格**:

- 宽度: 500px
- 高度: 200px
- 使用 Recharts BarChart

**颜色方案**:
| 进度类型 | 颜色 |
|----------|------|
| 计划进度 | #E2E8F0 (Border) |
| 实际进度 | #2563EB (Primary) |

### 4. 成员贡献（柱状图）

**数据维度**:

- X轴: 成员名称
- Y轴: 任务完成数

**交互**:

- 鼠标悬浮显示具体数值
- 按完成数排序

**图表规格**:

- 宽度: 400px
- 高度: 300px
- 使用 Recharts BarChart

## 导出功能

### 导出 PDF 报告

点击「导出PDF报告」:

- 生成项目统计报告
- 包含：概览指标、图表截图、汇总表格
- 格式：标准报告模板

### 导出 Excel 数据

点击「导出Excel数据」:

- 生成 Excel 文件
- 包含：原始数据、汇总数据、图表数据表
- 格式：.xlsx

## 交互规范

- **时间筛选**: 点击时间范围 Tab 切换数据
- **图表悬浮**: 鼠标悬浮显示详细数值
- **图表切换**: 部分图表支持视图切换（周/月）
- **导出**: 点击导出按钮，生成文件下载

## 推荐图表库

| 图表类型 | 推荐库                    |
| -------- | ------------------------- |
| 折线图   | Recharts LineChart        |
| 饼图     | Recharts PieChart         |
| 条形图   | Recharts BarChart         |
| 柱状图   | Recharts BarChart         |
| 甘特图   | 自定义实现或 frappe-gantt |
