# 数据入库映射配置页 - 页面设计规范

> 页面路径: `/data-organization/mapping`
> 覆盖 MASTER 规范: 无

## 页面目标

配置标准表到资源库/主题库的字段映射，预处理规则，执行入库任务。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 数据组织 > 数据入库       │
│ 基本信息: 任务名称、目标分层、描述  │
├──────────┬──────────┬────────────┤
│ 源表    │ 映射操作 │ 目标表     │
│ 字段列表 │          │ 字段列表   │
│          │  >>     │            │
│          │  <<     │            │
│          │ 自动匹配│            │
├───────────────────────────────────┤
│ 清洗筛选 & 函数预处理配置           │
├───────────────────────────────────┤
│ 已配置任务列表                     │
├───────────────────────────────────┤
│ 保存 / 立即执行                    │
└───────────────────────────────────┘
```

## 映射区域设计

与数据标准化配置页相同的左右分栏设计:

- **左侧**: 源表 (标准表) 字段列表，可勾选
- **中间**: 映射操作按钮 (全选、选中、自动匹配等)
- **右侧**: 目标表字段列表，拖拽调整顺序

**自动匹配**: 根据字段名称模糊匹配，减少手动工作量

## 清洗预处理配置

- **过滤条件**: 编写WHERE条件过滤数据
- **字段预处理**: 每个目标字段可配置预处理函数
  - 下拉选择函数
  - 输入参数
- **数据质量过滤**: 可配置是否过滤空值数据

## 浏览映射

可切换两个视角:

1. **从源表看**: 显示源表映射到哪些目标表
2. **从目标表看**: 显示目标表来自哪些源表

## 执行流程

1. 保存配置
2. 点击立即执行
3. 后台异步执行
4. 可在列表查看进度和日志
5. 失败后可查看错误信息，修正后重新执行

## 适用场景

- **资源库**: 标准表 -> 资源库
- **主题库**: 标准表 -> 主题库
- 支持多个源表整合到一个主题库表

## 特殊设计

- 支持调度周期配置 (定时执行)
- 支持增量/全量输出配置
- 执行后更新数据量统计
