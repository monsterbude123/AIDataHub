# 数据组织管理模块 - 页面索引

## 模块说明

按照方式和规则对数据进行归并存储，实现从生产库到服务库的合理分布存储。分为四个分层：业务库、原始库、资源库、主题库。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| 资源目录浏览 | [catalog.md](./catalog.md) | 树形目录逐层浏览资源 |
| 数据入库映射 | [mapping.md](./mapping.md) | 配置源表到目标表字段映射 |

## 分层说明

| 分层 | 说明 |
|------|------|
| **业务库** | 各专业领域业务数据库，支撑业务数据 |
| **原始库** | 保留原始数据，反映原始业务场景 |
| **资源库** | 综合各类数据资源建立公共数据集合 |
| **主题库** | 围绕主题对象整合各类数据 |
