# 数据地图页 - 页面设计规范

> 页面路径: `/governance/data-map`
> 覆盖 MASTER 规范: 多筛选条件，高密度布局

## 页面目标

多维度组合筛选数据资产，全文搜索，浏览数据分布。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据地图        │
│ 多条件筛选区                       │
│ [搜索框] 全文搜索                  │
├──────────┬────────────────────────┤
│ 筛选侧栏 │ 数据资产列表            │
│          │                        │
│          │ 分页                   │
│          │                        │
└──────────┴────────────────────────┘
```

## 多维度筛选 (左侧)

每组筛选条件一个区块:

| 维度 | 筛选方式 |
|------|----------|
| 数据分层 | 复选框: 业务库/原始库/资源库/主题库 |
| 来源地区 | 树形选择 |
| 获取方式 | 复选框: 采集/交换/导入/计算 |
| 资源位置 | 复选框: 数据库/HDFS/对象存储 |
| 数据组织 | 树形分类 |
| 行业 | 树形分类 |
| 分级分类 | 复选框 |

**已选条件**展示在顶部，可点击X移除。

## 数据资产列表卡片

每张卡片:

- 数据资产名称 (加粗)
- 所属路径: 目录层级面包屑
- 数据量: 行数/大小
- 更新时间
- 分级分类标签 (带颜色)
- 底部标签: 打标签展示
- 操作: 查看详情 / 导出台账

## 全文搜索

- 搜索框在顶部
- 支持拼音搜索
- 输入即时搜索 (debounce 300ms)
- 按相关性排序

## 资产详情弹窗

点击卡片打开弹窗展示详情:

- **基本信息**: 名称、路径、数据量、更新时间
- **元数据**: 字段列表，展示字段名、类型、描述
- **数据示例**: 前10行样本数据表格
- **血缘链接**: 点击跳转到血缘分析页

## 导出

- **导出数据台账**: 导出当前筛选结果，包含数据源、数据集、数据量等信息
- **导出血缘溯源台账**: 按血缘关系导出台账，展示数据来源去向

## 交互规范

- 筛选条件组合筛选
- 清空筛选按钮一键重置
- 支持按更新时间、数据量排序
- 移动端筛选侧栏可收起

## 性能考虑

- 筛选结果缓存
- 卡片列表虚拟滚动
- 搜索防抖
