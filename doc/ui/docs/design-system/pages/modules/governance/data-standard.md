# 数据标准管理页 - 页面设计规范

> 页面路径: `/governance/standards`
> 覆盖 MASTER 规范: 无

## 页面目标

定义数据标准，管理标准数据元和标准字典。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据标准管理    │
│ Tabs: 数据元 ▶ 标准字典 ▶ 类型映射 │
└───────────────────────────────────┘
```

---

### 布局

- 过滤栏: 搜索、分类筛选
- 数据元表格

### 数据元表格列

| 列 | 说明 |
|----|------|
| 数据元标识符 | |

## Tab 2: 标准字典管理

### 左侧分类树

- 树形分类目录
- 逐层浏览
- 支持增删改分类节点

### 右侧字典列表

分类点击后展示该分类下字典:

| 字典类型 | 布局 |
|----------|------|
| **自定义字典** | 支持用户添加字典项，表格展示: 编码 → 名称 → 排序 |
| **数据集字典** | 配置数据源 + 数据表 + 编码列 + 名称列，从数据库读取 |

### 操作

- 新增字典
- 编辑字典
- 删除字典 (确认)
- **刷新缓存**: 重新加载字典数据到缓存
- **导入**: 按模板批量导入自定义字典项
- **导出**: 导出字典项

### 特殊设计

- 字典数据缓存提高读取效率
- 数据标准化时关联字典做校验
- 数据服务输出时自动翻译字典编码为名称

---

## Tab 3: 标准类型映射

不同数据库有不同字段类型定义，映射到标准类型:

| 标准类型 | 数据库类型映射 |
|----------|--------------|
| 字符串 | VARCHAR, VARCHAR2, TEXT, STRING |
| 整数 | INT, INTEGER, BIGINT |
| 小数 | FLOAT, DOUBLE, DECIMAL, NUMERIC |
| 日期 | DATE |
| 时间 | TIME |
| 日期时间 | DATETIME, TIMESTAMP |
| 布尔 | BOOLEAN, BIT |

可新增/编辑/删除映射关系。

## 职责说明

> 本页面负责**定义**数据标准，标准化**执行**在数据集成模块的数据标准化页面

## 交互规范

- 搜索支持按数据元名称、标识符搜索
- 字典支持缓存，提高查询性能
- 变更后需要通知相关任务重新执行标准化
