# 数据治理管理模块 - 页面索引

## 模块说明

包含数据资源目录、数据质量管理、数据标签管理、数据血缘、数据标准管理、数据模型管理。提供完整数据治理能力。治理任务执行时引用基础设施配置资源。

## 功能页面

| 页面         | 文件                                     | 说明                             |
| ------------ | ---------------------------------------- | -------------------------------- |
| 数据地图     | [data-map.md](./data-map.md)             | 多维度组合筛选搜索数据资产       |
| 数据质量管理 | [data-quality.md](./data-quality.md)     | 质量规则配置、检测、工单         |
| 数据标签管理 | [tag-management.md](./tag-management.md) | 标签全生命周期管理、标签碰撞查询 |
| 数据血缘分析 | [lineage.md](./lineage.md)               | 图形化血缘展示、影响分析         |
| 数据标准管理 | [data-standard.md](./data-standard.md)   | 数据元、标准字典定义             |
| 数据模型管理 | [data-model.md](./data-model.md)         | 元模型、ER图、物理建表           |

## 核心特性

- 全文搜索数据资产，支持标签筛选
- 自动化质量检测，闭环工单处理
- 支持标签交集并集组合查询（标签碰撞）
- 自动血缘采集，图形化展示，影响范围分析
- ER图模型设计，支持版本管理和审批

## 治理任务配置

数据治理涉及多种执行任务，需要引用基础设施配置：

### 任务类型与资源配置

| 任务类型     | 引擎  | 队列 | Worker | 说明             |
| ------------ | ----- | ---- | ------ | ---------------- |
| 质量规则检测 | Spark | ✓    | -      | 执行质量规则检测 |
| 标签自动提取 | Spark | ✓    | ✓      | 自动打标签任务   |
| 血缘分析     | Spark | ✓    | -      | 血缘关系分析     |
| 数据模型发布 | -     | -    | ✓      | 物理表创建       |

## 配置模板预设

### 质量检测配置模板

| 模板名称      | 引擎配置            | 队列             | 适用场景           |
| ------------- | ------------------- | ---------------- | ------------------ |
| 质量检测-快速 | spark-quick-check   | queue-low        | 快速检测，少量规则 |
| 质量检测-标准 | spark-quality-check | queue-governance | 标准检测，常规规则 |
| 质量检测-深度 | spark-deep-check    | queue-high       | 深度检测，大量规则 |

### 标签提取配置模板

| 模板名称      | 引擎配置           | 适用场景     |
| ------------- | ------------------ | ------------ |
| 标签提取-基础 | spark-tag-basic    | 基础标签提取 |
| 标签提取-语义 | spark-tag-semantic | 语义分析标签 |

## 与基础设施模块的关联

| 关联项        | 说明                            |
| ------------- | ------------------------------- |
| Spark引擎配置 | 质量检测、标签提取使用Spark引擎 |
| 资源队列      | 治理任务提交到队列执行          |
| Worker节点    | 标签提取可指定Worker执行        |
| 配置模板      | 预设治理任务配置模板            |

## 配置继承说明

治理任务的配置继承链：

```
系统级治理配置 (spark-governance-default)
    ↓ 继承
租户级配置 (spark-tenant-a-governance)
    ↓ 引用
治理任务执行配置
```

## 治理任务监控

### 任务执行状态

| 列       | 说明                       |
| -------- | -------------------------- |
| 任务名称 | 治理任务名称               |
| 任务类型 | 质量检测/标签提取/血缘分析 |
| 数据范围 | 检测的数据表数量           |
| 状态     | 待执行/执行中/成功/失败    |
| 使用资源 | 引擎+队列信息              |
| 执行时间 | 开始-结束时间              |
| 操作     | 详情/日志/重新执行         |

### 质量检测结果统计

- 检测表数量
- 规则执行数量
- 问题数据条数
- 问题类型分布
