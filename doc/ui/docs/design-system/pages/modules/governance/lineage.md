# 数据血缘分析页 - 页面设计规范

> 页面路径: `/governance/lineage`
> 覆盖 MASTER 规范: 全屏图形展示，需要足够空间

## 页面目标

图形化展示数据血缘关系，分析影响范围。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据血缘        │
│ 搜索: [输入表名]  [定位]          │
│ 层级: ↑加号放大 ↓减号缩小  重置视图 │
├──────────────┬────────────────────┤
│              │                    │
│ 左侧树       │ 血缘图画布          │
│              │                    │
│              │                    │
│              │  (全屏可拖拽缩放)  │
│              │                    │
├──────────────┼────────────────────┤
│              │ 节点属性面板       │
│              │                    │
└──────────────┴────────────────────┘
```

## 左侧表树

- 树形展示数据源 -> 数据库 -> 表
- 支持搜索快速定位表
- 点击表名称在右侧画布展示血缘

## 中间血缘画布

- 使用 React-Flow 渲染
- 支持鼠标拖拽移动节点
- 支持滚轮缩放
- 支持框选多个节点
- 点击节点选中，右侧显示属性
- 箭头表示数据流向: 上游 → 当前节点 → 下游

### 颜色编码

| 节点类型  | 颜色 |
| --------- | ---- |
| 数据源表  | 蓝色 |
| ETL任务   | 橙色 |
| 数据服务  | 绿色 |
| 报表/指标 | 紫色 |

### 支持层级

- **表级血缘**: 展示表与表之间关系
- **字段级血缘**: 展示字段到字段的关系
- 可切换显示级别

## 右侧属性面板

选中节点后展示:

- **基本信息**: 名称、类型、描述
- **元数据信息**: 数据量、更新时间
- **ETL任务信息**: 调度周期、最近执行状态
- **操作**: 查看详情 / 刷新血缘 / 导出影响范围

## 影响分析功能

修改元数据前，自动分析下游影响:

- 图形高亮展示所有下游节点
- 分类统计: 影响多少个表、多少个数据服务、多少个报表
- 支持导出影响分析结果CSV
- 帮助评估修改风险

## 采集机制

- 自动从ETL任务、SQL开发、数据服务采集血缘关系
- 血缘自动更新，保持和实际一致
- 支持手动调整血缘关系

## 交互规范

- 双击节点可跳转到对应元数据详情页
- 滚轮缩放以鼠标位置为中心
- 双击背景重置视图到合适大小
- 支持导出血缘图为PNG图片

## 可访问性说明

- 复杂图形需要同时提供文字汇总表
- 表格列出所有上游节点和下游节点
- 屏幕阅读器可读取表格

## 性能考虑

- 超过100个节点提示用户缩小范围
- 展示TOP N 主要路径，隐藏不重要分支
- 使用Canvas渲染大图减少DOM节点数
