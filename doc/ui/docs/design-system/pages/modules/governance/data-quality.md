# 数据质量管理页 - 页面设计规范

> 页面路径: `/governance/data-quality`
> 覆盖 MASTER 规范: 多步骤流程，工单系统

## 页面目标

定义质量规则，配置质量检测任务，查看质量报告，发起质量工单。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据质量管理    │
│ Tabs: 规则定义 ▶ 任务配置 ▶ 质量统计 ▶ 工单 │
└───────────────────────────────────┘
```

---

## Tab 1: 质量规则定义

### 布局

过滤栏 + 规则列表

### 规则列表表格

| 列 | 说明 |
|----|------|
| 规则名称 | |
| 规则类型 | 标签: 一致性/准确性/完整性/规范性/关联性/自定义 |
| 状态 | 启用/禁用 |
| 审批状态 | 待审批/已通过/拒绝 |
| 创建人 | |
| 操作 | 编辑 / 复制 / 删除 / 查看 |

### 新增/编辑规则弹窗

表单:

| 字段 | 说明 |
|------|------|
| 规则名称 | 必填 |
| 规则类型 | 选择类型 |
| 规则表达式 | 编辑器编写校验条件 |
| 错误描述 | 检测不通过时描述 |
| 严重等级 | 低/中/高 |
| 状态 | 启用/禁用 |

**规则类型预置**:
- 一致性: 数据值符合格式规范
- 准确性: 数据值在合理范围
- 完整性: 空值率检查
- 规范性: 符合字典枚举
- 关联性: 外键关联存在
- 自定义: 用户自定义表达式

## Tab 2: 质量任务配置

### 布局

过滤栏 + 任务列表

### 任务列表表格

| 列 | 说明 |
|----|------|
| 任务名称 | |
| 数据资源 | |
| 规则数量 | |
| 调度周期 | |
| 状态 | 运行中/停止 |
| 最后执行结果 | 成功/失败/部分失败 |
| 操作 | 查看 / 执行 / 编辑 / 日志 |

### 新增质量任务

1. 选择数据资源
2. 选择检测规则 (可多选)
3. 配置调度周期
4. 配置质量告警条件
5. 保存

## Tab 3: 质量统计分析

### 布局

```
┌──────────┬──────────┐
│ KPI卡片区 │          │
├──────────┼──────────┤
│ 问题分布柱状图  │          │
├──────────┤          │
│ 趋势面积图    │          │
│             ← 质量问题趋势
└──────────┴──────────┘
```

### KPI卡片

- 检测资源数
- 总记录数
- 问题记录数
- 问题占比 %

### 交互

- 时间范围筛选
- 按规则类型筛选
- 导出质量报告PDF/Excel

## Tab 4: 质量工单

### 工单列表

| 列 | 说明 |
|----|------|
| 工单标题 | |
| 问题数据资源 | |
| 发起人 | |
| 负责人 | |
| 状态 | 待处理/处理中/已解决 |
| 创建时间 | |
| 操作 | 查看 / 处理 |

### 工单详情

- 基本信息
- 问题描述
- 质量检测结果
- 问题数据预览 (在线查看前100行)
- 处理留言区
- 处理按钮: 认领 / 解决 / 驳回

## 审批流程

- 可配置规则开关: 开启后新增规则需要审批才能使用
- 可配置任务开关: 开启后新增任务需要审批才能执行
- 审批使用系统统一审批流程

## 交互规范

- 质量任务完成后，如果问题数超过阈值，自动发起工单给负责人
- 支持手动发起工单
- 工单状态变化发送消息通知负责人
