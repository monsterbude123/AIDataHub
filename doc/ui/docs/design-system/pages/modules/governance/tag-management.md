# 数据标签管理页 - 页面设计规范

> 页面路径: `/governance/tags`
> 覆盖 MASTER 规范: 卡片网格布局适合标签展示

## 页面目标

标签全生命周期管理，通过标签刻画对象特征，支持标签碰撞查询。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据治理 > 数据标签管理     │
│ 过滤栏: [搜索] [分类筛选] [等级]   │
│ [新增标签]                         │
├──────────────┬────────────────────┤
│ 分类树      │ 标签卡片网格        │
│             │                    │
│             │                    │
│             │                    │
└──────────────┴────────────────────┘
```

## 左侧分类树

- 支持业务灵活分类
- 逐层浏览
- 支持增删改节点
- 支持检索分类
- 点击分类筛选右侧标签

## 右侧标签卡片网格

每张卡片:

- **标签名称** (加粗)
- **标签编码** (小字灰色)
- **标签描述** (两行截断)
- **统计信息**: 数据总量 / 昨日增量 / 规则数
- **等级标签**: 一级/二级/三级 (颜色不同)
- **操作**: 编辑 / 规则配置 / 查询数据 / 删除

### 网格响应式

- 桌面: 4列
- 平板: 2-3列
- 移动端: 1列

## 新增/编辑标签弹窗

表单:

| 字段 | 说明 |
|------|------|
| 标签名称 | 必填 |
| 标签编码 | 必填，唯一 |
| 标签分类 | 树形选择 |
| 标签等级 | 选择: 一级/二级/三级 |
| 标签描述 | 文本域 |

## 标签规则配置页

配置标签提取规则:

| 区域 | 说明 |
|------|------|
| 数据源选择 | 选择数据资源 |
| 提取条件 | 配置WHERE条件决定哪些记录打此标签 |
| 提取方式 | 全量提取 / 增量提取 |
| 调度周期 | 定时重新提取 |

**支持同一标签配置多个规则**，结果合并。

## 标签任务监控

弹窗展示提取任务:

| 列 | 说明 |
|----|------|
| 执行时间 | |
| 提取方式 | 全量/增量 |
| 提取记录数 | |
| 新增标签数 | |
| 状态 | 成功/失败 |
| 操作 | 查看日志 |

## 标签数据查询页

- 左侧: 标签目录树，勾选多个标签
- **组合条件选择**: 交集 / 并集 (单选)
- 右侧: 结果列表，展示标签主体
- 支持按对象属性检索
- 支持导出查询结果

## 标签主体管理

- 支持增删改标签主体
- 支持全文检索主体
- 展示每个主体关联的标签

## 交互规范

- 标签提取任务异步执行
- 失败可查看错误日志重新执行
- 支持批量删除标签
- 删除需要二次确认

## 特殊设计

- **交集**: 同时满足所有勾选标签
- **并集**: 满足任一勾选标签
- 这个功能叫"标签碰撞"，支持多标签组合精准定位
