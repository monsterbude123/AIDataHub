# 公共页面 - 页面索引

> 不归属业务模块的公共页面，不在菜单栏显示

## 模块说明

不归属业务模块的公共页面，如登录、个人中心、错误页等。

## 功能页面

### 非菜单页面

| 页面      | 类型  | 路由       | 入口方式         | 文档                       |
| --------- | ----- | ---------- | ---------------- | -------------------------- |
| 登录页    | `[C]` | `/login`   | 未登录自动跳转   | [login.md](./login.md)     |
| 个人中心  | `[D]` | `/profile` | 用户头像下拉菜单 | [profile.md](./profile.md) |
| 404错误页 | `[C]` | `/404`     | 路由不存在时显示 | -                          |
| 403错误页 | `[C]` | `/403`     | 无权限时显示     | -                          |
| 500错误页 | `[C]` | `/500`     | 服务器错误时显示 | -                          |

**页面类型说明**：

- `[C]` 配置页面 - 系统级页面，不在菜单
- `[D]` 详情页面 - 从用户菜单进入，不在侧边菜单栏

## 导航结构

```
公共页面 (不在侧边菜单栏)

├── 404错误页 [C] (/404)
├── 403错误页 [C] (/403)
└── 500错误页 [C] (/500)
```
