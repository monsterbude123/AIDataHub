# 登录页面 - 页面设计规范

> 页面路径: `/login`
> 覆盖 MASTER 规范: 居中简约设计

## 页面目标

用户登录认证，支持第三方登录，密码找回。

## 布局结构

```
┌───────────────────────────────────────┐
│                                       │
│                                       │
│    [Logo]  AIDataHub 数据中台        │
│                                       │
│          ┌─────────────────┐          │
│          │  用户名         │          │
│          ├─────────────────┤          │
│          │  密码           │          │
│          ├─────────────────┤          │
│          │ [ 记住我 ]      │          │
│          ├─────────────────┤          │
│          │ [     登录     ] │          │
│          └─────────────────┘          │
│                                       │
│       忘记密码 | 注册新账号            │
│                                       │
│       其他登录方式:                    │
│    [OAuth2图标] [LDAP图标]            │
│                                       │
│                                       │
└───────────────────────────────────────┘
```

## 设计风格

- **左右布局**: 左侧品牌宣传图，右侧登录表单
- 移动端: 垂直排列，隐藏宣传图，只保留登录表单
- 简约干净，企业级风格

## 登录表单

| 字段          | 说明                                    |
| ------------- | --------------------------------------- |
| 用户名 / 账号 | 文本输入，支持自动完成                  |
| 密码          | 密码输入，支持点击眼睛图标显示/隐藏明文 |
| 记住我        | 复选框，勾选后记住登录状态7天           |
| 登录按钮      | 主要CTA，点击提交登录                   |

## 底部链接

- **忘记密码**: 跳转到密码重置页面
- **注册账号**: 跳转到注册页面 (如果开放注册)

## 第三方登录

支持多种认证方式:

- OAuth2 统一身份认证
- LDAP 认证
- AD 域认证

每个方式一个图标按钮，点击跳转对应认证。

## 交互规范

- **表单验证**: 失去焦点即时验证必填项
- **错误提示**: 用户名密码错误显示在表单上方红色
- **加载状态**: 登录中按钮禁用，显示loading spinner
- **回车键**: 输入完按回车直接提交
- **记住登录**: 默认不勾选，由用户选择

## 安全考虑

- 密码输入默认隐藏
- 登录失败锁定账户 (可配置次数)
- 验证码: 失败多次后显示图形验证码
- 登录成功跳转到首页或之前页面
- 已登录用户访问/login自动跳转到首页

## 响应式

- **Desktop (>1024px)**: 左右分栏，各占50%
- **Tablet (768-1024px)**: 表单居中，最大宽度400px
- **Mobile (<768px)**: 全屏表单，边距16px

## 配色

- 背景: 渐变色或浅色背景，主品牌色左上角点缀
- Logo: 居中顶部
- 表单卡片: 白色背景阴影，圆角
- 登录按钮: 主品牌色背景，白色文字
