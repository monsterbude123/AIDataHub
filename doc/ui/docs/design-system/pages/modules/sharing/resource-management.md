# 共享资源管理页 - 页面设计规范

> 页面路径: `/sharing/resources`
> 覆盖 MASTER 规范: 分步登记流程

## 页面目标

管理共享资源目录，登记不同类型资源，发布服务。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 共享交换 > 资源管理    │
│ [新增编制资源] [导入] [导出]       │
├──────────────┬────────────────────┤
│ 目录树      │ 资源列表            │
│             │                    │
│             │                    │
│             │                    │
└──────────────┴────────────────────┘
```

## 左侧目录树

- 支持增删改目录节点
- 名称唯一性校验
- 自动编码
- 点击筛选右侧列表

## 右侧资源列表

表格:

| 列 | 说明 |
|----|------|
| 资源名称 | |
| 资源类型 | 库表/接口/文件/应用 |
| 共享类型 | 无条件/有条件/不共享 |
| 状态 | 未发布/已发布/已取消 |
| 创建人 | |
| 创建时间 | |
| 操作 | 详情 / 编辑 / 发布 / 取消 |

## 新增编制资源 (分步表单)

### 步骤 1: 基本信息
- 选择目录
- 填写资源名称
- 选择资源类型: 库表数据 / 接口数据 / 文件数据 / 应用系统

### 步骤 2: 资源登记 (不同类型不同表单)

**库表数据登记**:
- 选择数据源
- 选择数据表
- 测试连接
- 可选择采集方式: 远程采集 / 自定义SQL
- 预览字段信息

**接口数据登记**:
- 代理接口: 填写URL、认证方式、参数
- 封装接口: 登记已封装接口

**文件数据登记**:
- 上传文件到文件系统
- 填写描述
- 支持预览、下载、删除

**应用系统登记**:
- 基本信息填写
- 访问地址

### 步骤 3: 共享配置
- 设置共享类型: 无条件共享 / 有条件共享 / 不共享
- 选择可共享数据项
- 配置服务

## 发布与审核

- 新增后未发布需要上报审核
- 审核通过后才能发布
- 已发布可取消发布（需要审核）
- **编辑规则**: 未发布可修改删除；已发布只能修改基本信息不能修改数据项；已取消只能逻辑删除

## 服务登记

资源挂接后，登记服务:
- 不同资源类型支持不同服务类型
- 配置查询参数和返回字段
- 只有已发布可共享资源才能登记服务
- 发布服务后才能申请使用

## 交互规范

- 一键自动映射 (从资源字段映射到服务字段)
- 支持搜索资源名称
- 分页展示
- 增删改操作需要对应权限
- 目录节点支持右键菜单操作

## 权限

- 资源创建者可管理自己的资源
- 管理员可管理所有资源
- 只有审核通过才能发布
