# 共享交换首页仪表盘 - 页面设计规范

> 页面路径: `/sharing/home`
> 覆盖 MASTER 规范: 多KPI卡片 + 排行表格

## 页面目标

首页概览统计，展示待办和排行。

## 布局结构

```
┌──────────────────┬──────────────────┐
│  待办任务统计    │  资源目录统计    │  ← 第一排两个KPI卡片
├──────────────────┼──────────────────┤
│  热门资源TOP 10 │ 资源申请共享排行 │  ← 第二排两个表格
├──────────────────┴──────────────────┤
│                                  │
│  需求申请汇总表格                  │
│                                  │
└───────────────────────────────────┘
```

|------|------|

按资源类型分类统计资源数量:

|----------|------|

## 交互规范

- 点击排行项目跳转到对应的详情页
- 点击待办统计数字跳转到事项任务页
- 首页数据每日刷新，也支持手动点击刷新按钮
- 所有数据都是当前用户部门权限范围内可见

## 设计要点

- 卡片布局简洁，信息密度适中
- 排行榜用行背景深浅区分奇偶行
- 排名第一用金色背景突出展示
