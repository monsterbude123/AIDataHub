# DAG任务编排页 - 页面设计规范

> 页面路径: `/scheduler/dag`
> 覆盖 MASTER 规范: 全屏画布设计，需要最大化可用空间

## 页面目标

可视化DAG任务编排，配置任务依赖关系。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 任务调度 > DAG编排     │
│ [保存] [验证] [运行] [全屏]       │
├──────────┬────────────────────────┤
│ 节点面板  │       DAG画布          │
│ (节点类型)│                        │
│          │                        │
│          │ 拖拽节点，连线配置依赖  │
│          │                        │
│          │                        │
├──────────┼────────────────────────┤
│ 属性面板  │ 选中节点显示属性配置   │
└──────────┴────────────────────────┘
```

## 左侧节点面板

可拖拽节点类型:

| 分类 | 节点类型 |
|------|----------|
| 数据集成 | 数据接入、数据探查、标准化 |
| 数据治理 | 质量检测、标签提取 |
| 数据处理 | Spark SQL、Python脚本 |
| 控制流 | 条件分支、循环 |

拖拽节点到画布添加节点。

## 中间DAG画布

- 使用 React-Flow 渲染
- 支持拖拽移动节点
- 支持拖拽节点边缘连接两个节点 (上游 → 下游)
- 支持点击节点选中，右侧显示属性
- 支持删除节点 (删除不影响连接线自动重连)
- 支持画布缩放平移
- 箭头表示依赖关系：上游完成 → 下游开始

## 右侧属性面板

选中节点后显示配置:

| 属性 | 说明 |
|------|------|
| 节点名称 | 可编辑 |
| 任务类型 | 只读 |
| 关联任务 | 选择已存在的任务 |
| 执行参数 | JSON配置 |
| 超时设置 | 分钟 |
| 重试次数 | 失败重试次数 |
| 失败策略 | 继续 / 停止整个流程 |

## 调度配置 (DAG级别)

底部或顶部配置:

- **调度策略**:
  - 定时调度: cron表达式
  - 事件触发: 上游任务完成触发
  - 依赖触发: 满足所有依赖完成触发
- **优先级**: 高 / 中 / 低
- **执行队列**: 选择资源队列

## 操作按钮

- **保存**: 保存DAG配置
- **验证**: 验证DAG正确性 (检查环路、检查孤立节点)
- **立即运行**: 立即执行一次
- **全屏**: 全屏画布编排

## 验证规则

前端验证必须通过才能保存:

1. 不能有环路
2. 不能有孤立节点 (没有入口也没有出口)
3. 所有必需参数已配置
4. 所有节点关联有效的任务

## 交互规范

- Ctrl+Z 撤销，Ctrl+Shift+Z 重做
- Delete 删除选中节点
- 空格 + 拖拽平移画布
- 滚轮缩放
- 双击节点编辑名称

## 性能考虑

- 画布超过50个节点提示简化
- 使用虚拟滚动节点面板
- 防抖处理画布变更
