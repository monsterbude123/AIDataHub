# 统一日志中心页 - 页面设计规范

> 页面路径: `/scheduler/logs`
> 覆盖 MASTER 规范: 流式日志展示，搜索过滤

## 页面目标

统一收集查看各任务运行日志，支持搜索过滤。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 任务调度 > 日志中心    │
│ 过滤栏: 任务 [时间范围] [级别] [搜索]│
│ 自动刷新 [开关]                    │
├───────────────────────────────────┤
│                                  │
│ 日志列表流式展示                  │
│                                  │
│ 加载更多                          │
│                                  │
└───────────────────────────────────┘
```

## 过滤条件

| 过滤项 | 说明 |
|--------|------|
| **任务** | 下拉选择任务名称 |
| **执行ID** | 输入某次执行ID |
| **时间范围** | 开始结束时间 |
| **日志级别** | 复选: DEBUG / INFO / WARN / ERROR |
| **关键词** | 搜索关键词，支持模糊搜索 |

## 日志展示

每条日志展示:

- **时间戳** (灰色小字左侧)
- **日志级别** (带颜色标签):
  - DEBUG: 灰色
  - INFO: 蓝色
  - WARN: 黄色
  - ERROR: 红色
- **日志内容** (自动换行，超长折叠，点击展开)

## 交互规范

- **自动刷新**: 开启后每10秒刷新追加新日志
- **加载更多**: 滚动到底部加载更多历史日志
- **关键词高亮**: 搜索关键词在日志内容中高亮
- **下载日志**: 支持下载本次执行完整日志文件
- **清空**: 清空当前展示

## 特殊设计

- 不同级别不同颜色，ERROR更容易发现
- 超长日志自动折叠避免页面过长
- 支持按执行ID查看单次执行完整日志
- 日志按时间倒序排列 (最新在前)

## 性能考虑

- 流式加载，不一次性加载所有日志
- 搜索在服务端完成
- 高亮不重渲染整个列表，只高亮当前页
