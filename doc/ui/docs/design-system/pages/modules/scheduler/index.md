# 统一任务调度中心模块 - 页面索引

## 模块说明

✨ 新增统一调度能力，原有各模块任务管理保留，调度由统一中心负责。支持DAG可视化编排，多种触发策略。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| DAG任务编排 | [dag.md](./dag.md) | 可视化DAG拖拽编排 |
| 任务运维列表 | [task-list.md](./task-list.md) | 任务监控运维 |
| 统一日志中心 | [log-center.md](./log-center.md) | 统一收集查看任务日志 |

## 核心特性

- 可视化DAG任务编排，配置任务依赖关系
- 支持定时调度、事件触发、依赖触发
- 任务队列优先级调度，集群负载均衡
- 支持失败重试、超时告警、多渠道通知
- 数据对账一致性检查
