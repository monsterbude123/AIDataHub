# 任务运维列表页 - 页面设计规范

> 页面路径: `/scheduler/tasks`
> 覆盖 MASTER 规范: 高密度表格，多筛选条件

## 页面目标

监控所有任务执行情况，支持运维操作。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 任务调度 > 任务运维    │
│ 过滤栏: [搜索] [状态] [类型] [时间]│
│ [刷新] [导出]                    │
├───────────────────────────────────┤
│                                  │
│ 任务列表表格                     │
│                                  │
│ 分页                             │
│                                  │
└───────────────────────────────────┘
```

## 任务列表表格

| 列 | 说明 |
|----|------|
| 任务名称 | 链接到DAG编排 |
| 任务类型 | 标签 |
| 调度类型 | 定时/事件/依赖 |
| 优先级 | 高/中/低 (颜色标识) |
| 最后执行时间 | |
| 最后执行状态 | 成功/失败/运行中 (颜色圆点) |
| 当前状态 | 在线/下线 |
| 操作 | 查看日志 / 重新执行 / 修改 / 下线 |

## 过滤条件

- **搜索**: 按任务名称搜索
- **状态筛选**: 全部 / 成功 / 失败 / 运行中
- **类型筛选**: 按任务类型筛选
- **时间范围**: 最后执行时间范围

## 操作功能

- **重新执行**: 手动触发重新执行
- **查看异常详情**: 弹窗展示错误堆栈
- **下线**: 下线后无法重新执行，保留配置
- **批量重新执行**: 勾选多个批量执行

## 告警配置

每个任务可配置告警:

- 超时预警: N分钟未完成告警
- 数据增量预警: 增量低于N条告警
- 调度超时预警: 到点未调度告警
- 告警通知渠道: 邮件 / 短信 / 钉钉

## 对账功能

支持数据对账:

- 定时检测来源表和目的表的数据量一致性
- 差异超过阈值发送告警
- 对账结果可查看

## 失败重试策略

可针对不同错误类型配置重试策略:

- 网络异常: 自动重试3次
- 数据库迁移锁: 等待后重试
- 数据错误: 不重试，立即告警

## 交互规范

- 自动刷新 (可配置间隔，默认 30秒)
- 点击任务名称跳转到编排页
- 状态颜色标识一目了然
- 异常行背景浅黄色提醒

## 报表

支持导出任务运维报表:

- 任务运行比例统计
- 成功率统计
- 按类型分组统计
- 导出Excel
