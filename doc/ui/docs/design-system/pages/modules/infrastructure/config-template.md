# 配置模板管理页 - 页面设计规范

> 页面路径: `/infrastructure/template`
> 所属模块: 基础设施管理模块
> 覆盖 MASTER 规范: 分组展示，模板卡片

## 页面目标

管理数据中台的预设配置模板，包括任务配置模板、资源模板、参数模板等，提供模板复用能力，简化任务配置流程，确保配置规范统一。

## 模板分类说明

| 分类     | 说明             | 适用场景                     |
| -------- | ---------------- | ---------------------------- |
| 任务模板 | 任务执行参数模板 | 数据迁移、数据探查等任务配置 |
| 资源模板 | 资源配置模板     | 队列配置、Worker分组配置     |
| 参数模板 | 引擎参数模板     | Spark/Flink/DataX参数预设    |
| 组合模板 | 多配置组合模板   | 引擎+队列+Worker组合预设     |

## 新建模板流程

### 步骤 1: 基本信息

| 配置项   | 类型        | 必填 | 说明                |
| -------- | ----------- | ---- | ------------------- |
| 模板名称 | Input       | ✓    | 模板显示名称        |
| 模板类型 | Select      | ✓    | 任务/资源/参数/组合 |
| 适用模块 | MultiSelect | ✓    | 可使用的模块列表    |
| 标签     | MultiSelect | ✗    | 模板特性标签        |
| 描述     | TextArea    | ✗    | 模板说明和适用场景  |

### 步骤 2: 配置内容

根据模板类型显示配置项：

**任务模板**:

- 引擎配置引用
- 引擎参数覆盖
- 队列配置引用
- Worker配置引用
- 执行策略参数

**资源模板**:

- 队列配置预设
- Worker分组预设
- 资源限制预设

**参数模板**:

- 引擎类型选择
- 参数配置表格
- 参数说明

**组合模板**:

- 选择多个配置引用
- 组合方式说明
- 适用场景描述

### 步骤 3: 预览确认

展示模板完整配置，确认后保存。

## 模板使用流程

### 从模板创建配置

```
任务创建页面
    ↓
选择"使用模板"
    ↓
选择合适的模板
    ↓
基于模板填充配置
    ↓
可调整参数
    ↓
保存配置
```

## 模板导入导出

### 导出模板

支持导出模板为JSON格式：

```
{
  "name": "迁移-大数据量",
  "type": "combination",
  "version": "1.0",
  "config": {
    "engine": {
      "type": "Spark",
      "ref": "spark-high-mem",
      "override": {
        "spark.executor.memory": "16g",
        "spark.executor.instances": "8"
      }
    },
    "queue": {
      "ref": "queue-high-priority",
      "priority": 8
    },
    "worker": {
      "ref": "worker-group-high-mem",
      "strategy": "leastLoad"
    }
  },
  "metadata": {
    "description": "适用于大数据量迁移场景",
    "tags": ["spark", "high-mem", "migration"]
  }
}
```

### 导入模板

支持从JSON文件导入模板：

- 选择JSON文件上传
- 校验模板格式
- 预览模板内容
- 确认导入

## 与其他模块的集成

### 模板引用点

| 模块        | 引用位置       | 说明             |
| ----------- | -------------- | ---------------- |
| 数据迁移    | 任务配置页     | 选择迁移任务模板 |

### 模板与配置的关系

```
配置模板 (预设)
    ↓ 应用
任务配置 (实例)
    ↓ 引用
引擎配置 + 队列配置 + Worker配置
    ↓ 执行
实际执行参数
```

## 技术实现要点

- **模板存储**: 数据库存储模板定义
- **版本管理**: 模板变更记录版本
- **引用计数**: 记录模板使用次数
- **模板校验**: 导入时校验模板格式
- **配置合并**: 应用模板时合并配置
- **标签索引**: 按标签快速检索模板
