# 数据探查页 - 页面设计规范

> 页面路径: `/data-integration/profiling`
> 覆盖 MASTER 规范: 无

## 页面目标

对待接入数据进行多维度分析，为数据定义提供依据。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据集成 > 数据探查          │
├──────────────┬────────────────────┤
│ 目录树       │ 顶部KPI概览         │
│             ├────────────────────┤
│             │ 数据样本表格        │
│             ├────────────────────┤
│             │ 元数据编辑区        │
│             │                    │
└──────────────┴────────────────────┘
```

## 顶部KPI概览卡片

行排列展示关键统计数据:

| 指标 | 说明 |
|------|------|
| 资源总量 | 总行数 |
| 空值率 | 平均空值百分比 |
| 有值率 | 平均有值百分比 |
| 增量 | 本次探查增量数据量 |

## 数据样本表格

- 分页展示抽样数据
- 默认展示前 100 行
- 列宽可拖拽调整
- 支持排序

## 元数据编辑区

表格形式展示每个字段:

| 列 | 操作 |
|----|------|
| 字段名 | 展示 |
| 数据类型 | 展示 (检测到的) |
| 描述 | 可编辑输入 |
| 关联标准数据元 | 可选择下拉 |
| 关联字典 | 可选择下拉 |
| 分级分类 | 可选择 |
| 操作 | 编辑/保存 |

## 交互规范

- **发起探查**: 点击「开始探查」按钮，后台执行任务
- **进度显示**: 实时展示探查进度
- **完成后**: 自动刷新统计数据和样本
- **检索**: 支持按字段名称检索数据项
- **保存元数据**: 批量保存所有修改

## 特殊设计

- 空值率过高的字段行背景浅黄色提醒
- 用户可基于探查结果修改元数据
- 探查结果保存后可进入下一步标准化处理
