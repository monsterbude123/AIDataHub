# 数据探查页 - 页面设计规范

> 页面路径: `/integration/profiling`
> 所属模块: 数据集成管理模块
> 覆盖 MASTER 规范: 左右分栏布局

## 页面目标

对待接入数据进行多维度分析，为数据定义提供依据。探查任务执行时引用基础设施配置资源。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│ 面包屑: 数据集成 > 数据探查                                    │
│ 操作栏: [新建探查任务] [刷新] [导出]                            │
├─────────────────────────────────────────────────────────────┤
│ 过滤栏: [数据源] [数据库] [表] [状态] [时间范围]                 │
├─────────────────────────────────────────────────────────────┤
│ 探查任务列表表格                                              │
│                                                             │
│ 分页                                                         │
└─────────────────────────────────────────────────────────────┘
```

## 新建探查任务流程

### 步骤 1: 选择数据源

| 配置项   | 类型   | 必填     | 说明                |
| -------- | ------ | -------- | ------------------- |
| 数据源   | Select | ✓        | 选择已配置的数据源  |
| 数据库   | Select | ✓        | 选择数据库          |
| 表       | Select | ✓        | 选择要探查的表      |
| 采样方式 | Radio  | ✓        | 全量/采样           |
| 采样比例 | Input  | 采样必填 | 采样百分比，默认10% |

### 步骤 3: 确认执行

展示配置摘要，确认后开始执行。

## 交互规范

- **发起探查**: 点击「开始探查」按钮，后台执行任务
- **进度显示**: 实时展示探查进度
- **完成后**: 自动刷新统计数据和样本
- **检索**: 支持按字段名称检索数据项
- **保存元数据**: 批量保存所有修改
- **配置复用**: 支持保存为配置模板

## 配置继承说明

探查任务的配置继承链：

```
系统级引擎配置 (spark-default)
    ↓ 继承
租户级引擎配置 (spark-tenant-a-default)
    ↓ 引用
探查任务执行配置
```

探查任务执行时：

1. 从基础设施模块获取引擎配置
2. 提交任务到指定的资源队列
3. 由队列分配资源执行探查
4. 收集探查结果并展示
