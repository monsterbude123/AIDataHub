# 数据源列表页 - 页面设计规范

> 页面路径: `/data-integration/sources`
> 覆盖 MASTER 规范: 无

## 页面目标

展示所有已配置的数据源，支持按目录分类浏览、搜索、增删改操作。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据集成 > 数据源管理        │
├──────────────┬────────────────────┤
│              │                    │
│  目录树      │  过滤栏 + 列表      │
│  (折叠支持)  │  搜索: 名称搜索     │
│              │  状态: 全部/已连接 │
│              │                    │
│              │ 数据源卡片网格      │
│              │                    │
│              │ 分页控件           │
│              │                    │
└──────────────┴────────────────────┘
```

## 左侧目录树

- 树形结构展示业务分类
- 支持折叠/展开
- 点击节点筛选右侧列表
- **右键菜单**: 新增子目录、重命名、删除
- 尺寸: 240px 宽度，可折叠到 48px (仅图标)

## 右侧数据源卡片网格

- 卡片布局: 桌面 3 列，平板 2 列，移动端 1 列
- 每张卡片包含:
  - 数据源类型图标 (MySQL/Oracle/等)
  - 数据源名称
  - 业务描述 (截断)
  - 连接状态点 (绿/红)
  - 创建时间
  - 操作菜单 (编辑/测试/删除)

## 交互规范

- **新建**: 右上角「新增数据源」按钮，弹窗打开分步表单
- **编辑**: 卡片操作菜单 → 编辑
- **删除**: 二次确认，仅未使用的数据源可删除
- **连接测试**: 测试后显示结果 Toast 通知
- **搜索**: 输入关键词即时过滤

## 特殊设计

- 连接状态用有色圆点展示，鼠标悬浮显示最后检测时间
- 支持拖拽调整目录树顺序

## 权限控制

- 仅有权限用户可看到新增/编辑/删除按钮
- 按业务系统隔离权限，用户只能看到授权的数据源

## 空状态设计

当列表无数据源时显示空状态：

```
┌───────────────────────────────────┐
│                                   │
│          [数据库图标 64px]         │
│              #94A3B8              │
│                                   │
│          暂无数据源               │
│   点击下方按钮创建第一个数据源     │
│                                   │
│         [新增数据源]              │
│                                   │
└───────────────────────────────────┘
```

### 空状态规范

| 元素     | 规格                                          |
| -------- | --------------------------------------------- |
| 图标     | `database-off`, 64px, #94A3B8                 |
| 主文案   | "暂无数据源", 16px, #475569                   |
| 副文案   | "点击下方按钮创建第一个数据源", 14px, #94A3B8 |
| 操作按钮 | Primary Button, "新增数据源"                  |

### 无权限空状态

当用户无权限访问任何数据源时：

| 元素     | 规格                                            |
| -------- | ----------------------------------------------- |
| 图标     | `lock`, 64px, #94A3B8                           |
| 主文案   | "无访问权限", 16px, #475569                     |
| 副文案   | "请联系管理员申请数据源访问权限", 14px, #94A3B8 |
| 操作按钮 | 文字链接, "申请权限"                            |

## 加载状态

| 场景       | 加载方式                |
| ---------- | ----------------------- |
| 初始加载   | Skeleton 卡片网格 (3列) |
| 目录树加载 | Skeleton 树结构         |
| 搜索加载   | Spinner 覆盖            |

## 跨模块关联入口

从数据源卡片可快速跳转到相关功能：

| 入口     | 位置         | 跳转目标                                      |
| -------- | ------------ | --------------------------------------------- |
| 探查数据 | 卡片操作菜单 | `/integration/profiling?sourceId=[id]`        |
| 创建迁移 | 卡片操作菜单 | `/integration/migration/create?sourceId=[id]` |
| 查看血缘 | 卡片操作菜单 | `/governance/lineage?table=[tableName]`       |

**入口样式**: 在卡片底部操作区添加为下拉菜单项
