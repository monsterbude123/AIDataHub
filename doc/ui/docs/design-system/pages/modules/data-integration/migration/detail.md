# 迁移任务详情页 - 页面设计规范

> 页面路径: `/integration/migration/[taskId]`
> 所属模块: 数据集成管理模块
> 覆盖 MASTER 规范: 详情页布局，多信息区域组织

## 页面目标

展示单个迁移任务的完整信息，包括基本信息、执行进度、数据统计、迁移详情和操作历史。

## 布局结构

``
┌─────────────────────────────────────────────────────────────┐
│ 面包屑: 数据集成 > 数据迁移 > [任务名称] │
│ 任务标题 + 状态标签 + 操作按钮 │
├─────────────────────────────────────────────────────────────┤
│ 执行进度卡片 │
│ ┌───────────────────────────────────────────────────────┐ │
│ │ 进度条 + 实时统计 + 时间信息 │ │
│ └───────────────────────────────────────────────────────┘ │
├─────────────────────────────────────────────────────────────┤
│ Tab 导航: [执行概览] [表详情] [执行历史] [配置信息] │
├─────────────────────────────────────────────────────────────┤
│ │
│ Tab 内容区域 │
│ │
└─────────────────────────────────────────────────────────────┘

```

## 页面顶部区域

### 任务标题区

| 元素 | 说明 |
|------|------|
| 任务名称 | H2 标题，可点击编辑（待执行状态） |
| 状态标签 | 当前任务状态，带颜色标签 |
| 迁移类型标签 | 同构/异构迁移类型 |
| 创建人 | 头像 + 用户名 + 创建时间 |

### 操作按钮区

| 按钮 | 显示条件 | 说明 |
|------|----------|------|
| 执行任务 | 待执行/已暂停 | 启动或继续执行 |
| 暂停任务 | 执行中 | 暂停当前执行 |
| 查看日志 | 所有状态 | 跳转日志中心 |
| 编辑配置 | 待执行 | 跳转配置编辑页 |
| 复制任务 | 所有状态 | 复制创建新任务 |
| 删除任务 | 待执行/已取消 | 删除任务 |

**按钮样式**: 主操作 Primary 色，危险操作红色
```

```
## 交互规范

- **实时更新**: 执行中状态自动刷新进度（10秒间隔）
- **暂停刷新**: 执行中可暂停自动刷新
- **展开详情**: 点击表名/执行记录展开详情
- **跳转日志**: 点击日志按钮跳转日志中心
- **编辑配置**: 待执行状态可点击编辑
- **复制任务**: 点击复制创建新任务配置
```
