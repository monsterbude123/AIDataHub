# 迁移任务配置页 - 页面设计规范

> 页面路径: `/integration/migration/create` (新建) `/integration/migration/[taskId]/edit` (编辑)
> 所属模块: 数据集成管理模块
> 覆盖 MASTER 规范: 分步表单，复杂配置向导

## 页面目标

配置数据迁移任务的各项参数，包括源/目标数据源选择、迁移范围、迁移模式、字段映射、执行策略等。

## 布局结构

```
┌─────────────────────────────────────────────────────────────┐
│ 面包屑: 数据集成 > 数据迁移 > 新建迁移任务                      │
│ 页面标题: 新建迁移任务                                        │
├─────────────────────────────────────────────────────────────┤
│ 步骤指示器                                                   │
│ [①基本信息] ── [②数据源配置] ── [③迁移范围] ── [④字段映射] ── [⑤执行策略] │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│ 当前步骤内容区域                                             │
│                                                             │
│                                                             │
├─────────────────────────────────────────────────────────────┤
│ 操作栏: [上一步] [下一步] [保存草稿] [取消]                   │
└─────────────────────────────────────────────────────────────┘
```

## 步骤指示器

配置向导分为 6 个步骤：

| 步骤 | 名称       | 说明                       |
| ---- | ---------- | -------------------------- |
| 1    | 基本信息   | 任务名称、描述、负责人     |
| 2    | 数据源配置 | 选择源和目标数据源         |
| 3    | 迁移范围   | 选择迁移的表/库范围        |
| 4    | 字段映射   | 配置字段对应关系           |
| 5    | 资源配置   | 引擎、队列、Worker配置引用 |
| 6    | 执行策略   | 迁移模式、重试、校验等     |

**步骤指示器样式**:

- 高度: 48px
- 当前步骤高亮显示 (Primary 色)
- 已完成步骤显示勾选图标
- 未完成步骤灰色显示
- 步骤间连线显示进度

## 步骤 1: 基本信息

| 配置项   | 类型        | 必填 | 说明                     |
| -------- | ----------- | ---- | ------------------------ |
| 任务名称 | Input       | ✓    | 最大 50 字符，唯一性校验 |
| 任务描述 | TextArea    | ✗    | 最大 500 字符            |
| 所属项目 | Select      | ✗    | 关联到数据项目（可选）   |
| 负责人   | Select      | ✓    | 从用户列表选择           |
| 标签     | MultiSelect | ✗    | 任务分类标签             |

**布局**: 单列布局，居中显示，最大宽度 600px

## 步骤 2: 数据源配置

### 源数据源配置

| 配置项     | 类型   | 必填 | 说明                                          |
| ---------- | ------ | ---- | --------------------------------------------- |
| 数据源类型 | Select | ✓    | MySQL/PostgreSQL/Oracle/SQL Server/MongoDB 等 |
| 数据源选择 | Select | ✓    | 从已配置数据源列表选择                        |
| 连接测试   | Button | -    | 点击测试连接是否正常                          |
| 数据源详情 | Card   | -    | 显示数据源连接信息（脱敏）                    |

### 目标数据源配置

| 配置项     | 类型   | 必填 | 说明 |
| ---------- | ------ | ---- | ---- |
| 数据源类型 | Select | ✓    | 同上 |
| 数据源选择 | Select | ✓    | 同上 |
| 连接测试   | Button | -    | 同上 |
| 数据源详情 | Card   | -    | 同上 |

**数据源类型图标**: 每种数据库类型对应特定图标

**同构/异构提示**:

- 源和目标类型相同: 显示 "同构迁移" 标签 (绿色)
- 源和目标类型不同: 显示 "异构迁移" 标签 (蓝色) + 类型转换提示

**连接测试结果样式**:

- 成功: 绿色文字 + 勾选图标
- 失败: 红色文字 + 错误图标 + 失败原因 Tooltip

## 步骤 4: 字段映射

### 字段映射表格

展示源表和目标表的字段对应关系：

```
┌──────────────────────────────────────────────────────────────────┐
│ 源字段           │ 类型      │ 目标字段         │ 类型      │ 转换规则 │
├──────────────────────────────────────────────────────────────────┤
│ id               │ INT       │ id               │ INT       │ 无      │
│ name             │ VARCHAR   │ user_name        │ VARCHAR   │ 重命名  │
│ create_time      │ DATETIME  │ created_at       │ TIMESTAMP│ 类型转换│
│ status           │ INT       │ status           │ VARCHAR  │ 枚举映射│
│ □                │           │ □                │           │         │
└──────────────────────────────────────────────────────────────────┘
│ [自动映射] [添加字段] [批量导入映射规则]                          │
└──────────────────────────────────────────────────────────────────┘
```

### 映射操作

| 操作         | 说明                   |
| ------------ | ---------------------- |
| 自动映射     | 同名字段自动匹配       |
| 手动添加     | 添加自定义字段映射     |
| 转换规则配置 | 配置类型转换、值映射等 |
| 排除字段     | 设置不迁移的字段       |

### 转换规则类型

| 规则类型 | 说明                               |
| -------- | ---------------------------------- |
| 无       | 直接映射，不做转换                 |
| 重命名   | 字段名变更                         |
| 类型转换 | 数据类型转换（如 INT → VARCHAR）   |
| 枚举映射 | 值映射（如 1/2 → active/inactive） |
| 函数转换 | 应用转换函数（如日期格式化）       |
| 常量填充 | 固定值填充新字段                   |

### 异构迁移特殊处理

当源和目标数据源类型不同时：

- 显示类型兼容性提示
- 自动推荐类型转换规则
- 不兼容类型红色警告

## 编辑模式差异

编辑已有任务时：

- 步骤指示器显示已有配置状态
- 只能编辑待执行状态的任务
- 编辑后可选择保存草稿或重新执行
- 执行中/已完成任务不可编辑，只可复制

## 表单验证规则

| 步骤       | 验证规则                                 |
| ---------- | ---------------------------------------- |
| 基本信息   | 任务名称必填且唯一                       |
| 数据源配置 | 源和目标数据源必须不同，连接测试必须通过 |
| 迁移范围   | 至少选择一个表/库                        |
| 字段映射   | 源和目标字段数量匹配，类型兼容性检查     |
| 执行策略   | 批量大小、并行数等参数范围校验           |

**验证失败样式**:

- 红色边框标注错误字段
- 字段下方显示错误提示文字
- Toast 提示当前步骤存在问题

## 交互规范

- **步骤跳转**: 点击已完成步骤可跳转回看
- **实时校验**: 输入后实时校验，显示校验结果
- **自动保存**: 配置变更自动保存草稿（防意外丢失）
- **数据源级联**: 选择数据源类型后，数据源列表自动过滤
- **字段预览**: 选择表后展示字段预览
