# 数据源配置表单页 - 页面设计规范

> 页面路径: `/data-integration/sources/new` 或弹窗
> 覆盖 MASTER 规范: 无

## 页面目标

新增/编辑数据源配置，分步骤引导用户完成配置，支持连接测试。

## 布局结构

**分步表单**:

```
┌───────────────────────────────────┐
│ 步骤条: [1] 基本信息 > [2] 连接配置 > [3] 元数据采集 │
├───────────────────────────────────┤
│                                   │
│          当前步骤表单              │
│                                   │
│ 上一步                       下一步 │
└───────────────────────────────────┘
```

## 步骤 1: 基本信息

| 字段 | 类型 | 说明 |
|------|------|------|
| 数据源名称 | 文本输入 | 必填 |
| 数据源类型 | 下拉选择 | 必填: MySQL/Oracle/SQLServer/PostgreSQL/Hive/Elasticsearch/OSS |
| 所属分类 | 树形选择 | 必填，选择业务分类 |
| 描述 | 文本域 | 可选 |

## 步骤 2: 连接配置

| 字段 | 类型 | 说明 |
|------|------|------|
| 主机地址 | 文本输入 | 必填 |
| 端口 | 数字输入 | 必填，默认值根据类型自动填充 |
| 数据库名称 | 文本输入 | 必填 (数据库类型) |
| 用户名 | 文本输入 | 必填 |
| 密码 | 密码输入 | 必填 |
| JDBC 额外参数 | 文本域 | 可选 |

## 步骤 3: 元数据采集配置

| 选项 | 类型 | 说明 |
|------|------|------|
| 接入策略 | 单选 | 一次性接入 / 周期性接入 |
| 调度周期 | 下拉选择 | 日/周/月/自定义 (cron表达式) |
| 数据更新策略 | 单选 | 全量覆盖 / 增量追加 |
| 需要采集元数据 | 开关 | 默认开启 |

## 底部按钮

- **上一步**: 仅第二步第三步可用，返回上一步，保留已填数据
- **连接测试**: 在第二步可用，点击后后台测试连接，显示 Toast 成功/失败
- **下一步**: 进入下一步，前端校验必填项
- **完成**: 最后一步，保存配置，返回列表页

## 交互规范

- **实时校验**: 字段离开焦点后即时校验
- **错误提示**: 错误信息显示在字段下方红色
- **保存草稿**: 支持离开时自动保存草稿
- **密码**: 默认隐藏，可点击眼睛图标显示

## 特殊设计

- 不同数据源类型显示不同配置字段
- 例如: OSS 对象存储需要 AccessKey/SecretKey/Bucket 而不是 JDBC 配置
- 类型切换后，清空不适用的字段

## 权限

- 需有数据源配置权限
