# 任务队列管理模块 - 页面索引

## 模块说明

统一任务队列管理中心，实时监控系统中所有任务队列运行情况，支持队列级别操作管理。

## 功能页面

| 页面         | 文件                       | 说明                             |
| ------------ | -------------------------- | -------------------------------- |
| 队列监控总览 | [monitor.md](./monitor.md) | 查看所有队列实时状态、任务吞吐量 |

## 核心特性

- 实时展示所有队列状态（队列长度、处理速率、等待时间）
- 队列级别操作管理（暂停/恢复、清空、优先级调整）
- 任务详情查看（任务状态、执行时间、错误信息）
- 队列健康度监控与告警
- 支持队列容量趋势图表展示

## 业务场景

- 数据同步任务队列监控
- 数据清洗任务队列管理
- 特征工程任务队列调度
- 质量检测任务队列运维
