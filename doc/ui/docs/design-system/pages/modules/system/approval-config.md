# 审批流程配置页 - 页面设计规范

> 页面路径: `/system/approval-config`
> 覆盖 MASTER 规范: 可视化流程配置

## 页面目标

为不同业务类型配置审批流程，支持多级审批、线性审批、并联审批。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 系统管理 > 审批配置     │
│ [新增模板]                         │
├──────────┬────────────────────────┤
│ 模板列表 │ 流程编辑画布           │
│          │                        │
│          │                        │
│          │                        │
│          │                        │
└──────────┴────────────────────────┘
```

## 左侧模板列表

| 模板名称 | 业务类型 | 状态 | 操作 |
|----------|----------|------|------|
| 数据模型审批 | 数据模型 | 启用 | 编辑 / 删除 |
| ... | | | |

点击模板加载到右侧画布编辑。

## 右侧流程编辑画布

可视化流程编辑:

- 开始节点
- 审批节点 (可添加多个)
  - 审批人类型: 指定用户 / 指定角色 / 上级领导 / 发起人所在部门负责人
  - 审批类型: 线性审批 (顺序) / 并联审批 (全部同意) / 或签 (任一同意)
- 结束节点

支持:
- 拖拽节点改变顺序
- 删除节点
- 配置每个节点审批人
- 配置审批意见是否必填

## 新增模板

表单:

| 字段 | 说明 |
|------|------|
| 模板名称 | 必填 |
| 业务类型 | 下拉选择: 数据模型 / 质量规则 / 质量任务 / 服务发布 |
| 开启审批 | 开关: 开启 / 关闭 |
| 流程描述 | 可选 |

开启审批 = 需要审批，关闭 = 直接通过

## 交互规范

- 保存后立即生效
- 删除需要二次确认
- 验证流程完整性: 必须有开始和结束，必须至少一个审批节点

## 使用方式

各个业务模块调用统一审批框架，不需要各自实现审批流程
