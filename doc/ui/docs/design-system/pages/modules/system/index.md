# 系统管理模块 - 页面索引

## 模块说明

系统级管理功能，包含统一审批流程、组织机构用户、角色权限管理等。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| 审批流程配置 | [approval-config.md](./approval-config.md) | 为不同业务配置审批流程 |
| 我的待办审批 | [approval-todo.md](./approval-todo.md) | 待办/已办审批列表 |
| 组织机构用户 | [org-user.md](./org-user.md) | 组织机构和用户管理 |
| 角色权限管理 | [role-permission.md](./role-permission.md) | 角色菜单权限数据权限配置 |

## 核心特性

- 统一审批框架，支持多级审批、线性审批、并联审批
- 树形组织机构管理
- 菜单权限 + 应用权限 + 数据权限三级权限控制
- 支持行级数据权限表达式配置
- 统一审批提醒通知
