# 系统管理模块 - 页面索引

> 模块路由前缀: `/system`
> 菜单位置: 一级菜单「系统管理」

## 模块说明

系统级管理功能，包含统一审批流程、组织机构用户、角色权限管理等。

## 功能页面

### 一级菜单页面

| 页面     | 类型  | 菜单名称 | 路由                      | 文档                                       |
| -------- | ----- | -------- | ------------------------- | ------------------------------------------ |
| 组织用户 | `[M]` | 组织用户 | `/system/org-user`        | [org-user.md](./org-user.md)               |
| 角色权限 | `[M]` | 角色权限 | `/system/role`            | [role-permission.md](./role-permission.md) |
| 审批待办 | `[M]` | 审批待办 | `/system/approval/todo`   | [approval-todo.md](./approval-todo.md)     |
| 审批配置 | `[M]` | 审批配置 | `/system/approval/config` | [approval-config.md](./approval-config.md) |
| 系统设置 | `[M]` | 系统设置 | `/system/settings`        | [settings.md](./settings.md)               |

### 非菜单页面（从列表/按钮进入）

| 页面     | 类型  | 路由                    | 入口方式                      | 文档                                       |
| -------- | ----- | ----------------------- | ----------------------------- | ------------------------------------------ |
| 用户详情 | `[D]` | `/system/user/[userId]` | 组织用户列表「查看」按钮      | [org-user.md](./org-user.md)               |
| 用户配置 | `[C]` | 弹窗                    | 「新增用户」/「编辑用户」按钮 | [org-user.md](./org-user.md)               |
| 角色配置 | `[C]` | 弹窗                    | 「新增角色」/「编辑角色」按钮 | [role-permission.md](./role-permission.md) |

**页面类型说明**：

- `[M]` 菜单页面 - 出现在侧边导航菜单
- `[D]` 详情页面 - 从列表点击进入，不在菜单
- `[C]` 配置页面 - 新增/编辑配置，不在菜单

## 核心特性

- 统一审批框架，支持多级审批、线性审批、并联审批
- 树形组织机构管理
- 菜单权限 + 应用权限 + 数据权限三级权限控制
- 支持行级数据权限表达式配置
- 统一审批提醒通知
