# 组织机构用户管理页 - 页面设计规范

> 页面路径: `/system/org-user`
> 覆盖 MASTER 规范: 树+表经典布局

## 页面目标

管理组织机构和用户，支持分级权限。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 系统管理 > 组织机构用户 │
│ [新增机构] [新增用户]             │
├──────────────┬────────────────────┤
│ 机构树      │ 用户列表表格        │
│             │                    │
│             │                    │
│             │                    │
│             │                    │
└──────────────┴────────────────────┘
```

## 左侧机构树

- 树形展示组织机构层级
- 支持右键菜单:
  - 新增子机构
  - 新增同级机构
  - 编辑机构
  - 删除机构 (确认，不能有子机构或用户)
- 支持搜索快速定位机构
- 点击机构筛选右侧用户列表

## 右侧用户列表

表格展示该机构下所有用户:

| 列 | 说明 |
|----|------|
| 账号 | |
| 姓名 | |
| 电话 | |
| 邮箱 | |
| 状态 | 正常 / 禁用 (颜色) |
| 分级分类 | 用户数据权限级别 |
| 操作 | 编辑 / 重置密码 / 禁用 / 删除 |

## 顶部操作

- **新增机构**: 弹窗新增
- **新增用户**: 弹窗新增

## 新增/编辑机构表单

| 字段 | 说明 |
|------|------|
| 机构名称 | 必填 |
| 上级机构 | 树形选择 |
| 机构编码 | 必填唯一 |
| 负责人 | 用户选择 |
| 联系电话 | |
| 地址 | |
| 排序 | |
| 状态 | 启用 / 禁用 |

## 新增/编辑用户表单

| 字段 | 说明 |
|------|------|
| 账号 | 必填唯一 |
| 姓名 | 必填 |
| 密码 | 新增必填 |
| 所属机构 | 单选 |
| 电话 | |
| 邮箱 | |
| 数据分级 | 选择用户最大可访问级别 |
| 状态 | 正常 / 禁用 |

## 功能

- **查询**: 支持按账号、姓名、状态条件查询
- **分页**: 用户列表分页
- **重置密码**: 管理员可重置用户密码
- **批量删除**: 勾选批量删除

## 权限

- 超级管理员可管理所有机构和用户
- 机构管理员只能管理本机构及下级机构
- 用户只能修改自己的基本信息（密码、邮箱等）
