# 系统设置页 - 页面设计规范

> 页面路径: `/system/settings`
> 覆盖 MASTER 规范: Tabs 标签页布局

## 页面目标

系统级全局配置管理，包含基础配置、邮件配置、存储配置等。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 系统管理 > 系统设置        │
├───────────────────────────────────┤
│                                   │
│  Tabs: 基础配置 ▶ 邮件服务 ▶ 存储配置 ▶ 安全策略 ▶ 日志配置 │
│  ┌─────────────────────────────┐  │
│  │                             │  │
│  │     Tab 内容区域            │  │
│  │                             │  │
│  │                             │  │
│  └─────────────────────────────┘  │
│                                   │
└───────────────────────────────────┘
```

## Tab 1: 基础配置

### 系统信息

| 字段     | 说明                       | 可编辑 |
| -------- | -------------------------- | ------ |
| 系统名称 | 平台名称，显示在浏览器标题 | ✓      |
| 系统Logo | 上传图片，建议 120x40      | ✓      |
| 系统描述 | 平台简介                   | ✓      |
| 版权信息 | 页脚版权声明               | ✓      |

### 功能开关

| 设置项       | 说明                       |
| ------------ | -------------------------- |
| 用户自主注册 | 是否允许用户自主注册账号   |
| 多端登录     | 是否允许同一账号多设备登录 |
| 密码找回     | 是否开启密码找回功能       |
| 操作日志     | 是否记录用户操作日志       |

### 会话设置

| 字段         | 说明               |
| ------------ | ------------------ |
| 会话超时时间 | 分钟，超时自动退出 |
| 验证码有效期 | 分钟               |
| Token 有效期 | 小时               |

---

## Tab 2: 邮件服务

### SMTP 配置

| 字段        | 说明                |
| ----------- | ------------------- |
| SMTP 服务器 | 如 smtp.example.com |
| 端口        | 25/465/587          |
| 发件人邮箱  |                     |
| 发件人名称  | 显示名称            |
| 用户名      | 认证用户名          |
| 密码        | 认证密码            |
| SSL/TLS     | 是否启用加密        |

### 测试邮件

- 提供发送测试邮件功能
- 输入测试邮箱地址，发送测试邮件验证配置

### 邮件模板

| 模板类型 | 说明               |
| -------- | ------------------ |
| 密码重置 | 密码重置邮件模板   |
| 账号激活 | 新用户激活邮件模板 |
| 审批通知 | 审批流程通知模板   |
| 告警通知 | 系统告警通知模板   |

---

## Tab 3: 存储配置

### 存储类型选择

| 类型       | 说明               |
| ---------- | ------------------ |
| 本地存储   | 服务器本地文件系统 |
| MinIO      | 开源对象存储       |
| 阿里云 OSS | 阿里云对象存储     |
| AWS S3     | AWS 对象存储       |

### 本地存储配置

| 字段         | 说明             |
| ------------ | ---------------- |
| 存储路径     | 文件存储根目录   |
| 最大文件大小 | MB，单个文件上限 |
| 允许文件类型 | 文件扩展名白名单 |

### 对象存储配置 (MinIO/OSS/S3)

| 字段       | 说明          |
| ---------- | ------------- |
| Endpoint   | 服务地址      |
| Access Key | 访问密钥      |
| Secret Key | 密钥          |
| Bucket     | 存储桶名称    |
| Region     | 区域 (S3/OSS) |

---

## Tab 4: 安全策略

### 密码策略

| 设置项     | 说明                        |
| ---------- | --------------------------- |
| 最小长度   | 至少 N 位字符               |
| 复杂度要求 | 大写/小写/数字/特殊字符组合 |
| 有效期     | 天数，过期强制修改          |
| 历史密码   | 不能与最近 N 次密码相同     |
| 锁定策略   | N 次失败后锁定账户          |

### IP 白名单

- 支持配置允许访问的 IP 段
- 支持 CIDR 格式 (如 192.168.1.0/24)
- 白名单外的 IP 无法访问系统

### 登录策略

| 设置项         | 说明                 |
| -------------- | -------------------- |
| 登录方式       | 密码/OAuth/LDAP 多选 |
| 强制双因素认证 | 是否开启 MFA         |
| 异地登录提醒   | 新设备登录发送提醒   |

---

## Tab 5: 日志配置

### 日志级别

| 模块     | 级别                  |
| -------- | --------------------- |
| API 日志 | DEBUG/INFO/WARN/ERROR |
| 任务日志 | DEBUG/INFO/WARN/ERROR |
| 审计日志 | DEBUG/INFO/WARN/ERROR |

### 日志保留

| 设置项           | 说明                   |
| ---------------- | ---------------------- |
| 操作日志保留天数 | 天，超期自动清理       |
| 登录日志保留天数 | 天                     |
| 任务日志保留天数 | 天                     |
| 最大存储空间     | GB，超限自动清理旧日志 |

### 日志导出

- 支持导出日志到外部系统
- 支持 Elasticsearch、Splunk 等对接

---

## 交互规范

- 配置修改后点击保存生效
- 敏感配置（密码、密钥）修改需要二次确认
- 邮件/存储配置提供测试连接功能
- 配置变更记录操作日志

## 权限控制

- 仅系统管理员可访问
- 部分敏感配置需要超级管理员权限
- 配置变更需要审计日志记录
