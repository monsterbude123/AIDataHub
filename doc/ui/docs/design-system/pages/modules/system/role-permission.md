# 角色权限管理页 - 页面设计规范

> 页面路径: `/system/role-permission`
> 覆盖 MASTER 规范: 树形权限选择布局

## 页面目标

管理角色，配置菜单权限、应用权限、数据权限。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 系统管理 > 角色权限    │
│ [新增角色]                         │
├──────────┬────────────────────────┤
│ 角色列表 │ 权限配置               │
│          │ ┌───────────────────┐ │
│          │ │ 菜单权限树        │ │
│          │ │ 应用权限          │ │
│          │ │ 数据权限          │ │
│          │ └───────────────────┘ │
│          │        [保存]          │
│          │                        │
└──────────┴────────────────────────┘
```

## 左侧角色列表

表格:

| 角色名称 | 描述 | 状态 | 操作 |
|----------|------|------|------|
| 系统管理员 | 所有权限 | 启用 | 编辑 / 删除 |

点击角色加载右侧权限配置。

## 右侧权限配置

### Tab 1: 菜单权限

树形展示所有菜单，勾选授权:

- [√] 系统管理
  - [√] 组织机构管理
  - [√] 角色权限管理
  - [√] 审批流程配置

### Tab 2: 应用权限 (URI权限)

列表展示所有URI/按钮权限，勾选授权:

| 模块 | 权限名称 | URI | 授权 |
|------|----------|-----|------|

### Tab 3: 数据权限

配置角色可访问的数据范围:

| 权限类型 | 配置方式 |
|----------|----------|
| **分级分类权限** | 勾选允许访问哪些分级 |
| **组织范围权限** | 勾选允许访问哪些组织机构数据 |
| **项目权限** | 勾选允许访问哪些项目 |
| **自定义行级规则** | 编写过滤表达式 |

### 用户授权

Tab 额外: 用户授权 → 给用户关联角色

- 已选用户列表
- 可选用户搜索添加

## 新增/编辑角色表单

| 字段 | 说明 |
|------|------|
| 角色名称 | 必填 |
| 角色描述 | |
| 状态 | 启用 / 禁用 |

## 交互规范

- 全选/反选菜单树
- 父节点选中自动选中所有子节点
- 父节点取消选中自动取消所有子节点
- 点击角色立即加载权限配置
- 保存成功提示

## 权限说明

- **菜单权限**: 控制哪些菜单可见
- **应用权限**: 控制哪些按钮/接口可访问
- **数据权限**: 控制可访问哪些数据（行级权限）
- 用户可以关联多个角色，权限叠加
