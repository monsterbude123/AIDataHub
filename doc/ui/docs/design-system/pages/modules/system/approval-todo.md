# 我的待办审批页 - 页面设计规范

> 页面路径: `/system/approval-todo`
> 覆盖 MASTER 规范: 列表布局，操作便捷

## 页面目标

展示当前用户需要审批的任务，提供审批功能。

## 布局结构 (Tabs)

```
┌───────────────────────────────────┐
│ 面包crumb: 系统管理 > 我的审批    │
│ Tabs: 我的待办 ▶ 我的已办        │
└───────────────────────────────────┘
```

---

## Tab 1: 我的待办

### 列表表格

| 列 | 说明 |
|----|------|
| 业务类型 | |
| 标题 | 链接到详情 |
| 发起人 | |
| 发起时间 | |
| 当前节点 | |
| 操作 | 审批按钮 |

### 过滤

支持按业务类型、时间范围筛选。

## 审批详情页

从上到下:

1. **基本信息**
   - 业务类型
   - 标题
   - 发起人信息
   - 发起时间

2. **审批流程进度**
   - 时间线展示
   - 已审批节点: 显示审批人、审批时间、审批意见、结果
   - 当前节点: 高亮
   - 未审批节点: 灰色

3. **业务详情**
   - 嵌入业务内容 (比如数据模型详情)
   - 只读展示

4. **审批表单**
   - 审批结果: 通过 / 拒绝 (单选)
   - 审批意见: 文本域 (可选，拒绝建议必填)

5. **按钮**
   - 提交审批

| 操作 | 查看详情 |

## 交互规范

- 待办数量右上角有小红点提示
- 进入页面自动刷新待办列表
- 审批完成后自动从待办列表移除
- 支持消息通知 (邮件/钉钉) 提醒新的待办
- 点击标题打开详情弹窗或新页面

## 特殊设计

- 审批流程跟踪可查看完整审批历史和每个节点意见
- 当前用户只能看到自己需要审批的任务
- 审批完成后流转到下一个节点
