# 自助即席查询构建页 - 页面设计规范

> 页面路径: `/analytics/ad-hoc`
> 覆盖 MASTER 规范: 三栏布局，拖拽交互

## 页面目标

支持用户通过界面拖拽选择表和字段，可视化生成查询，无需手写SQL。

## 布局结构

```
┌──────────┬──────────────┬────────────┐
│ 表资源树 │ 已选字段配置 │ 查询条件 │
│          │              │            │
│          │              │            │
│          │              │            │
│          │              │            │
└──────────┴──────────────┴────────────┘
├─────────────────────────────────────┤
│  执行 / 保存 / 重置                  │
└─────────────────────────────────────┘
```

## 左侧: 表资源树

- 树形展示用户有权限的数据资源
- 支持搜索表名称
- 点击表名称展开显示所有字段
- **拖拽字段** 到中间已选区域

## 中间: 已选字段配置

展示已选择的查询字段:

| 序号 | 表    | 字段 | 别名   | 聚合 | 操作 |
| ---- | ----- | ---- | ------ | ---- | ---- |
| 1    | users | id   | 用户ID | 无   | 删除 |

支持:

- 拖拽调整顺序
- 设置字段显示别名
- 选择聚合方式 (none/count/sum/avg/min/max)
- 删除已选字段

## 右侧: 查询条件配置

添加多个查询条件:

| 字段 | 操作符 | 值  | 操作 |
| ---- | ------ | --- | ---- |

支持操作符: =, !=, >, <, >=, <=, IN, LIKE, IS NULL, IS NOT NULL

添加条件按钮新增条件。

## 底部操作

- **预览SQL**: 生成并显示SQL，用户可查看
- **执行查询**: 执行查询，跳转到结果页
- **保存查询**: 保存查询配置，命名保存
- **分享查询**: 生成分享链接分享给其他用户
- **重置**: 清空所有配置

## 交互规范

- 拖拽添加字段直观便捷
- 自动处理表关联，如果选择多个表，自动JOIN关联
- 用户可预览生成的SQL
- 大结果集限制返回行数（默认 1000行）
- 执行前可预览SQL确认

## 权限

- 用户只能选择自己有权限访问的数据表
- 查询结果自动应用数据行级权限过滤
- 保存的查询所有者可编辑删除
- 分享的查询可被其他用户复制执行
