# 用户自助数据分析模块 - 页面索引

## 模块说明

✨ 新增缺失功能。支持用户自助可视化生成查询，结果可视化展示，无需开发人员参与。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| 自助即席查询构建 | [ad-hoc-query.md](./ad-hoc-query.md) | 拖拽选择表字段构建查询 |
| 查询结果可视化 | [ad-hoc-visualization.md](./ad-hoc-visualization.md) | 图表展示查询结果 |

## 核心特性

- 可视化查询构建，无需手写SQL
- 支持多种图表类型：柱状图、折线图、饼图、地图等
- 支持查询结果导出Excel/CSV
- 支持保存查询和分享查询
- 支持抽样数据探索
