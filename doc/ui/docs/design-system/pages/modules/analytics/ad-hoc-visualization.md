# 查询结果可视化页 - 页面设计规范

> 页面路径: `/analytics/visualization`
> 覆盖 MASTER 规范: 多图表支持，交互探索

## 页面目标

展示查询结果，支持可视化图表，支持导出和保存。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包crumb: 自助分析 > 结果可视化  │
│ 查询名称: [xxx] 保存时间: [xxx]   │
│ [编辑查询] [重新执行] [保存] [导出] │
├──────────┬────────────────────────┤
│ 图表选择 │ 结果图表 / 数据表格     │
│ (柱状    │                        │
│  折线   │                        │
│  饼图   │                        │
│  地图   │                        │
│  ...)  │                        │
│          │                        │
└──────────┴────────────────────────┘
```

## 左侧图表类型选择

点击切换图表类型:

- 柱状图
- 折线图
- 面积图
- 饼图
- 环形图
- 散点图
- 地图 (地理数据)

选择X轴字段和Y轴字段，点击生成图表。

## 右侧展示区域

### 标签页

1. **图表**: 展示生成的图表
   - 支持缩放
   - 支持点击筛选
   - 悬浮显示详情

2. **数据表格**: 展示原始数据
   - 分页
   - 支持排序
   - 可点击单元格筛选

## 操作

- **编辑查询**: 返回查询构建页修改
- **重新执行**: 重新执行查询获取最新数据
- **保存查询**: 保存当前查询配置，可命名
- **导出**: 导出结果 Excel / CSV 格式
- **分享**: 分享查询给其他用户

## 数据探索

- 支持抽样数据可视化探索
- 支持多维度切换
- 支持下载当前图表为PNG图片

## 交互规范

- 切换图表类型实时重新渲染
- 图表响应容器大小
- 大数据量自动抽样展示，提高渲染性能
- 悬浮显示详细数据值

## 性能考虑

- 大数据量使用Canvas渲染
- 图表数据聚合后渲染，不渲染每一个点
- 分页展示原始数据表格
- 支持虚拟滚动大表格

## 权限

- 只有查询所有者或分享对象可查看
- 导出受数据权限控制，只能导出允许的数据
