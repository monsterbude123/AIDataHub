# 数据服务管理模块 - 页面索引

## 模块说明

将数据资源以服务接口方式对外暴露，提供发布、授权、监控能力。

## 功能页面

| 页面 | 文件 | 说明 |
|------|------|------|
| 服务目录 | [catalog.md](./catalog.md) | 浏览搜索数据服务目录 |
| 服务配置 | [config.md](./config.md) | 新增编辑数据服务配置 |
| 服务授权 | [authorization.md](./authorization.md) | 管理服务访问授权 |
| 服务监控 | [monitoring.md](./monitoring.md) | 服务调用监控仪表盘 |

## 核心功能

- 支持查询检索类、数据下载类、比对类三种服务类型
- 数据下载支持后台离线分片输出、压缩加密、断点续传
- 授权控制访问频率、单日次数、到期时间
- 完整调用日志统计可视化
