# 数据服务监控仪表盘 - 页面设计规范

> 页面路径: `/data-service/monitoring`
> 覆盖 MASTER 规范: 使用更多图表，保持数据密集布局

## 页面目标

监控数据服务调用情况，可视化统计信息。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据服务 > 服务监控         │
│ 时间范围筛选: [今日/本周/本月/自定义] │
├──────────┬──────────┬──────────┬──┤
│ 总服务数 │ 今日调用 │ 总调用数 │ 活跃用户 │  ← KPI卡片
├──────────┴──────────┴──────────┴──┤
│                                  │
│  访问趋势折线图 (最近30天)         │
│                                  │
├──────────────────────────────────┤
│                                  │
│ 热门服务TOP 10 横向条形图         │
│                                  │
├──────────────────────────────────┤
│                                  │
│ 用户调用TOP 5 卡片               │
│                                  │
├──────────────────────────────────┤
│ 服务调用日志列表                  │
│ 服务名、调用方、耗时、时间、状态  │
└───────────────────────────────────┘
```

## KPI卡片区域

四个并排Bullet Chart:

| KPI | 目标 |
|-----|------|
| 总服务个数 | 对比上月 |
| 今日调用次数 | 对比昨日 |
| 累计调用次数 | 累计 |
| 活跃用户数 | 对比上周 |

## 图表

1. **访问趋势**: 折线图，X轴日期，Y轴调用次数
   - 可缩放时间范围
   - 支持点击查看详情

2. **热门服务TOP 10**: 横向条形图
   - 按调用次数排序
   - 条形长度代表调用次数

3. **用户调用TOP 5**: 卡片展示，用户名 + 调用次数 + 头像

## 调用日志列表

- 实时查询调用日志
- 列: 服务名称、调用方用户名、调用方IP、MAC地址、耗时、状态、时间
- 支持按服务名称、调用方搜索
- 分页加载

## 交互规范

- 时间范围筛选器影响所有图表和列表
- 支持导出统计报表
- 点击热门服务条形可跳转到服务详情页

## 性能考虑

- 图表数据聚合后返回，不传输原始日志
- 日志列表懒加载分页
- 刷新间隔可配置 (默认 30秒)
