# 数据服务目录页 - 页面设计规范

> 页面路径: `/data-service/catalog`
> 覆盖 MASTER 规范: 无

## 页面目标

浏览和搜索所有已发布的数据服务，查看服务详情。

## 布局结构

```
┌───────────────────────────────────┐
│ 面包屑: 数据服务 > 服务目录         │
│ 过滤栏: [搜索] [类型筛选] [状态]   │
│ [新增服务]                         │
├───────────────────────────────────┤
│                                   │
│ 服务卡片网格                      │
│                                   │
│ 分页控件                          │
│                                   │
└───────────────────────────────────┘
```

## 过滤栏

- **搜索**: 按服务名称模糊搜索
- **类型筛选**: 下拉: 全部 / 查询检索 / 数据下载 / 比对
- **状态筛选**: 下拉: 全部 / 已发布 / 未发布 / 已下线

## 服务卡片

每张卡片展示:

- **左上角**: 类型标签 (带颜色)
  - 查询检索: 蓝色
  - 数据下载: 绿色
  - 比对: 橙色
- **服务名称**: 加粗标题
- **服务描述**: 两行截断
- **发布人 / 创建时间**: 小字
- **调用统计**: 累计调用次数 小字
- **状态标签**: 已发布(绿) / 未发布(灰) / 已下线(红)
- **底部操作**: 查看详情 / 测试 / (权限: 下线 / 删除)

## 卡片网格

- 桌面: 3列
- 平板: 2列
- 移动端: 1列

## 交互规范

- 点击卡片标题进入详情页
- 新增服务打开分步配置弹窗
- 删除需要二次确认
- 未发布可直接删除，已发布必须先下线才能删除

## 特殊设计

- 支持下载服务接口文档Word文档
- 服务文档包含: 使用说明、参数列表、密钥、错误码说明
