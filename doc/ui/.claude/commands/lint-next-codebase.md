# 检查Next.js项目代码符合开发规范

请全面检查当前代码库是否符合Next.js前端开发规范，列出问题并提供修复建议。

执行步骤：
1. 运行项目自带的ESLint检查，收集所有错误和警告
2. 检查目录结构是否符合企业级规范要求
3. 扫描所有组件文件，检查：
   - 服务端/客户端组件使用是否正确
   - 是否存在超过500行的巨型组件
   - 类型使用是否正确，是否存在any滥用
   - 命名是否符合规范要求
4. 检查状态管理是否遵循：服务端状态由TanStack Query管理，不滥用全局状态
5. 检查安全规范：是否存在硬编码敏感信息、环境变量配置错误等问题
6. 检查代码提交配置是否符合规范

检查要点：
- ✅ 是否遵循优先使用服务端组件原则
- ✅ 是否存在any类型绕过类型检查的情况
- ✅ 是否存在超过500行未拆分的巨型组件
- ✅ 服务端数据是否都由TanStack Query管理，没有存入客户端全局状态
- ✅ 命名规范是否统一遵循
- ✅ 是否存在硬编码魔法数字和敏感配置
- ✅ 导入顺序和代码格式是否符合规范
- ✅ 目录结构是否匹配规范要求

输出要求：
按优先级列出所有不规范问题，每个问题说明位置和具体修复方案
