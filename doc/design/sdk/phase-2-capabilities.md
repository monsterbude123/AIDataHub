# 阶段 2：模块功能点定义（二级索引）

本阶段仅定义平台的 **二级索引层**：逐模块列出该模块下所有内聚功能点，并标记为 **对外能力** 或 **内部能力**。  
**禁止**在本阶段出现：共享实体字段、接口入参出参、错误码、Mock 等后续阶段内容。

> 注：功能点来源以 `doc/design/数据中台-最终需求梳理.md`（221 点）为准，并结合既有模块策划稿进行归并；所有功能点必须落在模块限界上下文内，禁止跨模块。

## 1. `data-integration`（数据接入集成）

- **数据接入**
  - **对外能力**：数据源分类浏览
  - **对外能力**：数据源配置（名称、连接信息、描述等）
  - **对外能力**：数据源修改（未使用数据源的配置更新）
  - **对外能力**：数据源删除（未在使用的数据源删除）
  - **对外能力**：数据源连接测试
  - **对外能力**：数据源类型扩展（结构化/半结构化/非结构化）
  - **对外能力**：数据源搜索查询（精确/模糊）
  - **对外能力**：业务系统权限隔离（按业务系统管理数据源权限）
  - **对外能力**：元数据初始采集（仅接入时初始采集）
  - **对外能力**：接入策略配置（一次性/周期性；插入/更新策略）
  - **对外能力**：批量接入（同一数据源多数据集）

- **数据探查**
  - **对外能力**：数据资源分类浏览（探查目录、已探查/未探查）
  - **对外能力**：数据浏览（分页预览）
  - **对外能力**：数据探查任务（总量/增量/空值率/样例/元数据变更等）
  - **对外能力**：探查侧元数据维护（管理/业务/技术元数据；字段关联标准/字典/分级分类）

- **数据标准化（执行）**
  - **对外能力**：标准化资源分类浏览（目录树管理、资源浏览）
  - **对外能力**：历史配置查看（来源层/目录层维度）
  - **对外能力**：标准库列表（下钻数据源/数据集/元数据）
  - **对外能力**：数据标准化处理（字段映射、清洗筛选、质量过滤、函数预处理）
  - **对外能力**：标准化任务管理（状态、报错、重跑）

- **数据开发（Spark 自助开发）**
  - **对外能力**：模型管理（SQL 编辑、保存、分类、拖拽生成）
  - **内部能力**：测试执行（采样测试）
  - **内部能力**：任务执行（Spark 执行、资源释放）
  - **内部能力**：临时视图（中间结果缓存、任务结束清理）
  - **内部能力**：数据结果输出（全量/增量、插入更新/全表更新）
  - **对外能力**：开发任务监控（进度、历史、异常、结果浏览）
  - **对外能力**：开发函数管理（UDF 上传/在线编写）

## 2. `data-service`（通用数据 API 服务）

- **服务资源管理**
  - **对外能力**：数据服务目录管理
  - **对外能力**：新增服务（基于数据资源/SQL 发布 REST 服务；自定义查询条件与响应字段；字典翻译）
  - **对外能力**：服务类型支持（查询检索/下载/比对）
  - **对外能力**：数据下载类增强（离线分片、压缩/加密、断点续传、输出到多存储）
  - **对外能力**：发布/取消发布
  - **对外能力**：浏览服务详情
  - **对外能力**：服务查询测试
  - **对外能力**：服务检索
  - **对外能力**：服务下线
  - **对外能力**：删除服务（未发布可删；已发布需先下线）
  - **对外能力**：接口文档下载（基于授权信息生成文档）

- **服务授权**
  - **对外能力**：新增服务授权（联系单、批量、频控、到期）
  - **对外能力**：授权分类（行业/单位/系统树）
  - **对外能力**：授权检索
  - **对外能力**：修改授权
  - **对外能力**：删除授权

- **服务监控**
  - **对外能力**：监控配置（调用次数、最近状态）
  - **对外能力**：服务调用日志查询（耗时、用户、IP、MAC 等）
  - **对外能力**：服务统计可视化（趋势、TOP、用户数等）

## 3. `metadata`（元数据全生命周期）

- **对外能力**：元数据采集（自动/订阅/手动；多源多类型）
- **对外能力**：添加 SQL 资源（SQL 数据集元数据）
- **对外能力**：元数据导入（模板）
- **对外能力**：元数据导出（部分/全部）
- **对外能力**：元数据标准管理（业务/技术/管理元数据元素）
- **对外能力**：元数据同步管理（定时比对、更新/删除）
- **对外能力**：元数据版本管理（变更历史、版本比对）
- **对外能力**：元模型属性配置（技术/管理/业务）
- **对外能力**：元数据变更订阅（邮件等）
- **对外能力**：ETL/模型/服务元数据版本管理（统一纳管扩展）

## 4. `data-organization`（数据分层组织）

- **业务库**
  - **对外能力**：数据资源分类（行业/部门/业务系统）
  - **对外能力**：数据资源目录管理（树增删改、采集删除资源）
  - **对外能力**：元数据维护入口（展示并维护）
- **原始库**
  - **对外能力**：数据资源分类
  - **对外能力**：数据资源目录管理
  - **对外能力**：元数据维护入口
- **资源库**
  - **对外能力**：数据资源分类（树、采集、支持直接探查入口）
  - **对外能力**：数据入资源库处理（字段映射、清洗筛选、函数预处理）
  - **对外能力**：入库任务管理（状态、报错、重跑）
  - **对外能力**：浏览映射信息（标准表/资源库表视角）
- **主题库**
  - **对外能力**：数据资源分类（主题对象）
  - **对外能力**：数据入主题库处理（字段映射、清洗筛选、函数预处理）
  - **对外能力**：入库任务管理
  - **对外能力**：浏览映射信息

## 5. `task-scheduler`（统一任务调度中心）

- **对外能力**：任务编排（DAG 可视化编排、依赖配置）
- **对外能力**：调度策略（定时/事件/依赖触发）
- **对外能力**：任务队列管理（队列、优先级、资源隔离）
- **对外能力**：集群负载均衡（分配与调度策略）
- **对外能力**：统一日志中心（统一收集与查看）

  - **对外能力**：我的待办
  - **对外能力**：我的已办
  - **对外能力**：审批流程跟踪
  - **对外能力**：审批提醒
- **组织用户**
  - **对外能力**：机构查询 / 机构增删改
  - **对外能力**：用户查询 / 用户增删改
  - **对外能力**：用户分级分类设置
- **角色权限**
  - **对外能力**：角色查询 / 角色增删改
  - **对外能力**：应用权限管理（URI/页面元素）
  - **对外能力**：菜单权限管理
  - **对外能力**：用户授权管理（角色-权限、用户-角色）
  - **对外能力**：数据权限管理（分级分类/项目/组织范围）
- **系统树目录**
  - **对外能力**：目录树统一管理（增删改复制）
  - **对外能力**：目录节点检索
  - **对外能力**：新增节点 / 删除修改节点

## 7. `data-operations`（数据运维监控）

- **对外能力**：任务运维监控（搜索/排序/重跑/异常详情）

  - **对外能力**：待办任务审批

  - **对外能力**：已办任务详情
- **资源管理**
  - **对外能力**：资源分类目录树管理（唯一性校验、自动编码）

  - **对外能力**：库表数据登记（采集/自定义 SQL、字段查看、连接测试）
  - **对外能力**：接口数据登记（代理/封装接口登记、测试调用、修改）

  - **对外能力**：可登记资源管理（已发布已挂接）

  - **内部能力**：服务请求权限校验（授权/有效期/频控；记录日志）
  - **对外能力**：已共享资源查看（提供方视角）
