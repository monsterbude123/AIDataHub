# 数据中台 - 最终功能性需求梳理

本文档基于原始需求 `数据中台.md` 进行梳理，梳理出存在的问题、不合理之处，并补充缺失功能，整理出完整的最终功能性需求。

---

## 一、原始需求完整性评估

### 1.1 存在的问题

| 问题           | 位置                   | 说明                                                             |
| -------------- | ---------------------- | ---------------------------------------------------------------- |
| 功能重叠       | 数据接入 vs 元数据管理 | 元数据采集功能在两处都有定义，职责划分不清晰                     |
| 分工不明确     | 数据标准化             | 数据集成中的数据标准化和数据治理中的数据标准管理职责需要明确划分 |
| 审批流程不完整 | 多处                   | 多处提到审批，但缺乏统一审批流程框架定义                         |
| 权限粒度不清晰 | 系统管理               | 只定义了用户/角色权限，缺乏数据级权限控制细节                    |

### 1.2 不合理之处

| 不合理                 | 位置         | 说明                                                |
| ---------------------- | ------------ | --------------------------------------------------- |
| 数据下载服务描述不完整 | 数据服务管理 | 只说明了输出到存储，但缺少分片、断点续传等细节      |
| 标签碰撞定义过简       | 数据标签管理 | 只提到多标签查询，缺少条件组合（交集/并集）能力定义 |
| 血缘缺少自动采集机制   | 数据血缘     | 只提到展示，没说明如何自动采集和更新血缘关系        |
| 水印溯源不完整         | 数据水印     | 只提到全文件解析，缺少部分数据泄露的溯源支持        |
| 缺少统一任务调度       | 各处         | 各个模块都有任务管理，但缺少统一调度中心的概念      |

---

## 二、最终功能性需求

### 2.1 数据集成管理

数据接入处理支持通过Spark、ETL实现结构化、半结构化、非结构化文件的集中读取、校验、清洗转换等接入处理，并存储到数据仓库。

#### 2.1.1 数据接入

| 功能项           | 需求描述                                                                                                                                                                          |
| ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 数据源分类浏览   | 支持用户浏览数据源目录，逐层递进浏览；支持按目录分类展示                                                                                                                          |
| 数据源配置       | 支持有权限用户配置数据源，包含名称、jdbc连接、用户名、密码、描述等                                                                                                                |
| 数据源修改       | 支持修改未使用的数据源配置                                                                                                                                                        |
| 数据源删除       | 支持删除未在使用的数据源配置                                                                                                                                                      |
| 数据源连接测试   | 支持测试数据源连接连通性                                                                                                                                                          |
| 数据源类型扩展   | 支持扩展新的数据源类型，支持结构化、半结构化、非结构化数据接入                                                                                                                    |
| 数据源搜索查询   | 支持精确/模糊搜索数据源名称                                                                                                                                                       |
| 业务系统权限隔离 | 支持按照业务系统进行数据源权限管理                                                                                                                                                |
| 元数据采集       | **（职责：只负责接入时的初始采集）** 采集数据表元数据信息，包含列名、描述、数据类型、精度等；支持达梦、Oracle、MySQL、SqlServer、Postgresql、Hive、Elasticsearch等 （职责明确化） |
| 接入策略配置     | 支持配置一次性接入、周期性接入策略；支持配置数据插入更新策略                                                                                                                      |
| 批量接入         | 支持指定一个数据源下的多个数据集批量接入                                                                                                                                          |

#### 2.1.2 数据探查

数据探查是数据接入流程的一个环节，对即将接入的数据进行多维度分析，为数据定义提供依据。

| 功能项           | 需求描述                                                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------------------------- |
| 数据资源分类浏览 | 支持逐层递进浏览探查资源目录；支持按已探查/未探查分类                                                                                    |
| 数据浏览         | 支持分页浏览待探查数据表中的数据                                                                                                         |
| 数据探查任务     | 支持发起探查任务，探查资源总量、增量、空值率、有值率、样例数据、元数据变更等                                                             |
| 元数据管理       | 支持录入数据表元数据信息（管理元数据、业务元数据、技术元数据）；支持编辑字段基础信息、关联标准数据元、关联字典、分级分类；支持检索数据项 |

#### 2.1.3 数据标准化

**（职责：执行数据标准化处理，数据标准定义由数据治理模块负责）** 将原始数据经过清洗转换、质量过滤、标准映射后写入标准资源库。

| 功能项           | 需求描述                                                                                         |
| ---------------- | ------------------------------------------------------------------------------------------------ |
| 数据资源分类浏览 | 支持逐层递进浏览资源目录；支持目录上新增目录、新增/修改数据源、采集数据集、添加SQL资源、浏览数据 |
| 历史配置查看     | 分别以来源层和目录层维度展示已配置的标准化任务流程                                               |
| 标准库列表       | 展示标准库下所有数据源信息，可下钻查看数据集，查看元数据详情                                     |
| 数据标准化处理   | 支持原始表与标准表逐字段关联；支持清洗筛选、质量过滤、函数预处理                                 |
| 标准化任务管理   | 支持浏览任务信息（名称、时间、状态、执行方式、数据量等）；支持查看报错、重新执行                 |

#### 2.1.4 数据开发

基于Spark的大数据自助开发能力。

| 功能项       | 需求描述                                                                                                                           |
| ------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| 模型管理     | 提供Spark SQL编辑器，支持填写自定义SQL并保存为模型；支持配置执行器内存、核数、个数；支持自定义模型分类；支持拖拽表自动生成查询语句 |
| 测试执行     | 自动解析源头表，通过采样配置抽取少量数据用于测试，加快开发校验                                                                     |
| 任务执行     | 使用Spark引擎执行，支持大数据量处理；执行完自动建表、主动释放计算资源                                                              |
| 临时视图     | 支持构建临时视图缓存中间结果，任务结束自动删除，提高SQL可读性和执行效率                                                            |
| 数据结果输出 | 支持全量、增量输出；支持插入更新及全表更新等模式                                                                                   |
| 开发任务监控 | 支持查看任务执行情况及历史；支持浏览结果数据、查看异常信息；支持实时进度显示                                                       |
| 开发函数管理 | 支持自定义UDF，提供JAR包上传和在线编写两种方式                                                                                     |

### 2.2 数据服务管理

将数据资源以服务接口方式对外暴露，提供发布、授权、监控能力。

#### 2.2.1 服务资源管理

| 功能项         | 需求描述                                                                                       |
| -------------- | ---------------------------------------------------------------------------------------------- |
| 数据服务目录   | 按照统一标准规范管理数据服务，实现科学有序安全使用                                             |
| 新增服务       | 支持基于数据资源或SQL语句发布Restful服务；支持自定义查询条件、响应字段；支持字典翻译           |
| 服务类型支持   | 查询检索类、数据下载类、比对类                                                                 |
| 数据下载类增强 | 支持后台离线分片输出到FTP、HDFS、对象存储；采用CSV格式，支持压缩、加密、分片写入；支持断点续传 |
| 发布/取消发布  | 发布后正式提供访问，未发布不可调用                                                             |
| 浏览服务详情   | 展示服务名称、接口地址、发布人、查询字段、响应字段等                                           |
| 服务查询测试   | 提供模拟测试功能，可输入查询条件测试调用                                                       |
| 服务检索       | 支持按服务名称检索                                                                             |
| 服务下线       | 支持将已发布服务下线                                                                           |
| 删除服务       | 未发布可直接删除，已发布需先下线才能删除                                                       |
| 接口文档下载   | 基于授权信息生成Word格式接口文档，包含使用说明、参数、密钥、状态码等                           |

#### 2.2.2 数据服务授权

在保障数据安全的前提下，为服务使用方授予访问权限。

| 功能项       | 需求描述                                                               |
| ------------ | ---------------------------------------------------------------------- |
| 新增服务授权 | 支持录入申请联系单、批量授权、设置访问频率、单日访问次数、授权到期时间 |
| 服务授权分类 | 支持按行业、单位、系统分类；支持逐层浏览、增删改节点、检索             |
| 服务授权检索 | 支持按申请标题、用户账号、用户名检索                                   |
| 修改服务授权 | 支持修改授权信息，包括申请方信息和访问限制                             |
| 删除服务授权 | 支持删除授权信息                                                       |

#### 2.2.3 数据服务监控

| 功能项         | 需求描述                                                                        |
| -------------- | ------------------------------------------------------------------------------- |
| 数据服务监控   | 支持配置监控服务调用次数和最近状态                                              |
| 服务调用日志   | 实时查询调用日志，包括耗时、调用方用户名、IP、MAC等                             |
| 服务统计可视化 | 展示总服务次数、今日次数、总个数、用户数、热门服务TOP10、用户调用TOP5、访问趋势 |

### 2.3 元数据管理

**（职责：负责元数据的全生命周期管理，数据接入只做初始采集）**

| 功能项           | 需求描述                                                                                    |
| ---------------- | ------------------------------------------------------------------------------------------- |
| 元数据采集       | 支持自动/订阅/手动方式采集导入元数据和元模型；支持关系型数据库、大数据等类型 （职责明确化） |
| 添加SQL资源      | 支持编写自定义SQL，生成SQL数据集元数据                                                      |
| 元数据导入       | 支持按模板导入元数据                                                                        |
| 元数据导出       | 支持按需导出部分或全部元数据                                                                |
| 元数据标准管理   | 支持创建修改删除元数据标准，包括业务元数据、技术元数据、管理元数据元素                      |
| 元数据同步管理   | 定时比对数据库和平台元数据是否一致，提供更新删除操作                                        |
| 元数据版本管理   | 支持创建修改删除操作的历史变更管理；支持查看历史、版本比对                                  |
| 元模型属性配置   | 支持绑定自定义元模型属性配置（技术/管理/业务）                                              |
| 元数据变更订阅   | 支持通过邮件等方式订阅元数据变更推送                                                        |
| **版本管理扩展** | 支持ETL任务、数据模型、数据服务的元数据版本管理                                             |

### 2.4 数据组织管理

按照方式和规则对数据进行归并存储，实现从生产库到服务库的合理分布存储。

#### 2.4.1 业务库

各专业领域业务数据库，支撑业务数据，是数据中心主要数据来源。

| 功能项           | 需求描述                                                     |
| ---------------- | ------------------------------------------------------------ |
| 数据资源分类     | 按行业/部门/业务系统分类，支持逐层递进浏览；支持增删目录节点 |
| 数据资源目录管理 | 支持目录树增删改节点；支持采集删除数据资源                   |
| 元数据管理       | 选中后展示元数据信息，支持维护                               |

#### 2.4.2 原始库

保留原始数据，反映原始业务场景，补充标准化数据、关联要素和标签信息。

| 功能项           | 需求描述                                   |
| ---------------- | ------------------------------------------ |
| 数据资源分类     | 按行业/部门/业务系统分类，支持逐层递进浏览 |
| 数据资源目录管理 | 支持目录树增删改节点；支持采集删除数据资源 |
| 元数据管理       | 选中后展示元数据信息，支持维护             |

#### 2.4.3 资源库

综合各类数据资源建立的关键要素及关联关系的公共数据集合。

| 功能项           | 需求描述                                                           |
| ---------------- | ------------------------------------------------------------------ |
| 数据资源分类     | 支持目录树展示，逐层递进；支持增删改数据源、采集数据；支持直接探查 |
| 数据入资源库处理 | 支持标准资源表到资源库表字段映射；支持清洗筛选、函数预处理         |
| 入库任务管理     | 支持浏览任务信息；支持查看报错、重新执行                           |
| 浏览映射信息     | 支持从标准表/资源库表维度查看映射关联                              |

#### 2.4.4 主题库

围绕主题对象（人、地、案、事件、物、组织等）整合各类数据形成的公共数据集合。

| 功能项           | 需求描述                                                               |
| ---------------- | ---------------------------------------------------------------------- |
| 数据资源分类     | 按主题分类（人员、场所、物品、案件、事件、信息、组织），支持目录树管理 |
| 数据入主题库处理 | 支持标准表到主题库表字段映射；支持清洗筛选、函数预处理                 |
| 入库任务管理     | 支持浏览任务信息；支持查看报错、重新执行                               |
| 浏览映射信息     | 支持从标准表/主题库表维度查看映射关联                                  |

### 2.5 数据治理管理

#### 2.5.1 数据资源目录

| 功能项           | 需求描述                                                                                                               |
| ---------------- | ---------------------------------------------------------------------------------------------------------------------- |
| 数据地图         | 支持按数据分层、来源地区、获取方式、资源位置、数据组织、行业等维度组合筛选；支持按表名称检索；支持浏览列信息和数据示例 |
| 导出数据台账     | 支持导出平台数据资源台账，包含数据源、数据集、数据量等信息                                                             |
| 导出血缘溯源台账 | 支持以血缘关系方式导出台账，展示数据来源去向                                                                           |
| **数据资产搜索** | 支持全文搜索数据资产，支持按多种维度筛选排序                                                                           |
| **数据资产标签** | 支持为数据资产打标签，支持按标签筛选                                                                                   |

#### 2.5.2 数据质量管理

通过建立质量评估标准，及时发现解决数据质量问题，形成闭环处理。

| 功能项       | 需求描述                                                                                     |
| ------------ | -------------------------------------------------------------------------------------------- |
| 质量规则定义 | 支持一致性、准确性、完整性、规范性、关联性等通用规则；支持自定义规则                         |
| 质量规则审批 | 支持动态开关审批，开启后新增规则需审批才能使用                                               |
| 质量规则配置 | 支持为数据资源配置检测规则；支持多种规则类型；支持配置调度周期                               |
| 质量任务审批 | 支持动态开关审批，开启后新增任务需审批才能执行                                               |
| 质量任务管理 | 支持浏览任务信息（名称、调度、时间、状态等）；支持手动执行、修改调度、查看历史、查看失败原因 |
| 质量报告生成 | 支持记录质量问题，生成报告包含问题数据、规则、检核结果、改进建议、趋势                       |
| 质量工单发起 | 支持发起质量工单，发送给指定用户提醒解决                                                     |
| 问题数据预览 | 支持在线查看质量任务输出的问题数据                                                           |
| 质量统计分析 | 可视化展示质量检测资源数、总记录数、问题数、问题占比、波动分析                               |

#### 2.5.3 数据标签管理

提供标签全生命周期管理，通过标签刻画对象特征，支持标签碰撞形成精准画像。

| 功能项             | 需求描述                                                                                              |
| ------------------ | ----------------------------------------------------------------------------------------------------- |
| 标签分类           | 支持按业务分类灵活分类；支持逐层浏览、自定义节点、检索分类                                            |
| 标签检索           | 支持按标签名称、调度时间、数据量检索                                                                  |
| 标签列表           | 支持卡片方式浏览，包含名称、数据总量、昨日增量、规则数                                                |
| 新增/修改/删除标签 | 支持维护标签信息（编码、名称、描述、等级）                                                            |
| 标签规则配置       | 支持从数据资源/SQL提取标签；支持全量/增量提取；同一标签支持多规则                                     |
| 标签任务监控       | 支持浏览提取任务信息；支持筛选检索；支持查看异常信息                                                  |
| 标签数据查询       | 支持按目录树浏览，展示数据量；支持勾选多个标签查询；**支持选择交集/并集组合条件**；支持按对象属性检索 |
| 标签主体管理       | 支持标签主体增删改；支持全文检索、查询关联标签                                                        |

#### 2.5.4 数据血缘

描述数据在产生加工流转过程中的继承关系，反映各环节继承关系。

| 功能项               | 需求描述                                                               |
| -------------------- | ---------------------------------------------------------------------- |
| **自动血缘采集**     | 支持从ETL任务、SQL开发、数据服务自动采集血缘关系；支持血缘关系自动更新 |
| 数据资源检索         | 支持树状展示，按名称搜索定位                                           |
| 数据表血缘分析       | 图形化展示全流程数据流向；支持查看ETL任务状态；点击节点可浏览数据      |
| 数据字段血缘分析     | 图形化展示字段级全流程数据流向；支持查看ETL任务状态                    |
| 影响分析             | 修改元数据时自动分析展示对下游的影响（接口、库表、SQL、报表、指标等）  |
| **血缘影响范围导出** | 支持导出影响分析结果                                                   |
