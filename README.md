# AI DataHub

▎ 企业级数据中台 SDK for Node.js/TypeScript

- 模块化
- 契约先行
- 领域驱动设计

## 简介

AI DataHub 是一个面向企业的数据中台开发 SDK，采用 DDD 领域驱动设计  
思想，将数据中台核心能力拆分为 16
个独立的业务模块，遵循契约先行开发模式，支持并行开发和渐进式落地。

# 核心特性

- 📦 模块化架构 - 16 个业务模块按限界上下文拆分，独立演进
- 📜 契约先行 - 所有接口契约统一定义在
  @ai-datahub/contract，消费者可仅依赖契约
- 🧩 npm workspaces - 标准 monorepo 结构，多包独立版本管理
- 🎯 TypeScript 优先 - 全程 strict mode，零 any 类型，完整类型推断
- 🔄 dual 输出 - 同时输出 ESM + CJS，兼容所有 Node.js 环境
- 🏷️ changesets - 专业多包版本管理 + CHANGELOG 自动生成

# 技术栈

- Language: TypeScript 5.x (strict mode)
- Runtime: Node.js 18+
- Package Manager: npm (workspaces monorepo)
- Build Tool: tsup
- Testing: Vitest
- ORM: Prisma
- Database: SQLite (dev) / PostgreSQL (prod)
- Code Quality: ESLint + Prettier + husky + lint-staged
- Versioning: changesets
- Validation: Zod

# 快速开始

```
  # 安装依赖
  npm install

  # 初始化数据库（首次运行）
  cd packages/database && npx prisma db push && cd ..

  # 构建所有包
  npm run build

  # 类型检查
  npm run build:check

  # 运行测试
  npm run test

  安装使用

  # 安装核心契约包
  npm install @ai-datahub/contract

  # 安装基础设施工具包
  npm install @ai-datahub/shared

  # 安装共享数据库包
  npm install @ai-datahub/database
```
